# 项目愿景与范围（Vision & Scope）

## 一句话定位

pe-kt 是一个以 Kotlin 全栈（Ktor 后端）驱动的 Project Euler 学习与展示平台：每道数学题配深度解析、可运行的 Kotlin 参考实现，以及帮助理解算法的计算过程可视化。

## 目标用户

- 主要：项目作者本人（用 PE 系统性地练 Kotlin / Ktor / 算法与数论）
- 次要：对 Project Euler 感兴趣、想看"数学思路 → 代码 → 可视化"完整链路的开发者

## 核心价值

1. **解析优先**：不止给答案和代码，而是讲清楚"为什么这样做"——数学推导、复杂度分析、暴力解 vs 优化解的对比
2. **代码即文档**：每道题的 Kotlin 实现是可运行的、带测试的，逐步沉淀出可复用的数论工具库
3. **可视化辅助理解**：对适合的题目（筛法、路径搜索、递归树、分治过程等）提供计算过程的动画/分步展示

## 范围边界

### 做（In Scope）

- 后端服务：Ktor 提供 REST API（题目元数据、解析内容、代码、运行结果、可视化数据）
- 题目内容：Markdown 格式的题面翻译、思路解析、Kotlin 参考实现
- 在线运行/预计算：后端执行解法代码，返回答案与耗时（受沙箱限制的轻量执行）
- 可视化数据端点：为前端图表/动画提供结构化数据（如筛法每一步的标记状态）
- 前端页面：题目列表、题目详情（解析 + 代码高亮 + 可视化）

### 暂不做（Out of Scope，至少 v1 不做）

- 用户系统、登录、提交答案判题（PE 官方不开放自动判题 API，且非本项目目的）
- 多语言解法对比（v1 只聚焦 Kotlin）
- 社区功能（评论、讨论）
- 移动端原生应用

## 成功标准（v1）

- [x] 能展示至少 25 道已完成解析的题目（含解析、代码、答案验证）
- [x] 其中至少 5 道带计算过程可视化
- [x] 沉淀出一个覆盖素数、GCD、模运算、组合数的 Kotlin 数论工具库（带单元测试）
- [x] 单次页面加载 < 1s（本地运行环境）
