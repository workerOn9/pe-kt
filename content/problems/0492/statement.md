# 492 · 爆炸数列

> 中文意译。英文原文见 [Project Euler Problem 492](https://projecteuler.net/problem=492)；抓取底稿见 `statement.en.md`。

数列 $a_1, a_2, a_3, \ldots$ 定义为：

$$
a_1 = 1
$$

$$
a_{n+1} = 6a_n^2 + 10a_n + 3 \qquad (n \ge 1)
$$

例如：

```
a3 = 2359
a6 = 269221280981320216750489044576319
a6 mod 1 000 000 007 = 203064689
a100 mod 1 000 000 007 = 456482974
```

定义 $B(x,y,n)$ 为对每个满足 $x \le p \le x+y$ 的素数 $p$ 求得的 $(a_n \bmod p)$ 之和。

例如：

```
B(10^9, 10^3, 10^3) = 23674718882
B(10^9, 10^3, 10^15) = 20731563854
```

求 $B(10^9, 10^7, 10^{15})$。
