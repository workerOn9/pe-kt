# 950 · 海盗分金

> 中文意译。英文原文见 [Project Euler Problem 950](https://projecteuler.net/problem=950)；抓取底稿见 `statement.en.md`。

一伙海盗获得了一批宝藏，必须在彼此之间进行分配。宝藏由若干枚完全相同且不可分割的金币组成。

根据海盗法则，金币分配必须遵循以下规则：
1. 最资深的海盗提出一份金币分配方案。
2. 所有海盗（包括提议者本人）对是否接受该分配方案进行投票。
3. 若至少有一半海盗投赞成票，则该分配方案正式生效。
4. 否则，提议的最资深海盗必须走跳板被处决扔进大海，然后由剩下的最资深海盗重复第 1 步提出新的分配方案。

海盗的幸福度定义如下：
- 若其未能活下来，幸福度为 $-\infty$；
- 若其幸存下来，幸福度等于 $c + p \cdot w$，其中 $c$ 为该海盗在最终方案中分得的金币数，$w$ 为被处决走跳板的海盗总数，$p$ 为海盗的嗜血度。

所有海盗均具有以下特征：
- **贪婪**：竭力最大化自身的幸福度。
- **残忍**：绝不合作、不作任何承诺，也不顾及任何声誉。
- **精明**：具有完美的理性和逻辑推理能力。

考虑在由 $n$ 名嗜血度均为 $p$ 的海盗分配 $C$ 枚金币的情形下，最资深的幸存海盗的幸福度 $c(n, C, p) + p \cdot w(n, C, p)$。
例如，$c(5, 5, \frac{1}{10}) = 3$ 且 $w(5, 5, \frac{1}{10}) = 0$：可以证明，如果最资深海盗提出按资历从高到低分配 $3, 0, 1, 0, 1$ 枚金币，分得金币的三名海盗均会投赞成票。
另一方面，$c(5, 1, \frac{1}{10}) = 0$ 且 $w(5, 1, \frac{1}{10}) = 1$：最资深海盗无论提出何种方案均无法存活，随后第二资深的海盗为了活命必须将唯一的金币分给另一名海盗。

定义：

$$
T(N, C, p) = \sum_{n=1}^N \big( c(n, C, p) + w(n, C, p) \big)
$$

已知 $T(30, 3, \frac{1}{\sqrt{3}}) = 190$，$T(50, 3, \frac{1}{\sqrt{31}}) = 385$，以及 $T(10^3, 101, \frac{1}{\sqrt{101}}) = 142427$。

求：

$$
\sum_{k=1}^6 T\left(10^{16}, 10^k + 1, \frac{1}{\sqrt{10^k + 1}}\right)
$$

给出答案的最后 9 位数字。
