# 哥德巴赫的另一个猜想

> 中文意译。英文原文见 [Project Euler Problem 46](https://projecteuler.net/problem=46)；抓取底稿见 `statement.en.md`。

克里斯蒂安·哥德巴赫曾提出猜想：**每个奇合数**都可以写成**一个素数加上一个平方数的两倍**的形式，即

$$n = p + 2k^2$$

其中 $p$ 是素数，$k$ 是正整数。例如：

| 奇合数 | 分解 |
|--------|------|
| 9  | $7 + 2 \times 1^2$ |
| 15 | $7 + 2 \times 2^2$ |
| 21 | $3 + 2 \times 3^2$ |
| 25 | $7 + 2 \times 3^2$ |
| 27 | $19 + 2 \times 2^2$ |
| 33 | $31 + 2 \times 1^2$ |

事实证明这个猜想是**错误**的。

那么，**不能**表示为一个素数与某个平方数两倍之和的最小奇合数是多少？
