# 618 · 给定质因数和之数

> 中文意译。英文原文见 [Project Euler Problem 618](https://projecteuler.net/problem=618)；抓取底稿见 `statement.en.md`。

考虑数 $15$、$16$ 和 $18$：

$15=3\times 5$，且 $3+5=8$。

$16 = 2\times 2\times 2\times 2$，且 $2+2+2+2=8$。

$18 = 2\times 3\times 3$，且 $2+3+3=8$。

$15$、$16$ 和 $18$ 是仅有的质因数（按重数计）之和为 $8$ 的数。

定义 $S(k)$ 为所有质因数（按重数计）之和为 $k$ 的数 $n$ 之和。因此 $S(8) = 15+16+18 = 49$。

其他例子：$S(1) = 0$，$S(2) = 2$，$S(3) = 3$，$S(5) = 5 + 6 = 11$。

Fibonacci 序列为 $F_1 = 1$，$F_2 = 1$，$F_3 = 2$，$F_4 = 3$，$F_5 = 5$，……。

求 $\displaystyle\sum_{k=2}^{24}S(F_k)$ 的最后九位数字。
