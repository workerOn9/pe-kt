# 527 · 随机二分查找

> 中文意译。英文原文见 [Project Euler Problem 527](https://projecteuler.net/problem=527)；抓取底稿见 `statement.en.md`。

在范围 $1 \le t \le n$ 内随机选取一个秘密整数 $t$。

目标是通过整数 $g$ 反复猜测 $t$ 的值。每猜一次会得到三种结果之一：$g \lt t$、$g = t$ 或 $g \gt t$。之后可以按需重复这一过程。

通常，标准二分查找能最小化平均所需的猜测次数：给定下界 $L$ 和上界 $H$（初始为 $L = 1$、$H = n$），令 $g = \lfloor (L+H)/2 \rfloor$，其中 $\lfloor \cdot \rfloor$ 是向下取整。若 $g = t$ 则过程结束；否则若 $g \lt t$，置 $L = g+1$，而若 $g \gt t$，置 $H = g-1$。更新边界后重复搜索，直到找到 $t$。即使 $t$ 无需搜索即可推断出来，也假定仍要进行一次搜索来确认它的值。

你的朋友 Bob 认为标准二分查找并不比他的随机版本好多少：不取 $g = \lfloor (L+H)/2 \rfloor$，而是令 $g$ 为 $L$ 到 $H$（含两端）之间的随机整数。算法的其余部分与标准二分查找相同。这种新的搜索策略称为随机二分查找。

对于在 $1 \le t \le n$ 中随机选取的 $t$，记 $B(n)$ 为用标准二分查找找到 $t$ 所需猜测次数的期望值，$R(n)$ 为用随机二分查找找到 $t$ 所需猜测次数的期望值。例如四舍五入到 $8$ 位小数，$B(6) = 2.33333333$，$R(6) = 2.71666667$。

求 $R(10^{10}) - B(10^{10})$，四舍五入到小数点后 $8$ 位。
