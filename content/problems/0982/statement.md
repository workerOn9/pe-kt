# 982 · 第三颗骰子

> 中文意译。英文原文见 [Project Euler Problem 982](https://projecteuler.net/problem=982)；抓取底稿见 `statement.en.md`。

爱丽丝（Alice）和鲍勃（Bob）用两颗六面骰子（点数为 $1$ 到 $6$）玩如下游戏：

1. 爱丽丝掷两颗骰子；她能看到掷出的点数，但鲍勃看不到；
2. 爱丽丝选择其中一颗骰子并向鲍勃展示其点数；
3. 鲍勃选择两颗骰子中的一颗：既可以选他看得到的那颗，也可以选盖着的那颗；
4. 爱丽丝向鲍勃支付鲍勃所选骰子朝上的点数对应的金额。

每名玩家制定一个（可能是非确定性的随机）策略。双方的一个示例策略如下：

- 爱丽丝选择展示点数最接近 $3.5$ 的骰子；若两颗骰子点数距离 $3.5$ 相同，则以各 $1/2$ 的概率随机选一颗展示；
- 鲍勃在展示的骰子点数至少为 $4$ 时选择展示的那颗；否则选择隐藏的那颗。

事实上，这两个策略组合构成了一个纳什均衡（Nash equilibrium）。也就是说，在鲍勃采用其策略的前提下，爱丽丝的策略使期望支付最小；而在爱丽丝采用其策略的前提下，鲍勃的策略使期望支付最大。

在此策略下，爱丽丝向鲍勃支付的期望金额为 $\frac{145}{36}\approx 4.027778$。

为了让游戏更有趣，他们引入了第三颗六面骰子：

1. 爱丽丝掷三颗骰子；她能看到所有点数，但鲍勃看不到；
2. 爱丽丝选择其中两颗骰子并向鲍勃同时展示它们；
3. 鲍勃从三颗骰子中选一颗：既可以选两颗可见骰子中的任意一颗，也可以选隐藏的那颗；
4. 爱丽丝向鲍勃支付鲍勃所选骰子朝上的点数对应的金额。

假定他们达成了一对构成纳什均衡的最优策略，求爱丽丝向鲍勃支付的期望金额，四舍五入保留小数点后六位数字。
