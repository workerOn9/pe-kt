# 821 · 123 可分离

> 中文意译。英文原文见 [Project Euler Problem 821](https://projecteuler.net/problem=821)；抓取底稿见 `statement.en.md`。

若整数集合 $S$ 满足 $S$、$2S$ 与 $3S$ 互不相交，则称 $S$ 是 123 可分离的。这里 $2S$ 与 $3S$ 分别由 $S$ 中所有元素乘以 $2$ 和乘以 $3$ 得到。

定义 $F(n)$ 为

$$
(S\cup 2S \cup 3S)\cap \{1,2,3,\ldots,n\}
$$

的元素个数的最大值，其中 $S$ 遍历所有 123 可分离集合。

例如 $F(6) = 5$，可由 $S = \{1,4,5\}$ 或 $S = \{1,5,6\}$ 取到。此外已知 $F(20) = 19$。

求 $F(10^{16})$。
