# 修改版斐波那契金块

> 中文意译。英文原文见 [Project Euler Problem 140](https://projecteuler.net/problem=140)；抓取底稿见 `statement.en.md`。

考虑无穷多项式级数

$$
A_G(x) = xG_1 + x^2G_2 + x^3G_3 + \cdots
$$

其中 $G_k$ 是二阶递推数列 $G_k = G_{k-1} + G_{k-2}$ 的第 $k$ 项，$G_1 = 1$、$G_2 = 4$，即 $1, 4, 5, 9, 14, 23, \dots$。

本题关心的是那些使 $A_G(x)$ 取正整数值的 $x$。前五个自然数所对应的 $x$ 列在下表中：

| $x$ | $A_G(x)$ |
|---|---|
| $\frac{\sqrt5 - 1}{4}$ | $1$ |
| $\frac25$ | $2$ |
| $\frac{\sqrt{22} - 2}{6}$ | $3$ |
| $\frac{\sqrt{137} - 5}{14}$ | $4$ |
| $\frac12$ | $5$ |

当 $A_G(x)$ 对应的 $x$ 是有理数时，我们称它为「金块」，因为这样的值越来越稀少；例如第 $20$ 个金块是 $211345365$。

求前三十个金块之和。
