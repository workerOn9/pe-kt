# 501 · 八约数计数

> 中文意译。英文原文见 [Project Euler Problem 501](https://projecteuler.net/problem=501)；抓取底稿见 `statement.en.md`。

$24$ 的八个约数是 $1, 2, 3, 4, 6, 8, 12$ 和 $24$。不超过 $100$ 且恰好有八个约数的数有十个：$24, 30, 40, 42, 54, 56, 66, 70, 78$ 和 $88$。记 $f(n)$ 为不超过 $n$ 且恰好有八个约数的数的个数。

已知 $f(100) = 10$，$f(1000) = 180$，$f(10^6) = 224427$。

求 $f(10^{12})$。
