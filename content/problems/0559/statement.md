# 559 · 置换矩阵

> 中文意译。英文原文见 [Project Euler Problem 559](https://projecteuler.net/problem=559)；抓取底稿见 `statement.en.md`。

若矩阵中第 $j$ 列的所有元素都小于第 $j + 1$ 列对应位置的元素，则称第 $j$ 列出现一次上升。

记 $P(k, r, n)$ 为具有以下性质的 $r \times n$ 矩阵的个数：

- 每一行都是 $\{1, 2, 3, \dots, n\}$ 的一个排列。
- 把第一列记为第 $1$ 列，则第 $j$ 列出现上升当且仅当 $j \lt n$ 且 $j$ 不是 $k$ 的倍数。

例如 $P(1, 2, 3) = 19$，$P(2, 4, 6) = 65508751$，$P(7, 5, 30) \bmod 1000000123 = 161858102$。

记 $Q(n) = \displaystyle \sum_{k=1}^n P(k, n, n)$。例如 $Q(5) = 21879393751$，$Q(50) \bmod 1000000123 = 819573537$。

求 $Q(50000) \bmod 1000000123$。
