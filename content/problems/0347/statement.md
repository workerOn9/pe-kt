# 347 · 只被两个素数整除的最大整数

> 中文意译。英文原文见 [Project Euler Problem 347](https://projecteuler.net/problem=347)；抓取底稿见 `statement.en.md`。

$\le 100$ 且只被素数 $2$ 与 $3$ 整除的最大整数是 $96$，因为 $96 = 32 \times 3 = 2^5 \times 3$。对两个不同的素数 $p$ 与 $q$，记 $M(p,q,N)$ 为 $\le N$ 且只被 $p$ 与 $q$ 整除的最大正整数；若不存在则为 $0$。

例如 $M(2,3,100)=96$；$M(3,5,100)=75$ 而不是 $90$，因为 $90$ 同时被 $2$、$3$、$5$ 整除。

$M(2,73,100)=0$，因为不存在 $\le 100$ 且同时被 $2$ 与 $73$ 整除的正整数。

记 $S(N)$ 为所有互不相同的 $M(p,q,N)$ 之和。$S(100)=2262$。

求 $S(10\,000\,000)$。
