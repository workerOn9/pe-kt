# 子三角形求和

> 中文意译。英文原文见 [Project Euler Problem 150](https://projecteuler.net/problem=150)；抓取底稿见 `statement.en.md`。

给定一个由正整数和负整数排成的三角数组，我们想找出一个子三角形，使其中所有数之和尽可能小。

在下面这个例子里可以验证，被标出的三角形满足这一条件，其和为 $-42$（原题此处为配图，这里按图示排成文字）。

```
       15
     -14   -7
    20  -13   -5
  -3    8   23  -26
   1   -4   -5  -18    5
 -16   31    2    9   28   3
```

现在要构造一个一千行的三角数组。为此按如下线性同余生成器（LCG）生成 500500 个落在 $\pm 2^{19}$ 范围内的伪随机数 $s_k$：

```
t := 0
for k = 1 up to k = 500500:
    t := (615949 × t + 797807) modulo 2^20
    s_k := t − 2^19
```

于是 $s_1 = 273519$，$s_2 = -153582$，$s_3 = 450905$，等等。

三角数组就由这些伪随机数排成：

```
s1
s2    s3
s4    s5    s6
s7    s8    s9    s10
...
```

子三角形可以从数组中的任意元素开始，并向下延伸任意多行（下一行取它正下方的两个元素，再下一行取正下方的三个元素，依此类推）。子三角形的和定义为其包含的所有元素之和。

求最小的子三角形和。
