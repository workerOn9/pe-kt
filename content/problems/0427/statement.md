# 427 · n-序列

> 中文意译。英文原文见 [Project Euler Problem 427](https://projecteuler.net/problem=427)；抓取底稿见 `statement.en.md`。

称一个整数序列 $S = \{s_i\}$ 为 $n$-序列，若它有 $n$ 个元素，且每个元素 $s_i$ 都满足 $1 \leq s_i \leq n$。因此这样的 $n$-序列共有 $n^n$ 个不同的。例如序列 $S = \{1,5,5,10,7,7,7,2,3,7\}$ 就是一个 $10$-序列。

对任意序列 $S$，令 $L(S)$ 为 $S$ 中取值相同的最长连续子序列的长度。例如对上面给出的序列，$L(S) = 3$，因为有三个连续的 $7$。

令 $f(n) = \sum L(S)$，求和遍及所有 $n$-序列 $S$。

例如 $f(3) = 45$，$f(7) = 1403689$，$f(11) = 481496895121$。

求 $f(7\,500\,000) \bmod 1\,000\,000\,009$。
