# 943 · 自描述序列

> 中文意译。英文原文见 [Project Euler Problem 943](https://projecteuler.net/problem=943)；抓取底稿见 `statement.en.md`。

给定两个不相等的正整数 $a$ 和 $b$，我们定义一个由交替出现的 $a$ 游程和 $b$ 游程组成的自描述序列。序列的第一项为 $a$，且游程长度序列恰好与原序列本身完全相同。

当 $a = 2, b = 3$ 时，该序列为：

$$
2, 2, 3, 3, 2, 2, 2, 3, 3, 3, 2, 2, 3, 3, 2, 2, 3, 3, 3, 2, 2, 2, 3, 3, 3, \dots
$$

序列以两个 $2$ 开头，接着是两个 $3$，随后是三个 $2$ 和三个 $3$，因此各游程的长度序列 $2, 2, 3, 3, \dots$ 正好由原序列给出。

设 $T(a, b, N)$ 为该序列前 $N$ 项之和。已知：
- $T(2, 3, 10) = 25$
- $T(4, 2, 10^4) = 30004$
- $T(5, 8, 10^6) = 6499871$

对所有满足 $2 \le a \le 223$、$2 \le b \le 223$ 且 $a \neq b$ 的对 $(a, b)$，求：

$$
\sum T(a, b, 22332223332233)
$$

输出其模 $2233222333$ 的余数。
