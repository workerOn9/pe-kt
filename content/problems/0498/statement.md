# 498 · 多项式除法的余数

> 中文意译。英文原文见 [Project Euler Problem 498](https://projecteuler.net/problem=498)；抓取底稿见 `statement.en.md`。

对正整数 $n$ 与 $m$，我们定义两个多项式 $F_n(x) = x^n$ 与 $G_m(x) = (x-1)^m$。

我们还定义多项式 $R_{n,m}(x)$ 为 $F_n(x)$ 除以 $G_m(x)$ 所得的余式。

例如 $R_{6,3}(x) = 15x^2 - 24x + 10$。

记 $C(n, m, d)$ 为 $R_{n,m}(x)$ 中 $d$ 次项系数的绝对值。

可以验证 $C(6, 3, 1) = 24$，$C(100, 10, 4) = 227197811615775$。

求 $C(10^{13}, 10^{12}, 10^4) \bmod 999999937$。
