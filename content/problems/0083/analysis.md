# 083 · 路径和：四种走法 — 解析

## 思路推导

把每个格子看成一个节点，相邻格子之间连一条有向边，边权为**目标格子的值**（这样从起点出发沿路径累加，恰好等于路径上所有格子之和，起点单独计入）。于是问题变成：

$$\min_{\text{路径 }(0,0)\to(n-1,n-1)}\ \sum_{\text{路径上的格 }v} a_v .$$

与 81 题不同，允许向左/向上后图中出现**环**，不再有拓扑序，一遍 DP 不再成立。但矩阵元素全是正数，边权严格为正，这带来两个关键性质：

1. **最优路径是简单路径**：若绕行成环，去掉环后每格的值都为正，代价严格下降；
2. **Dijkstra 的正确性前提成立**：已出堆（取到当前最小暂定距离）的节点距离即为最终答案，此后不会再被更短的路更新。

因此用优先队列实现 Dijkstra：每轮取出暂定距离最小的节点，向四个邻居做松弛。每个节点的入堆次数上界是它的入度（4），所以堆操作总量 $O(E)$，时间复杂度

$$O(E\log V)=O(4n^2\log n^2),$$

$n=80$ 时约 $6400\times4$ 次入堆、每次 $\log_2 6400\approx 13$ 次比较，非常轻。

**样例自检**：$5\times5$ 样例按同一份代码算得 $2297$，与题面一致；最优路径共 13 格，平均每格约 $177$，与矩阵元素量级相符。

答案：**425185**。

## 复杂度对比

| 方案 | 时间 | 实测（JIT 预热后） |
|------|------|------|
| 优化解：Dijkstra + 二叉堆 | $O(E\log V)=O(n^2\log n^2)$ | ~2.668 ms |
| 暴力解：Bellman–Ford 全图松弛，跑满 $V-1=n^2-1$ 轮 | $O(VE)=O(n^4)$——每轮 $4n^2$ 次松弛，共 $n^2$ 轮，约 $1.6\times10^8$ 次 | ~383.176 ms |

约 143 倍差距的根源是「出堆即定型」这条结论：Bellman–Ford 不承认任何节点已经算对，于是把同一批边反复检查几百轮；Dijkstra 用非负权这一前提把每格的处理次数压到常数次。

## 实现要点

- 用 `LongArray(3)`（距离、行、列）配合 `PriorityQueue(compareBy { it[0] })` 作堆元素，比定义 `data class` 更快也更省 GC；出堆后用 `if (d > dist[r][c]) continue` 跳过过期条目（惰性删除）
- 松弛的边权必须写成「邻居格的值」，起点在初始化时单独计入，避免起点被重复计算
- 越界检查用 `nr < 0 || nr >= n || nc < 0 || nc >= n`，不要用异常或包装数组
- 距离上界取 `Long.MAX_VALUE / 4` 而不是 `Long.MAX_VALUE`，避免松弛时的加法溢出
- 暴力解的轮数必须跑满 $n^2-1$（Bellman–Ford 的理论上界），不能加「本轮无更新就退出」的剪枝，否则会退化成两轮扫描而失去对照意义
