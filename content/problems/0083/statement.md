# 路径和：四种走法

> 中文意译。英文原文见 [Project Euler Problem 83](https://projecteuler.net/problem=83)；抓取底稿见 `statement.en.md`。

**注意**：本题是第 81 题的**大幅**高难度版本。

在下面这个 $5\times5$ 的矩阵中，从左上角走到右下角、允许向**左、右、上、下**四个方向移动时，最小路径和为 $2297$（下表中加粗的格子构成这条路径，同一格不重复计入）：

| | | | | |
|---|---|---|---|---|
| **131** | 673 | **234** | **103** | **18** |
| **201** | **96** | **342** | 965 | **150** |
| 630 | 803 | 746 | **422** | **111** |
| 537 | 699 | 497 | **121** | 956 |
| 805 | 732 | 524 | **37** | **331** |

请对 `matrix.txt`（一个约 31K 的文本文件，内含一个 $80\times80$ 的矩阵）求出从左上角到右下角、允许上下左右四个方向移动时的最小路径和。
