# 556 · 无平方因子的高斯整数

> 中文意译。英文原文见 [Project Euler Problem 556](https://projecteuler.net/problem=556)；抓取底稿见 `statement.en.md`。

高斯整数是形如 $z = a + bi$ 的数，其中 $a$、$b$ 是整数，且 $i^2 = -1$。高斯整数是复数的一个子集，而整数是其中 $b = 0$ 的那部分高斯整数。

高斯整数单位是满足 $a^2 + b^2 = 1$ 的那些，即 $1, i, -1, -i$ 之一。我们定义「真高斯整数」为满足 $a \gt 0$ 且 $b \ge 0$ 的高斯整数。

称高斯整数 $z_1 = a_1 + b_1 i$ 可被 $z_2 = a_2 + b_2 i$ 整除，如果 $z_3 = a_3 + b_3 i = z_1 / z_2$ 是高斯整数。

$$
\frac {z_1} {z_2} = \frac {a_1 + b_1 i} {a_2 + b_2 i} = \frac {(a_1 + b_1 i)(a_2 - b_2 i)} {(a_2 + b_2 i)(a_2 - b_2 i)} = \frac {a_1 a_2 + b_1 b_2} {a_2^2 + b_2^2} + \frac {a_2 b_1 - a_1 b_2} {a_2^2 + b_2^2}i = a_3 + b_3 i
$$

因此，$z_1$ 可被 $z_2$ 整除当且仅当 $\frac {a_1 a_2 + b_1 b_2} {a_2^2 + b_2^2}$ 和 $\frac {a_2 b_1 - a_1 b_2} {a_2^2 + b_2^2}$ 都是整数。例如，$2$ 可被 $1 + i$ 整除，因为 $2/(1 + i) = 1 - i$ 是高斯整数。

高斯素数是指只能被单位、它自身或它自身乘以单位整除的高斯整数。例如 $1 + 2i$ 是高斯素数，因为它只能被 $1$、$i$、$-1$、$-i$、$1 + 2i$、$i(1 + 2i) = i - 2$、$-(1 + 2i) = -1 - 2i$ 和 $-i(1 + 2i) = 2 - i$ 整除。$2$ 不是高斯素数，因为它可被 $1 + i$ 整除。

一个高斯整数可以唯一地分解为单位与若干个真高斯素数的乘积。例如 $2 = -i(1 + i)^2$，$1 + 3i = (1 + i)(2 + i)$。若一个高斯整数的素因子分解中不含重复的真高斯素数，则称它是无平方因子的。因此 $2$ 在高斯整数上不是无平方因子的，而 $1 + 3i$ 是。单位和按定义也是无平方因子的。

记 $f(n)$ 为满足 $a^2 + b^2 \le n$ 的真无平方因子高斯整数个数。例如 $f(10) = 7$，因为 $1$、$1 + i$、$1 + 2i$、$1 + 3i = (1 + i)(2 + i)$、$2 + i$、$3$ 和 $3 + i = -i(1 + i)(1 + 2i)$ 都是无平方因子的，而 $2 = -i(1 + i)^2$ 和 $2 + 2i = -i(1 + i)^3$ 不是。已知 $f(10^2) = 54$，$f(10^4) = 5218$，$f(10^8) = 52126906$。

求 $f(10^{14})$。
