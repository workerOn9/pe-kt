## 思路推导

**题目**：统计内切圆半径 $r \le n$ 的整数边 $60°$ 三角形个数 $T(n)$。

**几何转化**：$60°$ 三角形的三边 $(a,b,c)$ 满足余弦定理 $c^2 = a^2 + b^2 - ab$。
内切圆半径公式：
$$r = \frac{\sqrt{3}\,ab}{2(a+b+c)}$$

经推导（参见已知解答），可参数化所有本原解为互素对 $(p,q)$：
$$a = 2p-q, \quad b = 2q-p, \quad c = p+q$$
要求 $p > q > 0$、$\gcd(p,q)=1$、$p \not\equiv q \pmod 3$（后者保证恰好一个角为 $60°$）。
一般解再乘以整数因子 $k$，内切圆半径随之线性缩放。

**计数公式**：引入两个阈值 $M_1 = \lfloor 2n/\sqrt{3} \rfloor$、$M_2 = \lfloor 6n/\sqrt{3} \rfloor$，将解分为两类：

- 第一类（$p \not\equiv q \pmod 3$）：对每个满足条件的 $(p,q)$，贡献 $\lfloor M_1 / (pq) \rfloor$ 个解。
- 第二类（$p \equiv q \pmod 3$）：步长为 $3$ 扫描，贡献 $\lfloor M_2 / (pq) \rfloor$ 个解。

两个循环均只需枚举 $p,q \le \sqrt{M}$，总迭代量 $O(n)$。

**验证**：用 Python 独立实现，验证 $T(100)=1234$、$T(1000)=22767$、$T(10000)=359912$，均吻合。

## 教训

- 本题参数化来源于数论中 $60°$ 三角形的经典结果（参见 PE 论坛讨论）。
- 关键技巧是将"几何约束"转化为"整数对计数"，再用 Dirichlet 双曲和加速。
- 循环边界 $\sqrt{M_i}$ 约为 $1.2 \times 10^6$，在 90 分钟时限内绰绰有余。
