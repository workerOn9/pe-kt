# 143 · 托里拆利三角形 — 解析

## 思路推导

**第一步：把几何条件翻译成算术条件。** 费马点 $T$ 的特征是它与三个顶点连成的三条线段两两夹角都是 $120^\circ$（这正是 $p+q+r$ 取极值的驻点条件：沿任意方向微调 $X$，三条线段长度变化率之和为零，等价于三个方向的单位向量平衡，即两两成 $120^\circ$）。于是对三角形 $ATB$、$BTC$、$CTA$ 各用一次余弦定理，$\cos 120^\circ = -\tfrac12$ 使交叉项变成加号，得到

$$
a^2 = q^2 + qr + r^2,\qquad b^2 = p^2 + pq + q^2,\qquad c^2 = p^2 + pr + r^2,
$$

其中 $a = BC$、$b = CA$、$c = AB$，$p = XA$、$q = XC$、$r = XB$。

反过来，若正整数 $p,q,r$ 满足上面三式，就以 $T$ 为公共端点、沿两两成 $120^\circ$ 的三个方向分别截出长度 $p$、$q$、$r$ 的三段，得到 $A$、$C$、$B$ 三点。这时 $|AC|^2 = p^2+q^2+pq = b^2$，其余两边同理，所以这三点恰好构成题面里的三角形 $ABC$，而且 $T$ 严格在其内部。再补一句内角的论证：和函数 $\sum |X V_i|$ 是凸的，最小值唯一；若 $ABC$ 有内角 $\ge 120^\circ$，最小值点会落在该钝角顶点上，与「内部点 $T$ 也取到最小值」矛盾。因此 **三式成立 ⟺ 存在一个各内角 $<120^\circ$ 的托里拆利三角形**，几何部分到此完全消掉。

**第二步：图论建模。** 把每个正整数看作顶点，把满足「$x^2+xy+y^2$ 是完全平方数」的数对 $\{x,y\}$（下称 120° 对）看作边，则一个托里拆利三角形就是图中的一个三点两两相邻的三元组（3-团）$\{p,q,r\}$，要求 $p+q+r \le 120000$；题目要的是这些和的**去重**求和。注意 $x=y$ 时 $x^2+xy+y^2 = 3x^2$ 不是平方数，所以团内的三个数必然互不相同，把团写成 $a<b<c$ 不会有重复计数。

**第三步：造出全部 120° 对。** 直接按定义枚举要 $O(L^2)\approx 7.2\times10^9$ 次判定，必须换参数化。在艾森斯坦整数环里看这件事：令 $\rho = \mathrm{e}^{2\pi\mathrm{i}/3}$，$N(u+v\rho) = u^2-uv+v^2$，于是

$$
x^2+xy+y^2 = N(x - y\rho).
$$

$\mathbb{Z}[\rho]$ 是唯一分解整环。若 $x^2+xy+y^2 = z^2$ 且 $\gcd(x,y)=1$，则 $x-y\rho$ 的每个素因子指数都必须成对出现：对互不相伴的共轭素因子 $\pi\ne\bar\pi$ 来说，$v_\pi(\alpha)+v_{\bar\pi}(\alpha)$ 是偶数，而 $\pi\bar\pi = p$ 同时整除 $\alpha$ 会迫使 $p\mid x$ 且 $p\mid y$，与本原性矛盾；唯一的分歧素因子 $1-\rho$ 也不整除 $\alpha$（$1-\rho \mid x-y\rho \iff 3 \mid x-y$，本原解没有这一性质）。于是 $\alpha = x-y\rho$ 必是某个元素的平方再乘一个单位：$x - y\rho = \rho^{k}(u+v\rho)^2$。展开三个单位分支，取 $\rho^2$ 那一支得

$$
x = 2uv-u^2,\qquad y = u^2-v^2,\qquad z = u^2-uv+v^2 ,
$$

再取 $u = m+n$、$v = m$（$m>n>0$）即得到本题使用的形式

$$
x = m^2-n^2,\qquad y = 2mn+n^2,\qquad z = m^2+mn+n^2,\qquad x+y = m^2+2mn = m(m+2n).
$$

直接展开也能验证恒等式（$A^2+AB+B^2$ 在此处展开为 $(m^2+mn+n^2)^2$）。另两个单位分支只是把 $(x,y)$ 的符号或次序换一换，取 $m>n>0$ 并对每对取 $\min/\max$ 后都并进同一批边。$k$ 取遍正整数就覆盖了非本原的情形（$3\mid(m-n)$ 的那部分会重复产出，靠去重处理即可），所以 $m,n,k$ 三重循环**取遍全部** 120° 对：固定 $(m,n)$ 后只有 $k \le L/(m^2+2mn)$ 个倍数，总量实测 277767 条候选、去重后 **147707 条边**、**35333 个顶点**，远小于 $L^2$。

**第四步：三点两两相邻。** 只存「比自己大的邻居」的上邻接表（升序）。和 $\le L$ 的三元组里任意两数之和必 $\le L$，所以建图时用 $x+y\le L$ 截断不丢解。枚举每条边 $(a,b)$（$a<b$），把 $\mathrm{adj}(a)$ 与 $\mathrm{adj}(b)$ 求有序交集：交集里的元素 $c$ 必然 $>b$，正好构成 $a<b<c$ 的团，一边求交一边用 $a+b+c>L$ 提前退出（$c$ 递增）。命中的和放进 `HashSet`，最后求和。

## 独立验证与答案

**第二条路径（`brute-force.kt`）完全不用参数化。** 它从定义出发固定 $x$ 解 $y$：把式子配成

$$
(2y+x)^2 = 4z^2-3x^2 ,\qquad\text{即}\qquad (2z-w)(2z+w) = 3x^2\ (w = 2y+x),
$$

于是枚举 $3x^2$ 的因子对 $A\le B$，令 $A = 2z-w$、$B = 2z+w$，解出 $z = (A+B)/4$、$y = (B-A-2x)/4$，用条件 $A+B\equiv 0 \pmod 4$ 与 $w\equiv x \pmod 2$ 筛掉非整数解，再逐条用定义式复核。$x$ 的素因子来自最小素因子筛，$3x^2$ 的因子指数 = $x$ 的指数翻倍（素因子 3 多算一次）。这条路径不依赖「参数化是否取遍所有解」这个前提：它按定义式 $x^2+xy+y^2=z^2$ 枚举出该范围内的**全部** 120° 对，而参数化给出的每条边都天然满足定义式（由第三步的恒等式），两者实跑出来的边数同为 147707，故边集完全相同；再往上，团数（508）与最终答案也一致。另外还用一段独立的定义式枚举脚本在 $x+y\le 3000$ 的范围内逐对比较过，2304 条边一模一样。

**样例复现。** 题面 $a=399$、$b=455$、$c=511$ 对应 $p,q,r = 195,264,325$：$195^2+195\cdot264+264^2 = 399^2$、$195^2+195\cdot325+325^2 = 455^2$、$264^2+264\cdot325+325^2 = 511^2$，三数之和 $784$。两份代码都把这三个等式写成运行时断言，并断言上限取 $784$ 时该和解在集合里、上限取 $783$ 时集合为空（$784$ 是全局最小和）。

**内角条件的复核。** 对全部 508 个团还原三边长并算内角：最大内角 $116.2717^\circ$、最小 $3.1746^\circ$，没有一个内角 $\ge 120^\circ$，三角不等式也全部成立。最小角出现在团 $(2709,4515,110960)$：它给出的三边是 $6321$、$112339$、$113285$，前两边之和只比第三边大一点，$3.17^\circ$ 的内角正对着最长的边。这直接支撑了第一步「三式成立 ⟺ 存在合法三角形」的等价性。

**去重不是形式上的保险。** 508 个团只给出 **491 个不同的和**：17 个团是多余的，例如和 $16464$ 同时来自 $(4095,5544,6825)$ 与 $(4224,5200,7040)$。若按团累加，会得到 $32029046$，比正确答案多 $1270649$。

完整范围内最大的和是 $119952$，不同的和共 491 个，答案为 **30758397**。

## 复杂度对比

| 方案 | 时间 | 空间 | 实测（JIT 预热后） |
|---|---|---|---|
| 优化：艾森斯坦参数化 + 排序去重 + CSR 上邻接表求交 | $O(E\log E + \sum_v \deg^2 v)$ | $O(L+E)$ | 23.5309 ms |
| 对照：定义式固定 $x$ 解 $y$ + 哈希查边 | $O\big(\sum_{x<L} d(3x^2) + 739451\big)$ | $O(L+E)$ | 187.6677 ms |

其中 $E = 147707$、$L = 120000$；对照解的因子枚举总量实测 $\sum_{x<L}d(3x^2) = 10299946$（最大单点是 $x = 110880$ 的 $1782$ 个因子），它还要做 739451 次哈希查边。优化解比对照解快约 $8.0$ 倍，差距主要来自「每对候选都要展开因子并查一次哈希」与「每条边只走一次线性扫描」的不同。

计时口径：两个解都在程序内 JIT 预热后自报耗时，由主 Agent 在空闲机器上各编译一次、独立进程重复 5 次取最小值；数字已同步进 `meta.json` 的两个 baseline 字段。计时覆盖完整的求解函数，包括候选生成、排序去重、建图与三元组搜索，不含样例断言、编译与输出。

## 实现要点

- **参数化一定会有重复。** $3\mid(m-n)$ 的 $(m,n)$ 会把本原解放大后重复产出（原始候选 277767 条 vs 去重后 147707 条），所以顺序是「先排序去重、再建 CSR」，而不是边生成边信任。
- **必须只存上邻接。** 若存双向邻接再在交集里判断 $c>b$，写法上没有错，但键空间和常数都翻倍；只存 $v\to(>v)$ 的邻居后，交集结果天然满足 $a<b<c$，一个团只被数一次。
- **截断只用 $x+y\le L$。** 和 $\le L$ 的团里任两数之和必然 $\le L$，所以这个上界不丢解；若改成 $x+y \le \lfloor L/2\rfloor$ 之类就会漏解。
- **平方判定用整数阈值比较**，不用 `sqrt` 的浮点结果直接下结论；坐标到 $10^5$ 量级时 $x^2+xy+y^2$ 已远超 $2^{31}$（对照解里 $3x^2$ 最大约 $4.3\times10^{10}$），一律用 `Long`。
- 对照解的因子对筛选里 $A\le\sqrt{3x^2}$ 与 $A+B\equiv0\pmod4$ 两个条件缺一不可，漏掉前一个每个 $y$ 会被算两次，漏掉后一个会产出非整数的 $z$。
- 团的数量（508）与和的数量（491）不等，集合语义必须落实在代码里，不能只写在注释里。
