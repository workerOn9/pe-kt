# 托里拆利三角形

> 中文意译。英文原文见 [Project Euler Problem 143](https://projecteuler.net/problem=143)；抓取底稿见 `statement.en.md`。

设 $ABC$ 是一个三个内角都小于 $120^\circ$ 的三角形，$X$ 是它内部的任意一点，记

$$
XA = p,\qquad XC = q,\qquad XB = r.
$$

费马请托里拆利找出使 $p + q + r$ 最小的点 $X$ 的位置。

托里拆利证明了：若在三角形 $ABC$ 的三条边上分别作出等边三角形 $AOB$、$BNC$、$AMC$，则这三个等边三角形的外接圆会交于三角形内部的同一点 $T$；他还证明了 $T$（称为托里拆利点／费马点）正是使 $p + q + r$ 最小的点。更值得注意的是，当这个和取到最小值时，有

$$
AN = BM = CO = p + q + r,
$$

并且 $AN$、$BM$、$CO$ 三者也交于 $T$。

如果 $p + q + r$ 取到最小值时 $a, b, c, p, q, r$ 全都是正整数，我们就称三角形 $ABC$ 是一个托里拆利三角形。例如 $a = 399$、$b = 455$、$c = 511$ 就是一个托里拆利三角形，此时 $p + q + r = 784$。

求所有托里拆利三角形中不同的 $p + q + r \le 120000$ 之和。
