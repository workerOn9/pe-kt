# 统计数字

## 问题转化

$f(n, d)$ 表示在 $[0, n]$ 的十进制表示中数字 $d$ 出现的总次数。求所有满足 $f(n, d) = n$ 的正整数 $n$ 之和（对 $d = 1..9$ 汇总）。

## 数位计数公式

对每一位 $t$（权重 $10^t$），设 $high = n / 10^{t+1}$，$cur = (n/10^t) \mod 10$，$low = n \mod 10^t$：

- $cur > d$：该位贡献 $(high + 1) \cdot 10^t$
- $cur = d$：该位贡献 $high \cdot 10^t + low + 1$
- $cur < d$：该位贡献 $high \cdot 10^t$

求和即得 $f(n, d)$。

## 二分/分治剪枝

$f(n, d) - n$ 具有 Lipschitz 性质：相邻点差值 $\leq 13$（十进制位数）。对每个 $d$，用分治法枚举区间 $[lo, hi]$，若两端同号且超出 $\pm 12$，跳过整段。上界 $10^{12}$ 已足够覆盖所有解。

## 答案

Python 分治枚举得到 $d=1..9$ 的所有不动点并求和：

$$\sum_{d=1}^{9} s(d) = 21\,295\,121\,502\,550$$
