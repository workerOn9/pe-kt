# 511 · 整除性质优良的序列

> 中文意译。英文原文见 [Project Euler Problem 511](https://projecteuler.net/problem=511)；抓取底稿见 `statement.en.md`。

记 $Seq(n,k)$ 为长度为 $n$ 的正整数序列 $\{a_i\}_{1 \le i \le n}$ 的个数，使得：

- 对 $1 \le i \le n$，$n$ 能被 $a_i$ 整除；
- $n + a_1 + a_2 + \cdots + a_n$ 能被 $k$ 整除。

举例：

$Seq(3,4) = 4$，这 $4$ 个序列为

$\{1, 1, 3\}$，$\{1, 3, 1\}$，$\{3, 1, 1\}$，$\{3, 3, 3\}$。

$Seq(4,11) = 8$，这 $8$ 个序列为

$\{1, 1, 1, 4\}$，$\{1, 1, 4, 1\}$，$\{1, 4, 1, 1\}$，$\{4, 1, 1, 1\}$，$\{2, 2, 2, 1\}$，$\{2, 2, 1, 2\}$，$\{2, 1, 2, 2\}$，$\{1, 2, 2, 2\}$。

$Seq(1111,24)$ 的最后九位数字是 $840643584$。

求 $Seq(1234567898765,4321)$ 的最后九位数字。
