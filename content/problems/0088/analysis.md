# 088 · 乘积和数 — 解析

## 思路推导

设 $N$ 有一组元素个数为 $k$、取值全为自然数的乘积和表示。把其中所有 $1$ 单独拿出来：$N$ 的表示里若有 $c$ 个 $1$，剩下的 $m = k - c$ 个因子都 $\ge 2$，记它们的和为

$$s = f_1 + f_2 + \cdots + f_m, \qquad N = f_1 f_2 \cdots f_m .$$

由于 $1$ 对乘积没有贡献、每补一个 $1$ 就让和增加 $1$，补 $c$ 个 $1$ 后和恰好是 $s + c = N$，于是

$$\boxed{k = m + (N - s)}.$$

这条恒等式是全部推导的支点：**只要枚举 $N$ 的乘法分拆 $\{f_i\}$，就能立刻算出它对应的 $k$，不必为每个 $k$ 单独搜索。**

**搜索上界**：取 $\{f_i\} = \{2, k\}$ 再补 $k-2$ 个 $1$，得到 $k$ 项、乘积 $2k$、和 $2 + k + (k-2) = 2k$，是合法的乘积和表示。所以

$$\text{minimal}(k) \le 2k,$$

搜索只需覆盖 $N \le 2 \cdot 12000 = 24000$。

**算法**：用非降因子序的 DFS 枚举所有乘积不超过 $24000$ 的因子组合 $(f_1 \le f_2 \le \cdots \le f_m \le 24000)$，每走到一个状态就用 $k = m + (p - s)$（$p$ 为当前乘积）更新 `best[k] = min(best[k], p)`。非降序保证每个乘法分拆只被枚举一次，`p·f ≤ 24000` 的剪枝砍掉一切不可能成为最小值的分支。

最后把 $k = 2 \dots 12000$ 的 `best[k]` **按数值去重**后求和：同一个小 $N$ 可以是多个 $k$ 的最小值（题面里 $8$ 同时是 $k=4,5$ 的最小值），题面明确要求只计一次。

## 复杂度对比

| 方案 | 时间 | 实测（JIT 预热后） |
|------|------|------|
| 优化解：非降因子序 DFS，用 $k = m + (N-s)$ 边走边更新 `best[k]` | 与枚举到的乘法分拆个数同阶（远小于 $O(2K\log 2K)$） | ~1.368 ms |
| 暴力解：对每个 $N \le 2K$ 递归枚举它的全部乘法分拆再反推 $k$ | $O\left(\sum_{N \le 2K}\sqrt N \cdot \text{分拆数}\right)$ | ~13.928 ms |

暴力解多做了「每个 $N$ 都重跑一遍因数试除递归」这一层开销，因此约慢一个数量级；两者都远快于「对每个 $k$ 从小到大试 $N$」的朴素做法——那种写法要检查约 $\sum_k (2k - k) = 7\times10^7$ 次，每次还要判可否分拆。

## 实现要点

- 关键恒等式 $k = m + (p - s)$：把「补 1」这一 $O(N)$ 的自由度折叠成一次算术，是整个算法的核心
- 上界 $2k$ 必须证明后再用：它同时决定数组大小与 DFS 剪枝的阈值
- DFS 因子必须非降序（`minFactor` 参数），否则同一分拆会以多种排列被重复枚举
- 求和前按 $N$ 去重：不同 $k$ 共享同一个最小值是常见情形，漏掉去重会得到偏大的结果
- 若只对 $k=2\dots12$ 跑一遍，应得到 $61$，可作为实现正确性的自检
