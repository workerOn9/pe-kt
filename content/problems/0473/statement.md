# 473 · 黄金数制

> 中文意译。英文原文见 [Project Euler Problem 473](https://projecteuler.net/problem=473)；抓取底稿见 `statement.en.md`。

令 $\varphi$ 为黄金比：$\varphi = \frac{1 + \sqrt{5}}{2}$。

值得注意的是，即使要求每个 $\varphi$ 的幂在这个和式中至多使用一次，也仍然可以把每个正整数都写成若干个 $\varphi$ 的幂之和。
即便如此，这种表示仍不唯一。
若进一步要求不出现指数相邻的幂，且表示是有限的，则表示就唯一了。
例如 $2 = \varphi + \varphi^{-2}$，$3 = \varphi^{2} + \varphi^{-2}$。

为了表示这样的 $\varphi$ 的幂之和，我们使用一个由 0 和 1 组成的字符串，并用一个点标出负指数从哪里开始。
我们称之为该数在**黄金数制（phigital number base）**下的表示。
于是 $1 = 1_{\varphi}$，$2 = 10.01_{\varphi}$，$3 = 100.01_{\varphi}$，$14 = 100100.001001_{\varphi}$。

$1$、$2$ 和 $14$ 在黄金数制下的表示字符串是回文的，而 $3$ 的不是（黄金数制的那个点并不是正中间的字符）。

不超过 $1000$ 且黄金数制表示为回文的正整数之和是 $4345$。

求不超过 $10^{10}$ 且黄金数制表示为回文的正整数之和。
