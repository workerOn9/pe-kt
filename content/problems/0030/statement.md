# 各位数字的五次方

> 中文意译。英文原文见 [Project Euler Problem 30](https://projecteuler.net/problem=30)；抓取底稿见 `statement.en.md`。

令人意外的是，能写成其各位数字的四次方之和的数只有三个：

| 数字 | 验证 |
|------|------|
| $1634$ | $1634 = 1^4 + 6^4 + 3^4 + 4^4$ |
| $8208$ | $8208 = 8^4 + 2^4 + 0^4 + 8^4$ |
| $9474$ | $9474 = 9^4 + 4^4 + 7^4 + 4^4$ |

其中 $1 = 1^4$ 不算在内，因为它并不是「和」。

这三个数之和为 $1634 + 8208 + 9474 = 19316$。

求：所有能写成其各位数字的五次方之和的数，它们的总和是多少？
