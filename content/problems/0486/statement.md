# 486 · 含回文的字符串

> 中文意译。英文原文见 [Project Euler Problem 486](https://projecteuler.net/problem=486)；抓取底稿见 `statement.en.md`。

记 $F_5(n)$ 为满足下列条件的字符串 $s$ 的个数：

- $s$ 只由字符 `0` 与 `1` 组成；
- $s$ 的长度不超过 $n$；
- $s$ 含有一个长度至少为 $5$ 的回文子串。

例如 $F_5(4) = 0$，$F_5(5) = 8$，$F_5(6) = 42$，$F_5(11) = 3844$。

记 $D(L)$ 为满足 $5 \le n \le L$ 且 $F_5(n)$ 能被 $87654321$ 整除的整数 $n$ 的个数。

例如 $D(10^7) = 0$，$D(5 \cdot 10^9) = 51$。

求 $D(10^{18})$。
