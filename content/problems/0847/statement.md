# 847 · 杰克的豆子

> 中文意译。英文原文见 [Project Euler Problem 847](https://projecteuler.net/problem=847)；抓取底稿见 `statement.en.md`。

杰克面前放着三个盘子。巨人把 $N$ 颗豆子分配在这三个盘子里。所有的豆子看起来一模一样，但其中有一颗是魔法豆。杰克不知道哪一颗是魔法豆，但巨人知道。

杰克可以向巨人提问，问题的形式为："这组豆子里包含魔法豆吗？" 每次提问时，杰克可以从**某一个盘子**中任选一个豆子子集，巨人会如实回答"是"或"否"。

如果这三个盘子分别装有 $a$、$b$ 和 $c$ 颗豆子，我们用 $h(a, b, c)$ 表示杰克为了确保能找出魔法豆所需提问的最小次数。例如，$h(1, 2, 3) = 3$ 且 $h(2, 3, 3) = 4$。

设 $H(N)$ 为所有满足 $1 \le a + b + c \le N$ 的非负整数三元组 $(a, b, c)$ 的 $h(a, b, c)$ 之和。
已知：$H(6) = 203$ 且 $H(20) = 7718$。

全 1 数（repunit）$R_n$ 是由 $n$ 个数字 '1' 组成的整数。例如 $R_3 = 111$，且 $H(R_3) = 1634144$。

求 $H(R_{19})$ 对 $1\,000\,000\,007$ 取模的值。
