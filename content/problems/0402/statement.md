# 402 · 整数值多项式

> 中文意译。英文原文见 [Project Euler Problem 402](https://projecteuler.net/problem=402)；抓取底稿见 `statement.en.md`。

可以证明：多项式 $n^4 + 4n^3 + 2n^2 + 5n$ 对每个整数 $n$ 都是 $6$ 的倍数；也可以证明 $6$ 是满足这一性质的最大的整数。

定义 $M(a, b, c)$ 为最大的 $m$，使得对所有整数 $n$，$n^4 + an^3 + bn^2 + cn$ 都是 $m$ 的倍数。例如 $M(4, 2, 5) = 6$。

再定义 $S(N)$ 为所有满足 $0 \lt a, b, c \leq N$ 的 $M(a, b, c)$ 之和。

可以验证 $S(10) = 1972$ 与 $S(10000) = 2024258331114$。

设 $F_k$ 为斐波那契数列：$F_0 = 0$，$F_1 = 1$，且当 $k \geq 2$ 时 $F_k = F_{k-1} + F_{k-2}$。

求 $2 \leq k \leq 1234567890123$ 时 $\sum S(F_k)$ 的最后 $9$ 位。
