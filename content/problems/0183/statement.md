# 拆分的最大乘积

设 $N$ 为正整数，将 $N$ 拆分为 $k$ 个相等的部分 $r = N/k$，使得 $N = r + r + \cdots + r$。
令这些部分的乘积为 $P = r^k = (N/k)^k$。

例如若将 $11$ 拆分为 $5$ 等份，每份为 $2.2$，则乘积为 $P = 2.2^5 = 51.53632$。

对于给定的 $N$，令 $M(N) = P_{\max}$ 为可能达到的最大乘积。

可以发现：
- 对 $N = 11$，取 $k = 4$ 时达到最大值 $P_{\max} = (11/4)^4 = 57.19140625$，这是一个**有限小数**；
- 对 $N = 8$，取 $k = 3$ 时达到最大值 $M(8) = (8/3)^3 = 512/27$，这是一个**无限循环小数**。

定义函数 $D(N)$：
- 若 $M(N)$ 为无限循环小数，则 $D(N) = N$；
- 若 $M(N)$ 为有限小数，则 $D(N) = -N$。

例如已知 $\sum_{N = 5}^{100} D(N) = 2438$。

求 $\sum_{N = 5}^{10000} D(N)$ 的值。
