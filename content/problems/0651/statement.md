# 651 · 带图案的圆柱

> 中文意译。英文原文见 [Project Euler Problem 651](https://projecteuler.net/problem=651)；抓取底稿见 `statement.en.md`。

一个无限长的圆柱，其曲面上完整地贴满颜色各异但形状相同的矩形贴纸，互不重叠。贴纸与圆柱对齐，因此有两条边平行于圆柱的轴，每个角处有四张贴纸相接。

设 $a>0$，并假设着色沿圆柱是周期的，图案每隔 $a$ 张贴纸重复一次。（周期可以是 $a$ 的任意因数。）设 $b$ 为沿圆柱一周能容纳的贴纸数。

设 $f(m, a, b)$ 为恰好使用 $m$ 种不同贴纸颜色的这种周期图案的个数。对图案作沿轴的平移、关于任意平面的反射、绕任意轴的旋转（或这些操作的组合），都视为与原图案相同。

已知 $f(2, 2, 3) = 11$，$f(3, 2, 3) = 56$，$f(2, 3, 4) = 156$。此外，$f(8, 13, 21) \equiv 49718354 \pmod{1\,000\,000\,007}$，$f(13, 144, 233) \equiv 907081451 \pmod{1\,000\,000\,007}$。

求 $\sum_{i=4}^{40} f(i, F_{i-1}, F_i) \bmod 1\,000\,000\,007$，其中 $F_i$ 是从 $F_0=0$，$F_1=1$ 开始的斐波那契数。
