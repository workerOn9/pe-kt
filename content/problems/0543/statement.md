# 543 · 素数和数

> 中文意译。英文原文见 [Project Euler Problem 543](https://projecteuler.net/problem=543)；抓取底稿见 `statement.en.md`。

定义函数 $P(n, k)$：若 $n$ 能写成 $k$ 个素数之和（允许重复使用同一个素数），则 $P(n, k) = 1$，否则 $P(n, k) = 0$。

例如 $P(10,2) = 1$，因为 $10$ 既能写成 $3 + 7$ 也能写成 $5 + 5$；而 $P(11,2) = 0$，因为没有两个素数之和等于 $11$。

记 $S(n)$ 为所有 $1 \leq i,k \leq n$ 的 $P(i,k)$ 之和。

例如 $S(10) = 20$，$S(100) = 2402$，$S(1000) = 248838$。

记 $F(k)$ 为第 $k$ 个斐波那契数（其中 $F(0) = 0$，$F(1) = 1$）。

求所有 $3 \leq k \leq 44$ 的 $S(F(k))$ 之和。
