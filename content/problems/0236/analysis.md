# 236 — Luxury Hampers（豪华礼篮）

## 建模：把两组分数条件变成整数线性方程

记 $A_i$、$B_i$ 为两家供应商第 $i$ 种商品的供货量，$a_i$、$b_i$ 为各自坏掉的件数（均为正整数）。题设是

$$
\frac{b_i}{B_i} = m\cdot\frac{a_i}{A_i}\quad(\forall i),
\qquad
\frac{\sum a_i}{\sum A_i} = m\cdot\frac{\sum b_i}{\sum B_i}.
$$

提出 $A_i$、$B_i$ 的公共因子 $g_i = \gcd(A_i,B_i)$，写成 $A_i = g_i a'_i$、$B_i = g_i b'_i$，并令 $m = u/v$ 为最简分数。单项条件 $b_i a'_i v = a_i b'_i u$ 的通解是

$$
a_i = p_i k_i,\qquad b_i = s_i k_i,\qquad
p_i = \frac{v a'_i}{G_i},\quad s_i = \frac{u b'_i}{G_i},\quad G_i = \gcd(v a'_i,\, u b'_i),\quad k_i \ge 1 .
$$

$\sum A = 18880 = 64\cdot 295$、$\sum B = 15744 = 64\cdot 246$，于是总量条件等价于一个整数线性方程：

$$
\boxed{\ \sum_{i=1}^{5} D_i k_i = 0,\qquad D_i = 246\,v\,p_i - 295\,u\,s_i,\qquad 1 \le k_i \le \mathrm{cap}_i\ }
$$

其中 $\mathrm{cap}_i = \min\bigl(g_i a'_i/p_i,\ g_i b'_i/s_i,\ \lfloor\sum A/p_i\rfloor,\ \lfloor\sum B/s_i\rfloor\bigr)$。

注意 $\sum a_i \le \sum A$：所有 $a_i \ge 1$，所以 $k_i \ge 1$ 且 $\sum p_i k_i \le \sum A = 18880$。

## 三个把候选压到可枚举的观察

**(1) $m$ 有硬上界。** $D_i > 0 \iff m^2 < \dfrac{246\,a'_i}{295\,b'_i}$。对 $(a'_i,b'_i) = (41,59)$ 的四种商品阈值是 $\sqrt{0.5795} = 0.761$（$m>1$ 时恒负），给出上界的是 $(41,5)$ 的那种商品，阈值 $\sqrt{10086/1475} = 2.61495\ldots$。$m$ 超过它以后所有 $D_i \le 0$，而它们又不可能同时为 $0$，方程无解。

**(2) 两条廉价必要条件。** $\sum p_i \le 18880$ 与 $\sum s_i \le 15744$（由 $k_i\ge1$ 与 $\sum a_i\le\sum A$、$\sum b_i\le\sum B$）。先算这两条，能刷掉绝大多数字母对。

**(3) $G_i$ 只可能是 $a'_i b'_i$ 的因子 —— 这条把 $v$ 也压住了。** 证明：设素数 $p \mid G_i$。若 $p \mid v$，由 $\gcd(u,v)=1$ 得 $p \nmid u$，而 $p \mid u b'_i$ 故 $p \mid b'_i$；否则 $p \mid a'_i$。于是 $G_i \mid a'_i b'_i$，对 $(41,59)$ 的商品 $G_i \in \{1,41,59,2419\}$：

- $41 \nmid u$：$G_i \le 59$，故 $p_i \ge 41v/59$，由 $3\cdot\frac{41v}{59} \le 18880$ 得 $v \le 9056$；
- $41 \mid u$：$41 \mid G_i$。若 $59 \nmid v$，则 $G_i = 41$、$p_i = v$，$3v \le 18880$ 即 $v \le 6293$（已含在上面）；
- $41 \mid u$ 且 $59 \mid v$：$G_i$ 可达 $2419$、$p_i = v/59$，此时 $v \le 70500$，必须单独扫 $u = 41u'$、$v = 59v'$。

两段并集 $\{v \le 9060\} \cup \{41\mid u,\ 59\mid v,\ v \le 70500\}$ 就是全部候选。（上一版的扫描范围 $u \le 5248$ 没有任何论证支撑，属于「碰巧覆盖了答案」。）

## 逐候选判定：合并同系数 + 扩展 gcd 收尾

对每个候选 $(u,v)$：

1. $D_i$ 全体除以公因数 $g = \gcd(D_1,\dots,D_5)$；
2. 把 $D$ 值相同的项**合并**成一个变量：若 $t$ 项系数同为 $d$、各自 $k$ 的上界为 $c_j$，则它们的和 $K$ 可以取 $[t,\ \sum c_j]$ 中的**每一个**整数（连续区间）；
3. 按区间从小到大枚举这些合并后的变量，每层用区间剪枝；
4. 只剩最后两个变量时用**扩展 gcd** 精确判定 $d_1k_1 + d_2k_2 = \mathrm{rem}$ 是否有整数解落在矩形内（一次 egcd + 参数 $t$ 的范围求交，$O(\log)$）。

以最大解 $m = 123/59$ 为例：$D = (312051,-94341,-94341,-1052265,-94341)$，除以 $7257$ 得 $(43,-13,-13,-145,-13)$，三个 $-13$ 合并后只剩 $3$ 个变量，枚举量从 $10^8$ 降到 $10^3$ 量级。上一版用「状态 = $(\sum p_ik_i,\, \sum s_ik_i)$ 的 HashMap 二维 DP」，在 $p_i=1$、$\mathrm{cap}_i$ 上千的候选上直接把堆吃爆（实测 `OutOfMemoryError`）。

## 答案

$$
\boxed{123/59}
$$

题面要求以最简分数 $u/v$ 作答；仓库 `ProblemMeta.answer` 是 `Long`，按「分数类答案先编码再存储」的约定（与 0175 的逗号串同理）定义

$$
\text{编码} = u\times 10^{6} + v = 123000059 .
$$

（分母最大只有 $1475$，$10^6$ 的位宽足够，且不会与任何 $u' \times 10^6 + v'$ 混淆。）

## 关键教训

- **「碰巧算对」不是正确性**。旧版扫描范围 $u \le 5248$ 没有任何推导，恰好覆盖了答案，于是把这个错误当作「旁证」写了一整轮。**范围必须有论证**：先证 $m$ 的上界，再用 $G_i \mid a'_ib'_i$ 把 $v$ 也压住，然后把「余下的小范围 + 两条必要条件」写成可复核的推理链。
- **枚举范围与判定方法要分开审计**：错误的判定会漏解，错误的范围会漏候选，两者症状相同（答案偏小），只有分别与独立的第三实现对照才能定位。
- **先归一化再搜索**：除以 $\gcd$ 与合并同系数把系数表从 $10^6$ 量级降到 $10^2$，也让「三个 $-13$ 只需知道它们的和」这一结构显形；不做这一步，搜索量差五个数量级。
- **扩展 gcd 是收尾的万能钥匙**：把 $n$ 元一方程的搜索降到 $n-2$ 元枚举 + 一次 $O(\log)$ 判定，且顺带给出了完整的解区间。
