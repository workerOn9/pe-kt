# 396 · 弱 Goodstein 数列

> 中文意译。英文原文见 [Project Euler Problem 396](https://projecteuler.net/problem=396)；抓取底稿见 `statement.en.md`。

对任意正整数 $n$，第 $n$ 个**弱 Goodstein 数列** $\{g_1, g_2, g_3, \dots\}$ 定义如下：

- $g_1 = n$；
- 对 $k > 1$，$g_k$ 是通过将 $g_{k-1}$ 写成 $k$ 进制，再把该表达式当成 $k+1$ 进制的数并减去 $1$ 得到的；
- 当 $g_k$ 变成 $0$ 时数列终止。

例如第 $6$ 个弱 Goodstein 数列为 $\{6, 11, 17, 25, \dots\}$：

- $g_1 = 6$；
- $g_2 = 11$，因为 $6 = 110_2$，$110_3 = 12$，$12 - 1 = 11$；
- $g_3 = 17$，因为 $11 = 102_3$，$102_4 = 18$，$18 - 1 = 17$；
- $g_4 = 25$，因为 $17 = 101_4$，$101_5 = 26$，$26 - 1 = 25$；
- 依此类推。

可以证明每个弱 Goodstein 数列都会终止。

记 $G(n)$ 为第 $n$ 个弱 Goodstein 数列中非零项的个数。

已知 $G(2)=3$，$G(4)=21$，$G(6)=381$；且 $1 \le n < 8$ 时 $\sum G(n) = 2517$。

求 $1 \le n < 16$ 时 $\sum G(n)$ 的最后 $9$ 位。
