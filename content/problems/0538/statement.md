# 538 · 最大四边形

> 中文意译。英文原文见 [Project Euler Problem 538](https://projecteuler.net/problem=538)；抓取底稿见 `statement.en.md`。

考虑正整数序列 $S = (s_1, s_2, \dots, s_n)$。

记 $f(S)$ 为以 $S$ 的四个元素 $(s_i, s_j, s_k, s_l)$（$i,j,k,l$ 互不相同）为边长的最大面积四边形的周长。若面积相同的四边形有多个，则取周长最大的那个。

例如，若 $S = (8, 9, 14, 9, 27)$，我们可以取元素 $(9, 14, 9, 27)$，构成一个等腰梯形，其平行边长分别为 $14$ 和 $27$，两腰长均为 $9$。该四边形的面积为 $127.611470879\cdots$。可以证明这是用 $S$ 中的边长所能构成的最大面积。因此 $f(S) = 9 + 14 + 9 + 27 = 59$。

记 $u_n = 2^{B(3n)} + 3^{B(2n)} + B(n + 1)$，其中 $B(k)$ 是 $k$ 的二进制表示中 $1$ 的个数。例如 $B(6) = 2$，$B(10) = 2$，$B(15) = 4$，且 $u_5 = 2^4 + 3^2 + 2 = 27$。

又记 $U_n$ 为序列 $(u_1, u_2, \dots, u_n)$。例如 $U_{10} = (8, 9, 14, 9, 27, 16, 36, 9, 27, 28)$。

可以证明 $f(U_5) = 59$，$f(U_{10}) = 118$，$f(U_{150}) = 3223$，以及对 $4 \le n \le 150$ 有 $\sum f(U_n) = 234761$。

求对 $4 \le n \le 3\,000\,000$ 的 $\sum f(U_n)$。
