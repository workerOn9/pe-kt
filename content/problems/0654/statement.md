# 654 · 相邻约束

> 中文意译。英文原文见 [Project Euler Problem 654](https://projecteuler.net/problem=654)；抓取底稿见 `statement.en.md`。

设 $T(n, m)$ 为正整数 $m$ 元组的个数，其中元组中任意两个相邻元素之和 $\le n$。

例如，$T(3, 4)=8$，对应以下八个 $4$ 元组：
$(1, 1, 1, 1)$
$(1, 1, 1, 2)$
$(1, 1, 2, 1)$
$(1, 2, 1, 1)$
$(1, 2, 1, 2)$
$(2, 1, 1, 1)$
$(2, 1, 1, 2)$
$(2, 1, 2, 1)$

已知 $T(5, 5)=246$，$T(10, 10^{2}) \equiv 862820094 \pmod{1\,000\,000\,007}$，$T(10^2, 10) \equiv 782136797 \pmod{1\,000\,000\,007}$。

求 $T(5000, 10^{12}) \bmod 1\,000\,000\,007$。
