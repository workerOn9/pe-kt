# 奇数周期的平方根

> 中文意译。英文原文见 [Project Euler Problem 64](https://projecteuler.net/problem=64)；抓取底稿见 `statement.en.md`。

所有平方根写成连分数时都是周期的，可以写成：

$$\sqrt{N}=a_0 + \dfrac{1}{a_1 + \dfrac{1}{a_2 + \dfrac{1}{a_3 + \dots}}}$$

以 $\sqrt{23}$ 为例：

$$\sqrt{23} = 4 + \sqrt{23}-4 = 4 + \dfrac{1}{\dfrac{1}{\sqrt{23}-4}} = 4 + \dfrac{1}{1 + \dfrac{\sqrt{23}-3}{7}}$$

继续展开下去会得到

$$\sqrt{23}=4 + \dfrac{1}{1 + \dfrac{1}{3 + \dfrac{1}{1 + \dfrac{1}{8 + \dots}}}}$$

可以看出这个序列在重复。为简洁起见，记 $\sqrt{23}=[4;(1,3,1,8)]$，表示循环块 $(1,3,1,8)$ 无限重复。

最小的十个无理平方根的连分数表示为：

- $\sqrt{2}=[1;(2)]$，周期 $=1$
- $\sqrt{3}=[1;(1,2)]$，周期 $=2$
- $\sqrt{5}=[2;(4)]$，周期 $=1$
- $\sqrt{6}=[2;(2,4)]$，周期 $=2$
- $\sqrt{7}=[2;(1,1,1,4)]$，周期 $=4$
- $\sqrt{8}=[2;(1,4)]$，周期 $=2$
- $\sqrt{10}=[3;(6)]$，周期 $=1$
- $\sqrt{11}=[3;(3,6)]$，周期 $=2$
- $\sqrt{12}=[3;(2,6)]$，周期 $=2$
- $\sqrt{13}=[3;(1,1,1,1,6)]$，周期 $=5$

在 $N \le 13$ 中，恰好有 4 个连分数的周期是奇数。

$N \le 10\,000$ 的平方根中，有多少个连分数的周期为奇数？
