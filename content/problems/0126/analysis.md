# 126 · 立方体分层 — 解析

## 思路推导

**把「层」写成一个函数。** 设长方体的三边为 $a \le b \le c$，第 $k$ 层（$k \ge 1$）所需的单位立方体个数记为 $f(a,b,c,k)$。题面给出了足够多的锚点：$3\times2\times1$ 的第 1 到第 4 层是 $22,46,78,118$；$5\times1\times1$ 的第一层也是 $22$；$5\times3\times1$、$7\times2\times1$、$11\times1\times1$ 的第一层都是 $46$。这些数据全部指向同一个闭式

$$
f(a,b,c,k) = 2(ab+ac+bc) + 4(a+b+c)(k-1) + 4(k-1)(k-2).
$$

**逐项读它的几何含义。** 第一层是给每个可见的单位面各贴一个立方体，所以 $k=1$ 时后两项归零，$f = 2(ab+ac+bc)$ 正是原长方体的表面积——对 $3\times2\times1$ 就是 $2(6+3+2)=22$。再往上一层，立体沿外法向整体加厚：六个面的面积不变（仍是 $2(ab+ac+bc)$）；十二条棱各自展开一条宽 $k-1$ 的斜带，每条棱长与它贡献的单位方格数成正比，每个尺寸在四条棱上出现，于是这一部分合计 $4(a+b+c)(k-1)$；八个角各展开一块边长 $k-1$ 的阶梯三角面，每块含 $(k-1)(k-2)/2$ 个单位方格，八个角合计 $4(k-1)(k-2)$。取 $k=2,3,4$ 依次得到 $46,78,118$，与题面逐个吻合。

**相邻两层只差一个等差数列。** 直接相减得

$$
f(a,b,c,k+1)-f(a,b,c,k) = 4(a+b+c) + 8(k-1).
$$

也就是说，从 $f_1 = 2(ab+ac+bc)$ 出发，增量依次是 $4s,\ 4s+8,\ 4s+16,\dots$（$s=a+b+c$），这是一个公差恒为 $8$ 的等差数列。于是枚举时不必每层重算多项式：记下当前层大小与当前步长，一次加法就能走到下一层，再给步长加 $8$。这一改写把每次推层从「三次乘法」降到「两次整数加法」。

**计数对象是 (长方体, 层) 对。** 题面定义的

$$
C(n) = \#\{(a,b,c,k) : a \le b \le c,\ k \ge 1,\ f(a,b,c,k) = n\},
$$

其中 $a \le b \le c$ 是朝向上的规范化：$5\times3\times1$ 与 $3\times1\times5$ 是同一个长方体，只能数一次（题面的 $C(22)=2$ 正对应 $(1,1,5)$ 与 $(1,2,3)$ 这两种，而不是六种排列）。由于 $f$ 关于 $k$ 严格递增，同一个长方体不可能用两层贡献同一个 $n$，所以「数长方体」与「数 (长方体, 层) 对」在这个意义下等价。

**枚举空间的三条剪枝。** 记底面积 $P = 2(ab+ac+bc)$，它满足 $f(a,b,c,k) \ge P$，所以任何能贡献 $n \le L$ 的长方体都有 $P \le L$：

- 由 $a \le b \le c$ 得 $P \ge 6a^2$，故只需枚举 $6a^2 \le L$；
- 固定 $(a,b)$ 时 $P$ 关于 $c$ 严格递增，最小值在 $c=b$ 处取到 $4ab+2b^2$，故只需枚举到 $4ab+2b^2 \le L$；
- 内层 $c$ 从 $b$ 起自增，$P$ 一旦超过 $L$ 立即跳出。

**为什么扫到的第一个就是答案。** 设某层满足 $f = n \le L$，则它的长方体底面积 $P \le f \le L$，必被上面的枚举覆盖且其层循环一定推进到 $n$。所以只要上界 $L \ge n$，计数数组在下标 $n$ 处就是完整的；从 $1$ 开始扫描，第一个满足 $C(n)=1000$ 的 $n$ 就是全局最小值。上界不硬编码：从 $1000$ 起倍增，直到扫出结果为止，这样既不依赖对答案量级的猜测，也保证不会因上界偏小漏答案。

## 独立验证与答案

**第一条路径：题面锚点全部复现。** 闭式逐点对上 $f(3,2,1,k)$（$k=1,2,3,4$）$= 22,46,78,118$，以及「第一层为 22 或 46」的 $5\times1\times1$、$5\times3\times1$、$7\times2\times1$、$11\times1\times1$。计数侧把题面给出的四个 $C$ 值与「最小的 $C(n)=10$ 的 $n$ 是 154」全部跑出来——后者是模型正确性最有力的检验，因为它同时锁定了闭式与计数语义。

| $n$ | 见证的 (长方体, 层) | $C(n)$ |
|---|---|---|
| 22 | (1,1,5,1), (1,2,3,1) | 2 |
| 46 | (1,1,11,1), (1,2,3,2), (1,2,7,1), (1,3,5,1) | 4 |
| 78 | (1,1,19,1), (1,2,3,3), (1,3,9,1), (1,4,7,1), (3,3,5,1) | 5 |
| 118 | (1,1,29,1), (1,2,3,4), (1,2,19,1), (1,3,8,2), (1,3,14,1), (1,4,11,1), (1,5,9,1), (2,5,7,1) | 8 |
| 154 | (1,1,18,2), (1,1,38,1), (1,2,5,4), (1,2,25,1), (1,3,11,2), (1,4,9,2), (1,5,12,1), (2,7,7,1), (3,3,4,3), (3,3,7,2) | 10 |

**第二条路径：换一个枚举方向。** `brute-force.kt` 把层号 $k$ 提到最外层，对每个 $(k,a,b)$ 让 $c$ 从 $b$ 起自增、每次重新按定义代入闭式求值，不保留任何增量状态；`solution.kt` 则是每个长方体只访问一次、层数用增量推进。两条路径覆盖的 (长方体, 层) 对完全相同，但生成顺序相反、中间量毫无共享，两份程序给出的计数数组逐项相同，答案也一致。

**第三条路径：换一门语言。** 用 Python 重新实现同一闭式的两种枚举，独立核算了全部计数与工作量：两份计数表逐项相等，被记数的层对数都是 $W = 10050016$（$L = 32000$），$C(22),C(46),C(78),C(118) = 2,4,5,8$，最小的 $C(n)=10$ 是 $154$。

**一个容易走偏的地方。** $C(n)$ 并不单调：$n = 18352$ 时 $C(n) = 1206$ 已经超过 $1000$，但题目要求的是**恰好**等于 $1000$，所以答案不是 $18352$。若按「第一个 $C(n) \ge 1000$」去找，就会得到错误结果。满足 $C(n)=1000$ 的 $n$ 依次是 $18522, 18576, 18880, 20494, 21006,\dots$，最小者即本题答案 **18522**。

## 复杂度对比

设 $L$ 为使用的上界（倍增收敛到 $32000$），$W$ 为满足 $f \le L$ 的 (长方体, 层) 对数——每个这样的层都必须落到计数数组上一次，这是本题不可回避的下界。

| 方案 | 时间 | 空间 | 实测（JIT 预热后） |
|---|---|---|---|
| 优化：按长方体分组、层数用增量推进 | $O(T+W)$，$T=682836$ | $O(L)$ | 9.5405 ms |
| 对照：按层号分组、每次重新代入闭式 | $O(KA+W)$，$K=89$，$A=116440$ | $O(L)$ | 16.9642 ms |

$L=32000$ 时 $W = 10050016$，即两份实现都要做一千万次记数；差别在外层结构——优化解访问 $T=682836$ 个 $(a,b,c)$ 三元组，每层只做加法；对照解要按 $k$ 重复走 $A=116440$ 组 $(a,b)$，并且每个 $(k,a,b,c)$ 组合都重算一次多项式（含一次失败退出，共 $W+A$ 次求值）。实测差约 $1.8$ 倍。

计时口径：两个解都在程序内 JIT 预热后自报耗时，由主 Agent 在空闲机器上各编译一次、独立进程重复 5 次取最小值；数字已同步进 `meta.json` 的两个 baseline 字段。两份实现用同一口径，计时覆盖完整的一次求解与上界倍增（$1000 \to 32000$），不含样例断言、编译与输出。

## 实现要点

- **上界必须不小于答案**，否则计数不完整。程序用倍增而不是硬编码 $32000$；若把上界直接写成 $20000$，答案 $18522$ 仍会被找到，但这属于对答案量级的预设，倍增写法不需要这个前提。
- **长方体要规范化**（$a \le b \le c$），否则 $C(22)$ 会被数成 $6$ 而不是 $2$。
- **层号从 $1$ 开始**：$k-1 = 0$ 时后两项自动归零，公式退化为表面积，这正是「第一层」。
- **内层用 `Int`、边界判定用 `Long`**：层大小 $f \le L$，步长 $4(a+b+c)+8(k-1)$ 也只有 $10^4$ 量级，内层循环不会溢出；而 $6a^2$、$4ab+2b^2$、底面积这些判定式先转 `Long` 再相乘，避免 `Int` 溢出。
- **不要用「第一个 $C(n) \ge 1000$」判据**：$C(n)$ 不单调（$18352$ 处已是 $1206$），必须精确等于目标值。
