# 整数角四边形

设 $ABCD$ 为凸四边形，对角线为 $AC$ 与 $BD$。在每个顶点，对角线与两条邻边各构成一个夹角，共产生八个顶角。

例如在顶点 $A$，两个角分别为 $\angle CAD$ 与 $\angle CAB$。

若这八个顶角（以角度制衡量）均为整数，则称此四边形为**整数角四边形**。正方形是一个例子（八个角全为 $45^\circ$）。另一个例子为：$\angle DAC = 20^\circ$、$\angle BAC = 60^\circ$、$\angle ABD = 50^\circ$、$\angle CBD = 30^\circ$、$\angle BCA = 40^\circ$、$\angle DCA = 30^\circ$、$\angle CDB = 80^\circ$、$\angle ADB = 50^\circ$。

问共有多少个**互不相似**的整数角四边形？

注：计算中，若算出的角度与某一整数相差不超过 $10^{-9}$，即可视为整数。
