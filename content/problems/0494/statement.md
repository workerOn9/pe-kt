# 494 · Collatz 前缀族

> 中文意译。英文原文见 [Project Euler Problem 494](https://projecteuler.net/problem=494)；抓取底稿见 `statement.en.md`。

Collatz 数列定义为：若 $a_i$ 为偶数则 $a_{i+1} = a_i/2$，若 $a_i$ 为奇数则 $a_{i+1} = 3a_i+1$。

Collatz 猜想断言：从任意正整数出发，该数列最终都会进入循环 $1,4,2,1, \ldots$。

我们把以 $a_1 = n$ 起步的 Collatz 数列的**前缀** $p(n)$ 定义为：由其中所有不是 $2$ 的幂的数构成的子序列（本问题中认为 $2^0 = 1$ 也是 $2$ 的幂）。例如：

```
p(13) = {13, 40, 20, 10, 5}
p(8) = {}
```

任何推翻该猜想的数都会有一个长度无限的数列前缀。

记 $S_m$ 为所有长度为 $m$ 的数列前缀构成的集合。$S_m$ 中的两个序列 $\{a_1, a_2, \ldots, a_m\}$ 与 $\{b_1, b_2, \ldots, b_m\}$ 称为属于同一个**前缀族**，当且仅当对所有 $1 \le i,j \le m$ 都有 $a_i \lt a_j$ 当且仅当 $b_i \lt b_j$。

例如在 $S_4$ 中，$\{6, 3, 10, 5\}$ 与 $\{454, 227, 682, 341\}$ 属于同一族，但与 $\{113, 340, 170, 85\}$ 不属于同一族。

记 $f(m)$ 为 $S_m$ 中不同前缀族的个数。已知 $f(5) = 5$，$f(10) = 55$，$f(20) = 6771$。

求 $f(90)$。
