# 558 · 无理数进制

> 中文意译。英文原文见 [Project Euler Problem 558](https://projecteuler.net/problem=558)；抓取底稿见 `statement.en.md`。

设 $r$ 为方程 $x^3 = x^2 + 1$ 的实根。

每个正整数都可以写成若干个互不相同、指数递增的 $r$ 的幂之和。若要求项数有限，且任意两个指数之差至少为 $3$，则这样的表示是唯一的。

例如 $3 = r^{-10} + r^{-5} + r^{-1} + r^2$，$10 = r^{-10} + r^{-7} + r^6$。有趣的是，这一关系对该方程的复根同样成立。

记 $w(n)$ 为上述唯一表示中 $n$ 的项数。因此 $w(3) = 4$，$w(10) = 3$。

更形式化地，对一切正整数 $n$ 有

$$
n = \sum_{k=-\infty}^\infty b_k r^k
$$

满足以下条件：

- 对所有 $k$，$b_k$ 为 $0$ 或 $1$；
- 对所有 $k$，$b_k + b_{k + 1} + b_{k + 2} \le 1$；
- $w(n) = \displaystyle \sum_{k=-\infty}^\infty b_k$ 有限。

记 $S(m) = \displaystyle \sum_{j=1}^m w(j^2)$。已知 $S(10) = 61$，$S(1000) = 19403$。

求 $S(5\,000\,000)$。
