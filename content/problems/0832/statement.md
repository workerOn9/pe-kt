# 832 · Mex 序列

> 中文意译。英文原文见 [Project Euler Problem 832](https://projecteuler.net/problem=832)；抓取底稿见 `statement.en.md`。

本题中 $\oplus$ 表示两个数的按位异或。
从空白纸开始，反复执行以下操作：

写下当前不在纸上的最小正整数 $a$；
找出最小的正整数 $b$，使得 $b$ 与 $(a \oplus b)$ 都不在纸上。然后写下 $b$ 与 $(a \oplus b)$。

第一轮后，纸上会写下 $\{1,2,3\}$。第二轮中 $a=4$，由于 $(4 \oplus 5)$、$(4 \oplus 6)$ 与 $(4 \oplus 7)$ 都已在纸上，因此 $b$ 必须是 $8$。

$n$ 轮后纸上会有 $3n$ 个数，记其和为 $M(n)$。
例如 $M(10) = 642$，$M(1000) = 5432148$。

求 $M(10^{18})$，答案对 $1\,000\,000\,007$ 取模。
