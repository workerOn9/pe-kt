# 487 · 幂和的幂和

> 中文意译。英文原文见 [Project Euler Problem 487](https://projecteuler.net/problem=487)；抓取底稿见 `statement.en.md`。

记 $f_k(n)$ 为前 $n$ 个正整数的 $k$ 次幂之和。

例如 $f_2(10) = 1^2 + 2^2 + 3^2 + 4^2 + 5^2 + 6^2 + 7^2 + 8^2 + 9^2 + 10^2 = 385$。

记 $S_k(n)$ 为所有 $1 \le i \le n$ 的 $f_k(i)$ 之和。例如 $S_4(100) = 35375333830$。

求所有介于 $2 \cdot 10^9$ 与 $2 \cdot 10^9 + 2000$ 之间的素数 $p$ 上，$\sum (S_{10000}(10^{12}) \bmod p)$ 的值。
