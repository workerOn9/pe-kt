# 415 · 泰坦尼克集合

> 中文意译。英文原文见 [Project Euler Problem 415](https://projecteuler.net/problem=415)；抓取底稿见 `statement.en.md`。

若存在一条直线恰好经过格点集合 $S$ 中的两个点，则称格点集合 $S$ 为**泰坦尼克集合**。

$S = \{(0, 0), (0, 1), (0, 2), (1, 1), (2, 0), (1, 0)\}$ 是泰坦尼克集合的一个例子：过 $(0, 1)$ 与 $(2, 0)$ 的直线不经过 $S$ 中的任何其他点。

另一方面，集合 $\{(0, 0), (1, 1), (2, 2), (4, 4)\}$ 不是泰坦尼克集合，因为过其中任意两点的直线都会经过另外两个点。

对任意正整数 $N$，记 $T(N)$ 为其中每个点 $(x, y)$ 都满足 $0 \leq x, y \leq N$ 的泰坦尼克集合 $S$ 的个数。可以验证 $T(1) = 11$，$T(2) = 494$，$T(4) = 33554178$，$T(111) \bmod 10^8 = 13500401$，$T(10^5) \bmod 10^8 = 63259062$。

求 $T(10^{11})\bmod 10^8$。
