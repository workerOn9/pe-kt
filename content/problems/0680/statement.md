# 680 · Yarra Gnisrever

> 中文意译。英文原文见 [Project Euler Problem 680](https://projecteuler.net/problem=680)；抓取底稿见 `statement.en.md`。

设 $N$ 和 $K$ 为两个正整数。

$F_n$ 是第 $n$ 个斐波那契数：$F_1 = F_2 = 1$，$F_n = F_{n - 1} + F_{n - 2}$ 对所有 $n \geq 3$。
设 $s_n = F_{2n - 1} \bmod N$，$t_n = F_{2n} \bmod N$。

从整数数组 $A = (A[0], \cdots, A[N - 1])$ 开始，初始时每个 $A\text{[}i]$ 等于 $i$。现在对 $A$ 连续执行 $K$ 次操作，其中第 $j$ 次操作是把 $A$ 中下标介于 $s_j$ 与 $t_j$ 之间（含两端）的元素逆序。

定义 $R(N,K)$ 为 $K$ 次操作后 $\sum_{i = 0}^{N - 1}i \times A\text {[}i]$ 的值。

例如，$R(5, 4) = 27$，可由以下过程得出：

初始位置：$(0, 1, 2, 3, 4)$
第 1 步 - 逆序 $A[1]$ 到 $A[1]$：$(0, 1, 2, 3, 4)$
第 2 步 - 逆序 $A[2]$ 到 $A[3]$：$(0, 1, 3, 2, 4)$
第 3 步 - 逆序 $A[0]$ 到 $A[3]$：$(2, 3, 1, 0, 4)$
第 4 步 - 逆序 $A[3]$ 到 $A[1]$：$(2, 0, 1, 3, 4)$
$R(5, 4) = 0 \times 2 + 1 \times 0 + 2 \times 1 + 3 \times 3 + 4 \times 4 = 27$

此外，$R(10^2, 10^2) = 246597$，$R(10^4, 10^4) = 249275481640$。

求 $R(10^{18}, 10^6)$，答案模 $10^9$。
