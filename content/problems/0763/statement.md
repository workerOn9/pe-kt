# 763 · 三维网格中的变形虫

> 中文意译。英文原文见 [Project Euler Problem 763](https://projecteuler.net/problem=763)；抓取底稿见 `statement.en.md`。

考虑一个立方体构成的三维网格。位于立方体 $(x, y, z)$ 中的变形虫可以分裂成三只变形虫，占据立方体 $(x + 1, y, z)$、$(x, y + 1, z)$ 和 $(x, y, z + 1)$，前提是这些立方体为空。

最初只有一个变形虫位于立方体 $(0, 0, 0)$。经过 $N$ 次分裂后，网格中将排列 $2N+1$ 只变形虫。一种排列可能通过若干不同的方式达到，但只计一次。设 $D(N)$ 为 $N$ 次分裂后不同可能排列的数目。

例如，$D(2) = 3$，$D(10) = 44499$，$D(20)=9204559704$，而 $D(100)$ 的最后九位数字是 $780166455$。

求 $D(10\,000)$，输入最后九位数字作为你的答案。
