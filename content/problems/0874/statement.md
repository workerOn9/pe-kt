# 874 · 最大质数得分

> 中文意译。英文原文见 [Project Euler Problem 874](https://projecteuler.net/problem=874)；抓取底稿见 `statement.en.md`。

设 $p(t)$ 表示第 $t + 1$ 个质数，因此 $p(0) = 2$，$p(1) = 3$，依此类推。
定义非负整数列表 $[a_1, \dots, a_n]$ 的**质数得分**为总和 $\sum_{i = 1}^n p(a_i)$。
设 $M(k, n)$ 为满足下列条件的所有列表 $[a_1, \dots, a_n]$ 的质数得分的最大值：
- 对每个 $i$，均有 $0 \le a_i < k$；
- 和 $\sum_{i = 1}^n a_i$ 是 $k$ 的倍数。

例如，$M(2, 5) = 14$，列表 $[0, 1, 1, 1, 1]$ 达到该最大质数得分 14。

求 $M(7000, p(7000))$。
