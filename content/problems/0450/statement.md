# 450 · 内摆线与格点

> 中文意译。英文原文见 [Project Euler Problem 450](https://projecteuler.net/problem=450)；抓取底稿见 `statement.en.md`。

内摆线是沿大圆内侧滚动的小圆上一点的轨迹。圆心在原点、从最右端出发的内摆线，其参数方程为：

$$
x(t) = (R - r) \cos(t) + r \cos(\frac {R - r} r t)
$$

$$
y(t) = (R - r) \sin(t) - r \sin(\frac {R - r} r t)
$$

其中 $R$ 是大圆半径，$r$ 是小圆半径。

记 $C(R, r)$ 为半径分别为 $R$ 与 $r$ 的内摆线上所有这样的整数坐标点的集合：存在对应的 $t$ 使 $\sin(t)$ 与 $\cos(t)$ 都是有理数。

设 $S(R, r) = \sum_{(x,y) \in C(R, r)} |x| + |y|$，即 $C(R, r)$ 中各点 $x$、$y$ 坐标绝对值之和。

设 $T(N) = \sum_{R = 3}^N \sum_{r=1}^{\lfloor \frac {R - 1} 2 \rfloor} S(R, r)$，即对正整数 $R$、$r$（$R\leq N$ 且 $2r < R$）求 $S(R, r)$ 之和。

已知：

$C(3, 1)$	=	$\{(3, 0), (-1, 2), (-1,0), (-1,-2)\}$

$C(2500, 1000)$	=	$\{(2500, 0), (772, 2376), (772, -2376), (516, 1792), (516, -1792), (500, 0), (68, 504), (68, -504),$
	$(-1356, 1088), (-1356, -1088), (-1500, 1000), (-1500, -1000)\}$

注：$(-625, 0)$ 不是 $C(2500, 1000)$ 的元素，因为对应的 $t$ 处 $\sin(t)$ 不是有理数。

$S(3, 1) = (|3| + |0|) + (|-1| + |2|) + (|-1| + |0|) + (|-1| + |-2|) = 10$

$T(3) = 10; T(10) = 524; T(100) = 580442; T(10^3) = 583108600$。

求 $T(10^6)$。
