# 518 · 素数三元组与等比数列

> 中文意译。英文原文见 [Project Euler Problem 518](https://projecteuler.net/problem=518)；抓取底稿见 `statement.en.md`。

记 $S(n) = \sum a + b + c$，其中求和遍历所有满足下列条件的三元组 $(a, b, c)$：

- $a$、$b$、$c$ 都是素数；
- $a \lt b \lt c \lt n$；
- $a+1$、$b+1$、$c+1$ 构成等比数列。

例如 $S(100) = 1035$，对应的三元组为：

$(2, 5, 11)$，$(2, 11, 47)$，$(5, 11, 23)$，$(5, 17, 53)$，$(7, 11, 17)$，$(7, 23, 71)$，$(11, 23, 47)$，$(17, 23, 31)$，$(17, 41, 97)$，$(31, 47, 71)$，$(71, 83, 97)$。

求 $S(10^8)$。
