# 483 · 重复置换

> 中文意译。英文原文见 [Project Euler Problem 483](https://projecteuler.net/problem=483)；抓取底稿见 `statement.en.md`。

我们把**置换**定义为对元素集合 $\{1, 2, 3, \ldots, n\}$ 顺序的一种重排。这样的置换共有 $n!$ 个，其中有一个把所有元素保持原样。当 $n = 3$ 时，$3! = 6$ 个置换如下：

```
P1 = 保持初始顺序
P2 = 交换第 1 个与第 2 个元素
P3 = 交换第 1 个与第 3 个元素
P4 = 交换第 2 个与第 3 个元素
P5 = 把元素整体右移一位
P6 = 把元素整体左移一位
```

一旦选定其中一个置换并反复施加同一个置换，最终总会回到初始顺序。

对置换 $P_i$，记 $f(P_i)$ 为反复施加 $P_i$ 直到恢复初始顺序所需的步数。当 $n = 3$ 时，我们得到：

```
f(P1) = 1 : (1,2,3) → (1,2,3)
f(P2) = 2 : (1,2,3) → (2,1,3) → (1,2,3)
f(P3) = 2 : (1,2,3) → (3,2,1) → (1,2,3)
f(P4) = 2 : (1,2,3) → (1,3,2) → (1,2,3)
f(P5) = 3 : (1,2,3) → (3,1,2) → (2,3,1) → (1,2,3)
f(P6) = 3 : (1,2,3) → (2,3,1) → (3,1,2) → (1,2,3)
```

记 $g(n)$ 为所有长度为 $n$ 的置换上 $f^2(P_i)$ 的平均值。则

$$
\begin{aligned}
g(3) &= \frac{1^2 + 2^2 + 2^2 + 2^2 + 3^2 + 3^2}{3!} = \frac{31}{6} \approx 5.166666667\mathrm{e}0 \\
g(5) &= \frac{2081}{120} \approx 1.734166667\mathrm{e}1 \\
g(20) &= \frac{12422728886023769167301}{2432902008176640000} \approx 5.106136147\mathrm{e}3
\end{aligned}
$$

求 $g(350)$，并按科学计数法写成保留 $10$ 位有效数字的形式，用小写字母 e 分隔尾数与指数（与上面的示例同格式）。
