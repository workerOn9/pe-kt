# 540 · 本原勾股三元组计数

> 中文意译。英文原文见 [Project Euler Problem 540](https://projecteuler.net/problem=540)；抓取底稿见 `statement.en.md`。

勾股三元组由三个满足 $a^2+b^2=c^2$ 的正整数 $a, b, c$ 组成。若 $a, b, c$ 互素，则称该三元组为本原的。

记 $P(n)$ 为满足 $a \lt b \lt c \le n$ 的本原勾股三元组的个数。例如 $P(20) = 3$，因为有三个三元组：$(3,4,5)$、$(5,12,13)$ 和 $(8,15,17)$。

已知 $P(10^6) = 159139$。求 $P(3141592653589793)$。
