# 260 — Stone Game（取石子游戏）

## 建模

三堆石子的局面是多重集，排序后记 $(x,y,z)$（$x\le y\le z$）。一步走法：选 $N\ge 1$ 与任意非空子集 $S\subseteq\{1,2,3\}$，$S$ 中每一堆同时减去 $N$。正常走法（取走最后一颗者胜），$(0,0,0)$ 无子可取，是必败局面。记 $\mathcal P$ 为全部必败局面：

$$
p \in \mathcal P \iff \text{从 } p \text{ 出发的每个合法走法都到达必胜局面}.
$$

逐状态枚举「$7$ 个移法族 $\times$ 所有 $N$」是 $O(Z^4)$。下面的三条唯一性引理把每个移法族压成一次 $O(1)$ 查表，使整体变成 $O(Z^3)$。

## 三条唯一性引理

**引理 1（值对补全唯一）** 对任意值对 $\{u,v\}$，至多一个 $w$ 使 $\{u,v,w\}\in\mathcal P$。

若 $w_1<w_2$ 都对同一值对成立，则从 $\{u,v,w_2\}$ 出发，只对取值为 $w_2$ 的那堆减 $w_2-w_1$，一步到达 $\{u,v,w_1\}\in\mathcal P$，与 $\{u,v,w_2\}$ 是必败局面矛盾。∎

**引理 2（未动值 + 双堆差唯一）** 对任意未动值 $u$ 与差 $d\ge 0$，至多一个基点 $a$ 使 $\{a,\,a+d,\,u\}\in\mathcal P$。

若 $a_1<a_2$，从 $\{a_2,\,a_2+d,\,u\}$ 对前两堆同减 $a_2-a_1$，一步到达 $\{a_1,\,a_1+d,\,u\}\in\mathcal P$。∎

**引理 3（间隔唯一）** 对任意间隔对 $(d_1,d_2)$，至多一个基点 $x$ 使 $\{x,\,x+d_1,\,x+d_1+d_2\}\in\mathcal P$：两个这样的局面之间只需三堆同减基点差。∎

引理 2、3 是引理 1 思想的推广：一步本来就可以同时调整「被同减的那几堆」，所以两个共享同一种差结构的局面之间往往只差一步；若它们都是必败局面，就与必败局面「所有后继都是必胜局面」直接冲突。

## 七个移法族与 $O(1)$ 查询

用三张表记录每条引理下「唯一的那个坐标」（无记录记 $-1$）：

- $F_1[u,v]$：值对 $\{u,v\}$ 的唯一第三值；
- $F_2[u,d]$：未动值 $u$、被同减两堆之差 $d$ 的唯一基点；
- $F_3[d_1,d_2]$：间隔对的唯一基点。

当前局面 $(x,y,z)$ 的七类走法各自等价于一条不等式（下表右侧均为一次查表）：

| 减的堆 | 一步走法的落点 | 能到必败局面的判据 |
|:--|:--|:--|
| $x$ | $\{c,\,y,\,z\}$ | $F_1[y,z] < x$ |
| $y$ | $\{x,\,c,\,z\}$ | $F_1[x,z] < y$ |
| $z$ | $\{x,\,y,\,c\}$ | $F_1[x,y] < z$ |
| $x,y$ | $\{c,\,c+(y-x),\,z\}$ | $F_2[z,\,y-x] < x$ |
| $y,z$ | $\{x,\,c,\,c+(z-y)\}$ | $F_2[x,\,z-y] < y$ |
| $x,z$ | $\{c,\,y,\,c+(z-x)\}$ | $F_2[y,\,z-x] < x$ |
| $x,y,z$ | $\{c,\,c+(y-x),\,c+(z-x)\}$ | $F_3[y-x,\,z-y] < x$ |

以第 4 行为例：若 $c=F_2[z,\,y-x]<x$，取 $N=x-c$ 对前两堆同减，落点恰为必败局面 $\{c,c+(y-x),z\}$；反过来，任何「同减前两堆」直达必败局面的走法，落点都形如 $\{c,c+(y-x),z\}$，由引理 2 这个 $c$ 唯一，必已被 $F_2$ 记录。其余各行同理。

## 递推顺序与剪枝

每个走法都让总和严格变小，排序后的多重集在字典序下也严格更小（逐族验证：单堆走法三段中有一段被减 N 后重排，双堆走法让两堆各减 N 后重排——无论是否越过最小值，字典序都严格变小，三堆走法让最小坐标变小）。因此按 $(x,y,z)$ 的字典序递推即可，所有被查询的局面都已经算完。

固定 $(x,y)$ 时，由引理 1，至多一个 $z$ 使 $(x,y,z)\in\mathcal P$：

- 若值对 $\{x,y\}$ 的补全 $c<y$ 在更早的行就已记录（当时的三元组排序后是 $(x,c,y)$ 或 $(c,x,y)$），那么整行每个 $(x,y,z)$（$z\ge y>c$）都能把最大堆减到 $c$，一步直达 $\{x,y,c\}$，整行都是必胜局面，直接跳过；
- 否则行内扫到第一个必败局面 $z_0$ 即可停止——更大的 $z$ 都能把最大堆减到 $z_0$ 一步直达它。

这两种情形合起来说明：行内第 3 条查询（$F_1[x,y]<z$）恒为假，内循环实际只需 6 条查询。实跑 $Z=1000$：全部排序三元组有 $\binom{1003}{3}=167\,668\,501$ 个，方法 A 只扫描了其中的 $46\,529\,505$ 个（$27.8\%$）。

## 独立复核（方法 B）

方法 B 换成三张布尔标记表——`one[值对]`、`two[差,未动值]`、`all[间隔对]`——只写「已被某个必败局面占用」，不存坐标、不做大小比较：标记在写、查询在读，靠字典序扫描保证「读到标记时，写标记的必败局面一定可达」（同一 key 至多一个必败局面，且扫描顺序保证其坐标更小）。它保留整行剪枝，但行内不提前终止，与 A 的代码路径独立。

两种实现在 $Z=100,200,500,1000$ 的（$\Sigma$、局面个数、局面集合滚动哈希）全部一致；完整规模下必败局面共 $121060$ 个。

## 直接暴力对照

`brute-force.kt` 完全按定义实现：按总和递增，对每个排序三元组枚举 7 个移法族与全部 $N\in[1,z]$，逐条查询后继是否必败，复杂度 $O(Z^4)$。它在 $Z=100$ 复现题面锚点 $173895$，并与方法 A 逐局面一致；$Z=250$ 时已需 $7.38\times10^8$ 次后继检查。

## 旁证

1. **题面锚点**：$Z=100$ 三种独立实现（方法 A、方法 B、直接暴力）全部得到 $173895$，与题面一致；A 与直接暴力在 $Z=100$、A 与 B 在 $Z=150$ 的全部 $x\le y\le z$ 三元组逐局面一致。
2. **闭式对照**：$x=0$ 时三堆同减不可能发生，游戏退化为两堆的 Wythoff 取子游戏，其必败局面应为 $(0,\lfloor n\varphi\rfloor,\lfloor n\varphi^2\rfloor)$（$\varphi$ 为黄金比）。实跑 $x=0$ 行的 39 个必败局面（$z\le 100$，$n=0..38$）与闭式逐一吻合。
3. **两条全规模路线**：方法 A（存坐标、6 查询、行内提前终止）与方法 B（纯标记、7 查询）对完整 $Z=1000$ 给出完全相同的局面集合。
4. **公开答案表**：Stephan Brumme 的 PE260 题解与若干 Project Euler 答案汇总页都列出 $167542057$（仅作旁证；`meta.answer` 取自本机实跑输出）。

## 关键教训

- **博弈递推的瓶颈是「每个状态的走法数」而不是状态数。** 每个状态有 $O(Z)$ 种走法；能把它们压成 $O(1)$，靠的是识别出一步走法**保持不变的结构**（未动值、差、间隔），然后问「该结构上唯一的必败局面是否落在可达范围内」。这套「按不变量归类」的思路，与棋类终局库的索引设计异曲同工。
- **唯一性引理都用「两步并一步」证明。** 同 key 的两个必败局面之间必然只差一步走法，这与必败局面的定义直接冲突——引理 1、2、3 的证明是同一个模板换三种差结构。写 Wythoff 型游戏的代码前，先把这些引理找齐，正确性论证会变得很短。
- **剪枝必须由定理支撑。** 「每行至多一个必败局面」「补全更早则整行必胜」都是引理 1 的直接推论，不是经验性剪枝；即便如此，$1.68\times10^8$ 个状态全量展开也是可接受的，剪枝只是让扫描量再降 $3.6$ 倍。
- **第二条实现路径很便宜且值得。** 标记表版本完全不比较坐标，转而依赖扫描顺序论证可达性；它替我们守住了「值比较」和「提前终止条件」这两处最容易写错的地方，一次运行就同时验证了引理的正确使用与剪枝的正确性。
- **暴力对照要先把题面锚点对齐。** 直接暴力在 $Z=100$ 只要 $26$ ms，却是整条信任链的起点：三种实现都复现 $173895$ 之后，全规模的 $167542057$ 才有底气。
