# 732 · 站在巨魔的肩膀上

> 中文意译。英文原文见 [Project Euler Problem 732](https://projecteuler.net/problem=732)；抓取底稿见 `statement.en.md`。

$N$ 个巨魔身处一个深 $D_N$ 厘米的洞中。第 $n$ 个巨魔的特征为：

从他脚到肩膀的距离（以厘米计），$h_n$；
他手臂的长度（以厘米计），$l_n$；
他的 IQ（易怒商数），$q_n$。

巨魔可以叠在彼此身上，每个巨魔站在下方巨魔的肩膀上。若一个巨魔的手能够到地面，他就能爬出洞并逃走。一旦某个巨魔逃走，他就不能再参与后续的逃脱努力。

巨魔们采取最优策略以最大化逃走巨魔的 IQ 总和，记为 $Q(N)$。

设
$r_n = \left[ \left( 5^n \bmod (10^9 + 7) \right) \bmod 101 \right] + 50$
$h_n = r_{3n}$
$l_n = r_{3n+1}$
$q_n = r_{3n+2}$
$D_N = \frac{1}{\sqrt{2}} \sum_{n=0}^{N-1} h_n$。

例如，第一个巨魔（$n=0$）到肩膀高 51 厘米，手臂长 55 厘米，IQ 为 75。

已知 $Q(5) = 401$，$Q(15)=941$。

求 $Q(1000)$。
