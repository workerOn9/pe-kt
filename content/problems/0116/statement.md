# 红、绿或蓝瓷砖

> 中文意译。英文原文见 [Project Euler Problem 116](https://projecteuler.net/problem=116)；抓取底稿见 `statement.en.md`。

一行 $5$ 块灰色正方形瓷砖，要将其中的若干块替换为彩色长方形瓷砖。彩色砖可选红色（长 $2$ 个单位）、绿色（长 $3$ 个单位）或蓝色（长 $4$ 个单位）。

若只选用红色砖，恰有 $7$ 种替换方法。

若只选用绿色砖，有 $3$ 种方法。

若只选用蓝色砖，有 $2$ 种方法。

规定颜色不得混用，则长度为 $5$ 单位的一行共有 $7 + 3 + 2 = 12$ 种替换灰色砖的方法。

问：长度为 $50$ 单位的一行，在颜色不混用、且**至少使用一块**彩色砖的前提下，共有多少种替换方法？

注：本题与 Problem 117 相关。
