# 整数坐标直角三角形

> 中文意译。英文原文见 [Project Euler Problem 91](https://projecteuler.net/problem=91)；抓取底稿见 `statement.en.md`。

点 $P(x_1, y_1)$ 与 $Q(x_2, y_2)$ 都取整数坐标（格点），将它们分别与原点 $O(0,0)$ 相连，得到三角形 $OPQ$。

当四个坐标都取 $0$ 到 $2$ 之间的整数（即 $0 \le x_1, y_1, x_2, y_2 \le 2$）时，一共可以构成恰好十四个含直角的三角形。

现在已知 $0 \le x_1, y_1, x_2, y_2 \le 50$，问一共能构成多少个直角三角形？
