# 660 · 全数字三角形

> 中文意译。英文原文见 [Project Euler Problem 660](https://projecteuler.net/problem=660)；抓取底稿见 `statement.en.md`。

我们称一个三边均为整数的三角形为 $n$-全数字的，如果它含有一个 $120$ 度的角，并且当三边用 $n$ 进制表示时，它们一起恰好各使用一次该进制的全部 $n$ 个数字。

例如，三角形 $(217, 248, 403)$ 是 $9$-全数字的，因为它含有一个 $120$ 度的角，且三边用 $9$ 进制表示为 $261_9, 305_9, 487_9$，各使用一次该进制的 $9$ 个数字。

求所有满足 $9 \le n \le 18$ 的 $n$-全数字三角形的最大边之和。
