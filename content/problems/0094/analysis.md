# 094 · 近乎等边的三角形 — 解析

## 思路推导

设两腰为 $n$，底为 $n-1$ 或 $n+1$，则面积只由 $n$ 决定：

**底为 $n+1$**：高 $h = \sqrt{n^2 - \left(\frac{n+1}{2}\right)^2} = \frac{1}{2}\sqrt{3n^2 - 2n - 1}$，面积

$$S = \frac{n+1}{2} \cdot h = \frac{n+1}{4}\sqrt{3n^2 - 2n - 1}.$$

**底为 $n-1$**：同理 $S = \frac{n-1}{4}\sqrt{3n^2 + 2n - 1}$。

整数边长的三角形若面积为整数，由海伦公式可知面积是 $\frac{1}{4}$ 的倍数；这里 $\frac{n\pm1}{4}$ 已经提供了分母，于是面积整数 $\iff 3n^2 \mp 2n - 1$ 是完全平方数 $m^2$。

**配方化为 Pell 方程。** 以底 $n+1$ 为例，$m^2 = 3n^2 - 2n - 1$，两边乘 3 再配方：

$$(3n-1)^2 - 3m^2 = 9n^2 - 6n + 1 - 3(3n^2-2n-1) = 4.$$

底 $n-1$ 同理给出 $(3n+1)^2 - 3m^2 = 4$。两个家族统一为

$$x^2 - 3y^2 = 4,\qquad x = 3n \mp 1.$$

而 $x$ 恰好就是周长：$3n+1$ 或 $3n-1$。$x^2-3y^2=4$ 的全部正整数解由两条基本解 $2$ 与 $4$ 生成，并满足线性递推

$$x_{k+1} = 4x_k - x_{k-1}:\qquad 2,\ 4,\ 14,\ 52,\ 194,\ 724,\ 2702,\ 10084,\ \dots$$

- $x \equiv 1 \pmod 3$：$x = 3n+1$，腰长 $n = (x-1)/3$，底为 $n-1$；
- $x \equiv 2 \pmod 3$：$x = 3n-1$，腰长 $n = (x+1)/3$，底为 $n+1$。

三角形不等式 $n + n > n \pm 1$ 即 $n > 1$，所以 $x = 2, 4$（对应 $n = 1$ 的退化三角形）必须剔除。从 $x = 14$（$5$-$5$-$6$，面积 $12$）起，逐一累加周长直到 $x > 10^9$：

$$14 + 52 + 194 + 724 + 2702 + 10084 + 37634 + 140452 + 524174 + 1956244 + 7300802 + 27246964 + 101687054 + 379501252 = \textbf{518408346}$$

下一个解 $x = 4 \times 379501252 - 101687054 = 1416317954 > 10^9$，枚举终止。

## 复杂度对比

| 方案 | 时间 | 实测（JIT 预热后） |
|------|------|------|
| 优化解：Pell 递推枚举解族（14 项） | $O(\log P)$，$P = 10^9$ | ~0.004 ms |
| 暴力解：扫描全部腰长 $n \le 3.3\times10^8$，逐个做平方判定 | $O(P)$（每次两次开方） | ~3719.327 ms |

约 90 万倍。暴力解的每次判定都在问「这个 $n$ 是不是解」，而 Pell 递推直接把它变成「下一个解是多少」——前者是搜索，后者是生成。这正是数论递推相对枚举的典型优势。

## 实现要点

- $n \le 3.3\times10^8$，$3n^2 \approx 3.3\times10^{17}$，仍在 `Long` 范围内（$< 9.2\times10^{18}$），无需 BigInteger
- 平方数判定必须用 `isqrt` 校正 `Math.sqrt`：$10^{17}$ 量级的数超过了 double 的 53 位有效位，直接比较会有±1 的误差
- 剔除 $n = 1$ 的退化三角形（共线，面积为 0）
- 递推得到的每个解都用「$3n^2 \mp 2n - 1$ 与 $m^2$ 相等」复核，避免递推起点或方向写错时静默给出错误结果
