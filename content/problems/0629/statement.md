# 629 · 散石 Nim

> 中文意译。英文原文见 [Project Euler Problem 629](https://projecteuler.net/problem=629)；抓取底稿见 `statement.en.md`。

Alice 和 Bob 在玩一种名为 Scatterstone Nim 的改良 Nim 游戏，Alice 先手，与 Bob 交替行动。游戏开始时有一组任意的石子堆，石子总数等于 $n$。

在某一方的回合中，他/她必须选一堆至少有 $2$ 颗石子的石堆，执行一次分裂操作，把这堆分成 $p$ 堆任意大小的非空石堆，其中 $2 \leq p \leq k$，$k$ 是某个固定常数。例如，若 $k = 3$，一堆大小为 $4$ 的石子可以分成 $\{1, 3\}$ 或 $\{2, 2\}$ 或 $\{1, 1, 2\}$；若 $k = 4$，还可以分成 $\{1, 1, 1, 1\}$。

如果在某一回合无法进行合法移动，则另一方获胜。

**获胜局面**定义为这样一组石堆：无论另一方如何行动，某一方最终都能确保获胜。

设 $f(n,k)$ 为给定参数 $n$ 和 $k$ 时，Alice 在她第一回合的获胜局面数。例如 $f(5, 2) = 3$，获胜局面为 $\{1, 1, 1, 2\}, \{1, 4\}, \{2, 3\}$。相对地，$f(5, 3) = 5$，获胜局面为 $\{1, 1, 1, 2\}, \{1, 1, 3\}, \{1, 4\}, \{2, 3\}, \{5\}$。

设 $g(n)$ 为 $f(n,k)$ 对所有 $2 \leq k \leq n$ 之和。例如 $g(7)=66$，$g(10)=291$。

求 $g(200) \bmod (10^9 + 7)$。
