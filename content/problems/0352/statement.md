# 352 · 批量检测

> 中文意译。英文原文见 [Project Euler Problem 352](https://projecteuler.net/problem=352)；抓取底稿见 `statement.en.md`。

羊群中的 $25$ 只羊每只都要检测一种罕见病毒（该病毒在羊群中的感染率为 $2\%$）。已有一种准确且极其灵敏的 PCR 检测，可对血样给出明确的阳性/阴性结果，但它非常耗时且昂贵。

由于成本很高，主管兽医建议改用下面的方案，而不是做 $25$ 次独立检测：

把 $25$ 只羊分成 $5$ 组、每组 $5$ 只。每组把 $5$ 份样本混在一起做一次检测。然后：

- 若结果为阴性，该组所有羊都判定为无病毒；
- 若结果为阳性，再做 $5$ 次检测（每只羊各一次）以确定具体是哪只感染。

由于单只羊的感染概率只有 $0.02$，每组的第一次（混合样本）检测结果是：

- 阴性（无需再测）的概率为 $0.98^5 = 0.9039207968$；
- 阳性（需再测 $5$ 次）的概率为 $1 - 0.9039207968 = 0.0960792032$。

因此每组检测次数的期望是 $1 + 0.0960792032\times 5 = 1.480396016$。全部 $5$ 组平均只需 $1.480396016\times 5 = 7.40198008$ 次检测，比逐只检测节省超过 $70\%$！

但这个方案还能大幅改进（前提仍是检测足够灵敏、混合样本没有副作用）。例如：

- 可以先把全部 $25$ 份样本混在一起检测。可以验证约有 $60.35\%$ 的情况结果为阴性，此时不必再测；只有剩下 $39.65\%$ 的情况需要进一步检测；
- 已知某组 $5$ 只羊中至少有一只感染、且前 $4$ 只的单独检测都为阴性时，就不必再检测第 $5$ 只（它必然感染）；
- 可以尝试不同的分组数/每组只数，并在每一层调整这些参数，使总检测次数的期望最小。

为简化过多可能，设计最省钱的检测方案时加上一个约束：**只要开始检测某个混合样本，就必须先把贡献该样本的羊全部筛完**（即每只羊都要有感染/无病毒的结论），才能开始检测其他羊。

对当前这个例子，最省钱的检测方案（称为**最优策略**）平均只需 $4.155452$ 次检测！

记 $T(s,p)$ 为用最优策略筛查 $s$ 只羊（单只携带该病毒的概率为 $p$）所需的平均检测次数。

已知（四舍五入到六位小数）$T(25, 0.02) = 4.155452$，$T(25, 0.10) = 12.702124$。

求 $p = 0.01, 0.02, 0.03, \dots, 0.50$ 时 $\sum T(10000, p)$，结果四舍五入到六位小数。
