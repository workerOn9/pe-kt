# 100 · 排列概率 — 解析

## 思路推导

设盒中共有 $n$ 个圆盘，其中 $b$ 个蓝盘。无放回地取两盘，两盘皆蓝的概率为

$$\frac{b(b-1)}{n(n-1)} = \frac{1}{2} \iff n(n-1) = 2b(b-1). \tag{1}$$

**化为佩尔方程。** 由于 $n(n-1)$ 与 $b(b-1)$ 都是相邻整数之积，令

$$x = 2n-1,\qquad y = 2b-1,$$

则 $x,y$ 都是正奇数，且

$$n(n-1) = \frac{x^2-1}{4},\qquad b(b-1) = \frac{y^2-1}{4}.$$

代回 $(1)$：$\dfrac{x^2-1}{4} = 2\cdot\dfrac{y^2-1}{4}$，整理得

$$x^2 - 2y^2 = -1. \tag{2}$$

反过来，$(2)$ 的任一正奇数解都能还原出一组合法配置 $n=\frac{x+1}{2},\ b=\frac{y+1}{2}$。于是问题变成：求负佩尔方程 $x^2-2y^2=-1$ 的解中，使 $n>10^{12}$ 的第一个。

**解的完全刻画。** 在环 $\mathbb{Z}[\sqrt2]$ 中，$x^2-2y^2 = N(x+y\sqrt2)$ 就是范数。$(2)$ 的最小正解是 $(x,y)=(1,1)$，对应 $1+\sqrt2$（范数 $-1$）。乘以

$$(1+\sqrt2)^2 = 3+2\sqrt2 \quad\text{即}\quad (x,y)\mapsto(3x+4y,\ 2x+3y)$$

保持范数 $-1$ 不变，而 $\mathbb{Z}[\sqrt2]$ 的单位群由 $1+\sqrt2$ 生成，故

$$x + y\sqrt2 = (1+\sqrt2)\,(3+2\sqrt2)^k,\qquad k = 0,1,2,\dots$$

给出且仅给出全部正整数解。实现上用整数递推逐个生成，避免任何浮点运算：

$$x_{k+1} = 3x_k + 4y_k,\qquad y_{k+1} = 2x_k + 3y_k.$$

**为什么可以「从小到大取第一个」。** 因为 $3+2\sqrt2 > 1$，序列 $x_k+y_k\sqrt2$ 严格递增，从而 $x_k$ 与 $n_k = \frac{x_k+1}{2}$ 也严格递增（$y_k$ 随 $x_k$ 同步增长）。列几项验证：

| $k$ | $x$ | $y$ | $n$ | $b$ |
|-----|-----|-----|-----|-----|
| 0 | 1 | 1 | 1 | 1 |
| 1 | 7 | 5 | 4 | 3 |
| 2 | 41 | 29 | 21 | 15 ← 题面首例 |
| 3 | 239 | 169 | 120 | 85 ← 题面次例 |
| ⋮ | | | | |
| 16 | 2140758220993 | 1513744654945 | 1070379110497 | **756872327473** |

$n_{15} = 183\,648\,021\,600 < 10^{12} < n_{16} = 1\,070\,379\,110\,497$，所以答案是

$$b = \frac{y_{16}+1}{2} = \frac{1\,513\,744\,654\,945+1}{2} = \mathbf{756872327473}.$$

**旁证。** 题面给出的两例 $(n,b) = (21,15)$、$(120,85)$ 分别落在 $k=2,3$，与递推序列完全吻合，说明解集刻画无误（题面此例就是解题者用来自查的锚点）。

**范围安全性。** 退出循环时 $x \approx 2.14\times10^{12}$，递推中的最大中间量 $4y \approx 6.1\times10^{12}$，远小于 `Long` 上限 $9.22\times10^{18}$；而「枚举 $n$ 到 $10^{12}$」的字面暴力需要 $10^{12}$ 次循环，本机不可行。

## 复杂度对比

| 方案 | 时间 | 实测（JIT 预热后） |
|------|------|------|
| 优化解：负佩尔方程整数递推 $(3+2\sqrt2)$ | $O(\log N)$ 步（此处 17 步），每步 4 次乘法 | ~0.00060 ms |
| 暴力解：枚举 $\sqrt2$ 的连分数渐近分数 + `BigInteger` 逐项判定 | $O(\log N)$ 步，每步为多精度乘法与平方 | ~0.1475 ms |

两者的迭代步数同阶，差距（约 $2\times10^2$ 倍）全部来自每步的算术成本：优化解只需 64 位整数加乘，暴力解每步要在 `BigInteger` 上算 $p^2-2q^2$（数值已达 $10^{24}$ 量级）并做一次对象化的大整数平方。这直观说明「同一数学结构、不同代数表示」的工程代价差异。

## 实现要点

- $n=\frac{x+1}{2}$ 用整数除法即可，因为 $x$ 恒为奇数；不要用 `double` 的 $\sqrt{}$ 去判佩尔方程，$10^{24}$ 量级的平方已超出双精度整数的精确表示范围（$2^{53}$）
- 递推顺序必须先算完 $x,y$ 再赋值（代码里用临时变量 `nx/ny`），否则会用已被覆盖的值
- 循环条件是 $n \le 10^{12}$（题面要求「超过」$10^{12}$），从 $(1,1)$ 起步自然跳过 $n=1$ 的退化配置
- 解的唯一性依赖「解集恰为单位群中 $1+\sqrt2$ 的偶次幂倍」这一代数事实，不能想当然地只用一对递推系数
