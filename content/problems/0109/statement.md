# 109 · 飞镖 checkout 计数

飞镖游戏中，选手向镖盘投出三支飞镖。镖盘被分成 $20$ 个等大的扇形区域，编号 $1$ 到 $20$。一支飞镖的得分取决于它落进的区域：落在红/绿外环之外的飞镖得 $0$ 分，外环以内的黑色与米色区域代表单倍得分，而红/绿外环与中环分别代表双倍与三倍得分。镖盘中心是两个同心圆，称为牛眼：外牛眼得 $25$ 分，内牛眼是双倍，得 $50$ 分。

规则有许多变体，但最流行的玩法中，选手从 $301$ 或 $501$ 分开始，最先把自己的累计得分减到 $0$ 的选手获胜。不过通常采用「双倍收镖」制：选手必须用最后一支飞镖命中双倍区域（包括中心的双倍牛眼）才算结束；任何会把累计得分减到 $1$ 或更低的飞镖都算「爆镖」，该组三镖的得分无效。

当选手能用当前分数收镖时，这称为一次 "checkout"，最高的 checkout 是 $170$：T20 T20 D25（两个三倍 $20$ 和一个双倍牛眼）。

得分恰为 $6$ 时，共有 $11$ 种不同的 checkout 方式：

- D3
- D1 D2
- S2 D2
- D2 D1
- S4 D1
- S1 S1 D2
- S1 T1 D1
- S1 S3 D1
- D1 D1 D1
- D1 S2 D1
- S2 S2 D1

注意 D1 D2 与 D2 D1 视为不同的方式，因为它们以不同的双倍收镖；而组合 S1 T1 D1 与 T1 S1 D1 则视为同一种。此外，考察组合时不把「未命中」算作一支镖：例如 D3 与 0 D3、0 0 D3 是同一种。

令人惊讶的是，checkout 方式总共有 $42336$ 种。

求得分小于 $100$ 时，一位选手共有多少种不同的 checkout 方式？
