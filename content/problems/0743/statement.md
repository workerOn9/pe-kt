# 743 · 矩阵之窗

> 中文意译。英文原文见 [Project Euler Problem 743](https://projecteuler.net/problem=743)；抓取底稿见 `statement.en.md`。

矩阵的一个窗口是指其连续的子矩阵。

考虑一个 $2\times n$ 矩阵，其中每个元素都是 0 或 1。设 $A(k,n)$ 为使得每个 $2\times k$ 窗口内元素之和都等于 $k$ 的这类矩阵的总数。

已知 $A(3,9) = 560$，$A(4,20) = 1060870$。

求 $A(10^8,10^{16})$，答案对 $1\,000\,000\,007$ 取模。
