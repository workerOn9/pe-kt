# 509 · 约数尼姆

> 中文意译。英文原文见 [Project Euler Problem 509](https://projecteuler.net/problem=509)；抓取底稿见 `statement.en.md`。

安东和贝特朗很喜欢玩三堆尼姆游戏。

不过，玩了很多局尼姆之后他们玩腻了，于是把规则稍微改了一下。

每一步只能从一堆中取走若干颗石子，且取走的数量必须是该堆现有石子数的真约数。

例如，若某堆在某一时刻有 $24$ 颗石子，那么只能取走 $1,2,3,4,6,8$ 或 $12$ 颗。

因此，若某堆只有一颗石子，就无法取走最后一颗——因为 $1$ 不是 $1$ 的真约数。

先手无法走出合法一步的一方输掉游戏。当然两人都会采用最优策略。

三元组 $(a, b, c)$ 表示三堆中石子的数量。记 $S(n)$ 为 $1 \le a, b, c \le n$ 中对下一位玩家而言的必胜局面数。

已知 $S(10) = 692$，$S(100) = 735494$。

求 $S(123456787654321)$ 模 $1234567890$。
