# 337 · 欧拉函数阶梯数列

> 中文意译。英文原文见 [Project Euler Problem 337](https://projecteuler.net/problem=337)；抓取底稿见 `statement.en.md`。

设 $\{a_1, a_2, \dots, a_n\}$ 是长度为 $n$ 的整数序列，满足：

- $a_1 = 6$；
- 对一切 $1 \le i < n$：$\phi(a_i) < \phi(a_{i+1}) < a_i < a_{i+1}$。

记 $S(N)$ 为满足 $a_n \le N$ 的这类序列的个数。例如 $S(10) = 4$：$\{6\}$、$\{6,8\}$、$\{6,8,9\}$、$\{6,10\}$。

可以验证 $S(100)=482073668$，$S(10\,000) \bmod 10^8 = 73808307$。

求 $S(20\,000\,000) \bmod 10^8$。

（注：$\phi$ 表示欧拉函数。）
