# 227 — The Chase（追逐）

## 思路：把两人博弈压成一个环上的随机游走

两枚骰子各被一名玩家持有，每回合两枚**独立**掷出。骰子的移动只有三种结果：传左（掷 1）、传右（掷 6）、不动（2–5），概率为

$$
p(-1) = \tfrac{1}{6},\quad p(0) = \tfrac{4}{6},\quad p(+1) = \tfrac{1}{6}.
$$

**关键观察：两人各自掷骰、互不干涉，所以「谁持有骰子」这一身份信息完全无关紧要。** 我们只需关心两枚骰子之间沿圆桌的最短间隔 $d$。设 $n$ 为玩家数（偶数），则 $d \in \{0, 1, \dots, n/2\}$，其中 $d = 0$ 表示两骰子同属一人 —— 游戏结束。

一轮中两枚骰子的位移分别为 $X_1, X_2$，间隔增量为 $\Delta = X_2 - X_1$。卷积 $(1,4,1)/6 \otimes (1,4,1)/6$ 给出

$$
P(\Delta = -2) = \frac{1}{36},\quad P(\Delta = -1) = \frac{8}{36},\quad P(\Delta = 0) = \frac{18}{36},\quad P(\Delta = +1) = \frac{8}{36},\quad P(\Delta = +2) = \frac{1}{36}.
$$

新状态是**环形最短距离**：

$$
d' = \min\bigl( (d + \Delta) \bmod n,\ \ n - (d + \Delta) \bmod n \bigr).
$$

这一步把「环」折叠成「半环」：$d$ 与 $n - d$ 合并，状态数从 100 降到 $n/2 = 50$。

## 期望方程与边界

记 $E_d$ 为从间隔 $d$ 开始到游戏结束的期望剩余回合数。一步消耗一回合，故

$$
E_d = 1 + \sum_{\Delta} p_\Delta \, E_{d'(d,\Delta)},\qquad d' \ne 0,
$$

而 $E_0 = 0$（吸收边界，$p_\Delta$ 中落在 $d'=0$ 的项直接丢弃）。对 $d = 1, \dots, n/2$ 得到 $m = 50$ 阶线性方程组 $A E = \mathbf{1}$，高斯消元求解。

两个容易踩的细节：

1. **$d = n/2$ 的自环**：$n/2 + 1$ 与 $n/2 - 1$ 折叠回 $n/2$，该状态有 $16/36$ 的概率原地不动。这一项必须计入，否则方程组不闭合。
2. **初值不是 $d = 1$**：题面说两名玩家**相对而坐**，即 $d = n/2 = 50$，取解向量最后一项。

## 旁证：精确有理数解

用 Python 的 `fractions.Fraction` 把全部概率写成精确分数做消元（全程无浮点）：

$$
E_{50} = \frac{586615414279592693268781956}{155163869452311434997005} = 3780.618621784790\ldots
$$

分母与分子互素，量级 $3.78\times 10^3$ 与「随机游走从对径位置走到中心的典型步数」相符：步长方差 $\mathrm{Var}(\Delta) = 2\cdot\frac{2}{6} = 2/3$，单步均方位移标准差约 $0.816$，而 $\{1, 2, \dots, 50\}$ 上的吸收随机游走从 50 到 0 的期望步数正比于 $d(n - d)/(\text{var}) \approx 2500/0.667 \approx 3750$，与精确值同量级、略高（因为 $\Delta$ 有 $\pm 2$ 的跳跃与折叠反射）。另用 Jacobi 迭代（纯松弛，不做消元）独立迭代到 $10^{-12}$ 收敛，以及 $n=6$ 的 20 万次蒙特卡洛模拟，三者互相对上。

## 答案

$$
E = 3780.618621784790\ldots
$$

十位有效数字：**3780.618622**（仓库惯例 `meta.json.answer` 存整数 $\mathrm{round}(E \times 10^8) = 378061862178$）。

## 关键教训

- **对称性降维**是这类「多人围桌」题的通用第一手：一旦发现状态只依赖两枚棋子（骰子）的相对位置，绝对位置就全部可以扔掉，$O(n)$ 个状态塌缩成 $O(n/2)$。
- **环形状态必须折叠**：$d$ 与 $n-d$ 等价，直接按 $0 \dots n-1$ 建状态会让方程组出现两组完全相同的行，且矩阵奇异；折叠后自动消解。
- **自环项不能丢**：$d = n/2$ 处 $\pm 1$ 的位移折回自身，是本题唯一会让「忘记它就得到错误答案」的地方，也是最值得手算一遍验证的点。
- **浮点消元 vs 精确算术**：$m = 50$ 的规模浮点完全够用，但用有理数重算一遍可以把「答案对不对」与「精度够不够」两件事分开确认；$10$ 位有效数字的题目必须留这道旁证。
