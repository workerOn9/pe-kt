# 966 · 三角形与圆的相交面积

> 中文意译。英文原文见 [Project Euler Problem 966](https://projecteuler.net/problem=966)；抓取底稿见 `statement.en.md`。

设 $I(a, b, c)$ 为边长为 $a, b, c$ 的三角形与一个面积等于该三角形的圆之间的最大可能相交面积。
例如 $I(3, 4, 5) \approx 4.593049$ 以及 $I(3, 4, 6) \approx 3.552564$。

对于满足 $1 \le a \le b \le c < a + b$ 且 $a + b + c \le 200$ 的整数 $a, b, c$，求 $I(a, b, c)$ 的总和。
四舍五入保留小数点后两位数字。
