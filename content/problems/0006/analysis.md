# 006 · 平方和之差 — 解析

## 思路推导

**暴力枚举**：遍历 1 到 100，分别累加 `sum` 与 `sumSq`，最后算 `sum² − sumSq`。O(n)，本题 n=100 瞬间完成。

**公式优化**：两条经典求和公式直接代入。

和的平方：

$$S_1 = \frac{n(n+1)}{2} = \frac{100 \times 101}{2} = 5050,\qquad S_1^2 = 25502500$$

平方和：

$$S_2 = \frac{n(n+1)(2n+1)}{6} = \frac{100 \times 101 \times 201}{6} = 338350$$

答案：

$$S_1^2 - S_2 = 25502500 - 338350 = 25164150$$

还能进一步化简出一个闭式：

$$S_1^2 - S_2 = \frac{n^2(n+1)^2}{4} - \frac{n(n+1)(2n+1)}{6} = \frac{n(n+1)(n-1)(3n+2)}{12}$$

代入 $n=100$：$\frac{100 \times 101 \times 99 \times 302}{12} = 25164150$，验证一致。

## 复杂度对比

| 方案 | 时间 | 实测（JIT 预热后） |
|------|------|------|
| 暴力枚举 | O(n) | ~0.23 µs |
| 公式直算 | O(1) | ~0.02 µs |

与 001 同构：规模一小两者都无所谓，规模一大（比如 n 改成 $10^{15}$）公式仍是常数时间，而且暴力在 $n > 10^9$ 时连循环都跑不完。**先推公式，再写循环。**

## 实现要点

- 用 `Long`：$n=100$ 时 $5050^2 = 25502500$ 已超 `Int` 的一半，n 稍大就溢出
- `solve(n)` 参数化，默认 100，方便换规模做对比实验
- 平方和公式分母 6 一定整除（三个连续整数 $n, n+1, 2n+1$ 中必含 2 和 3 的倍数），整数除法安全
