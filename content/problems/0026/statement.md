# 倒数的循环节

> 中文意译。英文原文见 [Project Euler Problem 26](https://projecteuler.net/problem=26)；抓取底稿见 `statement.en.md`。

单位分数指分子为 $1$ 的分数。分母从 $2$ 到 $10$ 的单位分数，其十进制表示如下：

| 分数 | 十进制表示 |
|------|-----------|
| $1/2$ | $0.5$ |
| $1/3$ | $0.(3)$ |
| $1/4$ | $0.25$ |
| $1/5$ | $0.2$ |
| $1/6$ | $0.1(6)$ |
| $1/7$ | $0.(142857)$ |
| $1/8$ | $0.125$ |
| $1/9$ | $0.(1)$ |
| $1/10$ | $0.1$ |

其中 $0.1(6)$ 表示 $0.166666\cdots$，即它有 $1$ 位循环节。可以看到 $1/7$ 有 $6$ 位循环节。

求 $d < 1000$ 中，使得 $1/d$ 的小数部分具有最长循环节的 $d$。
