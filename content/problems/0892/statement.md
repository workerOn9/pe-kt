# 892 · 斑马圆割

> 中文意译。英文原文见 [Project Euler Problem 892](https://projecteuler.net/problem=892)；抓取底稿见 `statement.en.md`。

考虑一个圆，其圆周上标记了 $2n$ 个不同点。

一种割法 $C$ 是用 $n$ 条线段连接这 $2n$ 个点，且任意两条线段均不相交（包括端点也不重合）。这 $n$ 条线段将圆划分为 $n + 1$ 个区域。每个区域被涂成黑色或白色，使得相邻区域颜色相反。设 $d(C)$ 为在割法 $C$ 下黑色区域数量与白色区域数量之差的绝对值。

设 $D(n)$ 为所有不同割法 $C$ 的 $d(C)$ 之和。例如，当 $n = 3$ 时共有五种不同的割法。

![n=3 时的五种割法及黑白染色](0892_Zebra.png)

上方的三种割法中，都有 2 个黑区域和 2 个白区域，因而 $d = 0$；下方的两种割法中，都有 3 个黑区域和 1 个白区域，因而 $d = 2$。因此 $D(3) = 0 + 0 + 0 + 2 + 2 = 4$。已知 $D(100) \equiv 1172122931 \pmod{1234567891}$。

求：

$$
\sum_{n=1}^{10^7} D(n)
$$

并将答案对 $1234567891$ 取模。
