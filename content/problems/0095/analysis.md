# 095 · 亲和数链 — 解析

## 思路推导

记 $\sigma(n)$ 为 $n$ 的真因数之和（不含 $n$ 自身）。题目要求一张有向图 $n \to \sigma(n)$ 上**所有元素都不超过 $10^6$ 的最长环**中的最小元素。

**批量求真因数和。** 对 $1 \le n \le N$ 逐个试除要 $O(N\sqrt N)$。改用倍率筛：枚举 $d$，把 $d$ 加到它的每个倍数上，

$$\sigma(n) = \sum_{d \mid n,\ d < n} d \iff \forall d:\ \sigma[2d] \mathrel{+}= d,\ \sigma[3d] \mathrel{+}= d,\ \sigma[4d] \mathrel{+}= d,\ \dots$$

总操作数 $\sum_{d \le N/2} N/d = O(N \log N) \approx 1.4\times10^7$，比试除法（约 $7\times10^8$）快两个数量级。上界：$n \le 10^6$ 时最大的真因数和为 $\sigma(997920) = 3392928$，`Int` 足够。

**环检测。** 用 `pos[cur]` 记录节点在当前路径中的下标（$-1$ 未访问、$-2$ 已彻底处理）。从每个尚未访问的起点走链：

- 遇到 $< 1$ 或 $> 10^6$ 的值（例如 $\sigma(1) = 0$）——链逃出定义域，作废；
- 遇到 `pos = -2` 的节点——它属于某条已分析过的链，不可能再贡献新环，剪枝；
- 遇到 `pos >= 0` 的节点——说明链走回自己的路径，从该下标到路径末尾恰是一个环，环长 $= |path| - idx$。

**为什么整体是线性的。** 每条新路径走完后整段标记为已处理，之后任何起点遇到它们都会立刻停下。每个节点至多作为「未访问」被展开一次，故总时间是 $O(N \log N)$（筛法）+ $O(N)$（走链）。

枚举结果：最长环的长度为 $28$，其最小元素是 **14316**。

## 复杂度对比

| 方案 | 时间 | 实测（JIT 预热后） |
|------|------|------|
| 优化解：倍率筛求 $\sigma$ + 路径下标环检测 | $O(N \log N)$，$N = 10^6$ | ~146.447 ms |
| 暴力解：试除法求 $\sigma$ + 每个起点独立走链直到回到自身 | $O(N\sqrt N + \sum L)$ | ~47620.078 ms |

约 325 倍（暴力解参数：warmup=1 runs=1，单次约 48 秒，无法承受更多轮次）。差距主要来自两处：$\sigma$ 的计算方式，以及暴力解对 $10^6$ 个起点各自重走整条链、而优化解让每个节点只被展开一次。

## 实现要点

- $\sigma(1) = 0$，链一旦落到 $0$ 就作废；「元素不超过一百万」也意味着链不许可向上越界
- 环的检测必须区分「当前路径上的节点」与「已处理完的节点」，只用一个 visited 布尔量会漏掉环或误报
- 环长并列时取更小的最小元素；本题最长环唯一，无需真正比较
- 筛法上界取 $N/2$ 即可：$d > N/2$ 时 $2d > N$ 已越界
- 整条路径的统一标记让每个数只被走一次，这是从 $O(N \cdot L)$ 降到 $O(N)$ 的关键
