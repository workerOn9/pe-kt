# 异或解密

> 中文意译。英文原文见 [Project Euler Problem 59](https://projecteuler.net/problem=59)；抓取底稿见 `statement.en.md`。

计算机中的每个字符都被赋予唯一的编码，最常用的标准是 ASCII（美国信息交换标准代码）。例如大写字母 `A` $= 65$、星号 `*` $= 42$、小写字母 `k` $= 107$。

一种现代的加密方法是：把文本文件转成 ASCII 字节，再把每个字节与取自密钥的一个值做 XOR（异或）运算。XOR 的优点是同一把密钥作用在密文上就能还原明文——例如 $65 \oplus 42 = 107$，而 $107 \oplus 42 = 65$。

若要不可破译，密钥应与明文等长且由随机字节组成，用户把密文与密钥分开存放，缺了任何一半都无法解密。

可惜这种做法对大多数用户并不实用，于是改用密码作为密钥：当密码比消息短（这是常态）时，密钥就在整条消息上循环重复。这一方案的平衡点在于：密码要足够长以保证安全，又要短到便于记忆。

本题已经为你降低了难度：加密密钥由三个小写字母组成。文件 `cipher.txt` 中存放的是用逗号分隔的加密 ASCII 码，且已知明文必然包含常见英文单词。请解密这条消息，并求出原文中所有 ASCII 值之和。
