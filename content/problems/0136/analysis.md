# 136 · 唯一的差 — 解析

## 思路推导

**第一步：把方程归约成一对正整数因子。** $x^2 - y^2 - z^2 = n > 0$ 排除了三者递增与三者相等的情形，所以等差

$$
x = a + d, \qquad y = a, \qquad z = a - d
$$

中的公差 $d \ge 1$，中间项 $a \ge 1$，而 $z > 0$ 要求 $a \ge d + 1$。代入得

$$
n = (a+d)^2 - a^2 - (a-d)^2 = 4ad - a^2 = a(4d - a).
$$

令 $u = a$、$v = 4d - a$，则 $uv = n$；反过来 $d = (u+v)/4$ 必须是正整数，而 $a \ge d+1$ 等价于

$$
4a \ge a + v + 4 \iff 3u - v \ge 4 .
$$

于是「$n$ 的解数」$R(n)$ 就是满足

$$
uv = n, \qquad u + v \equiv 0 \pmod 4, \qquad 3u - v \ge 4
$$

的有序对 $(u,v)$ 的个数。这是一一对应：$(u,v) \mapsto (a,d)$ 与 $(a,d) \mapsto (u,v)$ 互为逆映射，既不会漏也不会重。

**第二步：先只数模 4 条件。** 记

$$
F(n) = \#\{(u,v) : uv = n,\ u + v \equiv 0 \pmod 4\}.
$$

写 $n = 2^s m$（$m$ 为奇数）、$u = 2^i\rho$、$v = 2^j\sigma$，则 $i + j = s$、$\rho\sigma = m$。

- $s = 0$：$u,v$ 皆奇，$u+v \equiv 0 \pmod 4$ 等价于「一个因子 $\equiv 1$、另一个 $\equiv 3 \pmod 4$」。$n \equiv 3 \pmod 4$ 时由 $uv \equiv 3$ 自动成立，全部 $\tau(n)$ 个因子对合格；$n \equiv 1 \pmod 4$ 时任何因子对的两个因子同余，一对也不合格。
- $s = 1$：$u,v$ 一奇一偶，$u+v$ 为奇数，$F(n) = 0$。
- $s \ge 2$：若 $i \ne j$（不妨设 $i < j$），则 $u + v = 2^i(\rho + 2^{j-i}\sigma)$，括号内为奇数（$\rho$ 奇、$2^{j-i}\sigma$ 偶），故 $4 \mid u+v \iff i \ge 2$；若 $i = j = s/2$，则 $u + v = 2^{s/2}(\rho + \sigma)$，由 $\rho + \sigma$ 为偶数知 $v_2(u+v) \ge s/2 + 1 \ge 2$ 恒成立。

记合格的指数分配数为 $g(s)$：$s = 2$ 时只有 $(1,1)$，$g(2) = 1$；$s = 3$ 时两种分配都含指数 1，$g(3) = 0$；$s \ge 4$ 时 $i$ 可取 $2,3,\dots,s-2$ 共 $s-3$ 个值，偶数 $s$ 还要添上 $i = j = s/2$ 那一种，恰好仍是 $s - 3$。每种分配可搭配 $\tau(m)$ 组 $(\rho,\sigma)$，故

$$
F(n) = \tau(m)\,g(s), \qquad g(2) = 1,\quad g(3) = 0,\quad g(s) = s - 3 \ (s \ge 4).
$$

**第三步：把 $3u - v \ge 4$ 拆成「主方向 + 补一记」。** 把 $F$ 的成对方向折半，得到合格的无序因子对数 $C(n)$（完全平方的平方根只算一次）：

$$
C(n) = \frac{F(n) + \mathbf{1}[\,n\ \text{是完全平方数且}\ \sqrt n\ \text{为偶数}\,]}{2}.
$$

对任意无序对 $\{w, w'\}$（$w < w'$、$ww' = n$），方向 $(w',w)$ 永远合法，因为

$$
3w' - w \ge 3w' - (w'-1) = 2w' + 1 \ge 2\sqrt n + 1 > 4 \qquad (n \ge 3).
$$

方向 $(w,w')$ 是否也合法，则取决于

$$
3w - w' \ge 4 \iff 3w^2 - 4w \ge n .
$$

把只数后者（$w < \sqrt n$，因此完全平方的中点不计入）的个数记为 $D(n)$，于是

$$
R(n) = C(n) + D(n), \qquad R(n) = 1 \iff C(n) = 1 \ \text{且}\ D(n) = 0 .
$$

**第四步：枚举 $C(n) = 1$。** 由 $F = \tau(m)g(s)$ 逐个检查 $F \le 2$ 的情形（并注意完全平方修正项的奇偶性——$n$ 为平方且根为偶数时 $F$ 必为奇数），$C(n) = 1$ 当且仅当 $n$ 属于下面四族：

1. $n$ 是 $\equiv 3 \pmod 4$ 的素数（$s = 0$，$\tau = 2$，$F = 2$）；
2. $n = 4$ 与 $n = 4p$，$p$ 为奇素数（$s = 2$，$F = \tau(m) = 1$ 或 $2$）；
3. $n = 16$ 与 $n = 16p$，$p$ 为奇素数（$s = 4$，$F = \tau(m) \le 2$）；
4. $n = 32$（$s = 5$、$m = 1$，$F = 2$）。

**第五步：逐一核对 $D(n)$。**

- 素数的唯一因子对是 $\{n,1\}$，$w = 1$ 太小：$3 \cdot 1 - 4 = -1 < n$，所以 $D = 0$。
- $4$、$16$ 的因子对是中点 $(2,2)$、$(4,4)$，不构成第二个方向，$D = 0$。
- $4p$、$16p$ 的因子对是 $\{2,2p\}$、$\{4,4p\}$，平衡性条件分别是 $4 \ge 4p$、$32 \ge 16p$，即 $p \le 1$、$p \le 2$，奇素数都不满足，$D = 0$。
- 只有 $n = 32$ 的因子对 $\{4,8\}$ 满足 $3 \cdot 4^2 - 4 \cdot 4 = 32 \ge 32$，即 $R(32) = C + D = 2$，必须扣掉。

于是本题的答案就是集合

$$
\{\,\equiv 3 \pmod 4\ \text{的素数}\,\} \cup \{4, 16\} \cup \{4p,\ 16p : p\ \text{为奇素数}\,\}
$$

在 $n < N$ 内的元素个数：

$$
A(N) = \pi_3(N) + \mathbf{1}[N > 4] + \pi_{\text{奇}}\!\left(\left\lfloor \tfrac{N-1}{4} \right\rfloor\right)
      + \mathbf{1}[N > 16] + \pi_{\text{奇}}\!\left(\left\lfloor \tfrac{N-1}{16} \right\rfloor\right),
$$

其中 $\pi_3$ 数 $\equiv 3 \pmod 4$ 的素数，$\pi_{\text{奇}}(x)$ 数不超过 $x$ 的奇素数。$N = 100$ 时是 $13 + 1 + 8 + 1 + 2 = 25$，与题面的「二十五个」吻合；$N > 32$ 时 $\{4,16\}$ 两项恰与 $\pi_{\text{奇}}$ 里 $p = 2$ 的两次多算抵消，还能写成更整齐的

$$
A(N) = \pi_3(N) + \pi\!\left(\left\lfloor \tfrac{N-1}{4} \right\rfloor\right) + \pi\!\left(\left\lfloor \tfrac{N-1}{16} \right\rfloor\right).
$$

## 独立验证与答案

对照解 [brute-force.kt](brute-force.kt) 走的是完全不同的路：不做任何数论归约，直接对公差 $d$ 与中间项 $a$（$d+1 \le a \le 4d-1$）正向枚举 $n = a(4d-a)$，用字节计数数组累加解数，最后数出「计数恰为 1」的个数。它在 $5 \times 10^7$ 规模上共枚举 **118 626 557** 个 $(d,a)$ 组合，得到

$$
21\,874\,999\ \text{个 } n\ \text{至少有一个解，其中恰一个解}\ \mathbf{2\,544\,559}\ \text{个，恰两个}\ 5\,896\,962\ \text{个，三个以上}\ 13\,433\,478\ \text{个}.
$$

两个程序独立跑出的答案完全相同。

第二重验证是题面自身给出的锚点与手算样例（两文件各自断言）：

| 检查 | 结果 |
|---|---|
| $n = 20$（题面样例） | 唯一解 $(x,y,z) = (13,10,7)$ |
| $n < 100$（题面样例） | 25 个，优化解与定义枚举都给出 25 |
| $n < 1000$ | 158 个 |
| $n = 3,\ 4,\ 16,\ 48$ | 各 1 个解 |
| $n = 8$ | 0 个解（$8 = 2^3$，$s = 3$ 时 $g(s) = 0$） |
| $n = 15$ | 3 个解：$(5,3,1)$、$(7,5,3)$、$(19,15,11)$ |
| $n = 32$ | 2 个解：$(7,4,1)$、$(11,8,5)$ |

小规模上还做了双向对照：$N = 100,\ 1000,\ 10^4$ 处「由刻画构造的集合」与「按定义枚举得到的集合」逐元素相同；分段位筛与朴素筛在 $N \le 10^6$ 的五个规模上三项计数逐项相同。

全量下三段计数为 $\pi_3(5\times10^7) = 1\,500\,681$、不超过 $12\,499\,999$ 的素数 $818\,703$ 个、不超过 $3\,124\,999$ 的素数 $225\,175$ 个，和为 **2544559**。

## 复杂度对比

对照解把 $m = 4d - a$ 当主变量，对每个 $m$ 枚举 $d \in [\lceil (m+1)/3 \rceil,\ \lfloor (N + m^2 - 1)/(4m) \rfloor]$，迭代总数是 $\Theta(N \log N)$ 量级（$\sum_m N/(4m)$，$m$ 到 $\sqrt{3N} \approx 12247$ 为止），实测 $118\,626\,557$ 次；优化解只做一次 $O(N \log\log N)$ 的筛。两者实测耗时相差 $535.5708 / 78.1512 \approx 6.9$ 倍。

| 方案 | 时间 | 空间 | 实测（JIT 预热后） |
|---|---|---|---|
| 优化：数论刻画 + 分段位筛 | $O(N \log\log N)$ | $O(\sqrt N)$ + 8 KB 段缓冲 | 78.1512 ms |
| 对照：按定义枚举全部 $(d,a)$ | $\Theta(N \log N)$，约 $1.19\times10^8$ 次 | $O(N)$ 字节 | 535.5708 ms |

计时口径：两个解都在程序内 JIT 预热后自报耗时，由主 Agent 在空闲机器上各编译一次、独立进程重复 5 次取最小值；数字已同步进 `meta.json` 的两个 baseline 字段。

## 实现要点

- **严格小于的边界**：$4p < N$ 等价于 $p \le \lfloor (N-1)/4 \rfloor$，写成 $N/4$ 会多算一个素数；$16p$ 同理。$N = 100$ 这种小规模最容易暴露这里的差一位。
- **$n = 32$ 是唯一要扣的项**：$32 = 16 \cdot 2$，与 $16p$（$p$ 为奇素数）同属 $s = 4$ 分支，也有 $C(32) = 1$；但它的因子对 $\{4,8\}$ 两个方向都合法（$D(32) = 1$），解数是 2 而不是 1。它是本题里唯一「$C = 1$ 而 $R = 2$」的 $n$，正是它把一百以内的候选数从 26 拉回题面给出的 25。
- **分段位筛的三个易错点**：每段用 `Arrays.fill(bits, -1L)` 重置后必须把最后一个字的有效位以外的位清零（否则上一段的陈旧位会被数成素数）；标记从 $p^2$ 起（用 $q \ge p$ 夹住起步倍数），否则会把 $p$ 自己划掉；$k$ 为奇数 $\iff 2k+1 \equiv 3 \pmod 4$，所以第 3 类素数用 `Long.bitCount(bits[w] and 0xAAAA…/0x5555…)` 整字取，不必逐个取模。段长取 65536 个奇数（8 KB 位图）是为了让标记循环落在 L1 上：朴素布尔数组在大素数跨步标记时每一步都可能撞 50 MB 数组的缓存缺失。同一次进程内对比测量里，「朴素布尔筛选 + 一次计数扫描」的耗时约为分段位筛的两倍（倍率取自同机同一进程的对比测量，表中是空闲机器上的权威绝对值）。
- **溢出**：对照解的最大中间量是 $N + m^2 - 1 \approx 1.5\times10^8$；优化解里最大的段内定位量 $pq$ 与 $2k+1$ 都不超过 $5\times10^7$。这些都还在 `Int` 上限内，但代码里一律先用 `Long` 算乘积，免得边界上写出负数。
- **不要用 `% 4` 数数**：$n \equiv 1, 2 \pmod 4$ 与 $n \equiv 8 \pmod{16}$ 一个解都没有，这条结论由 $F$ 的公式自动给出（$s = 0$ 且 $n \equiv 1$、$s = 1$、$s = 3$），不需要额外的特判，也不需要按余数分类枚举。
