# 五边形数

> 中文意译。英文原文见 [Project Euler Problem 44](https://projecteuler.net/problem=44)；抓取底稿见 `statement.en.md`。

五边形数由公式 $P_n = n(3n-1)/2$ 生成，前十个是：

$$1,\ 5,\ 12,\ 22,\ 35,\ 51,\ 70,\ 92,\ 117,\ 145,\ \dots$$

可以验证 $P_4 + P_7 = 22 + 70 = 92 = P_8$；但它们的差 $70 - 22 = 48$ 并不是五边形数。

在所有满足「**和**与**差**都是五边形数」的数对 $P_j < P_k$ 中，$D = P_k - P_j$ 存在一个最小值。请求出这个最小的 $D$。
