# RSA 加密与未隐藏明文

RSA 加密算法基于以下过程：

生成两个互异的质数 $p$ 与 $q$。
计算模数 $n = pq$ 与欧拉函数值 $\phi = (p - 1)(q - 1)$。
选取公钥指数 $e$（$1 < e < \phi$），满足 $\gcd(e, \phi) = 1$。

在此密码体制中，明文消息是区间 $[0, n - 1]$ 内的整数 $m$。
加密过程计算密文 $c = m^e \bmod n$。
解密时计算满足 $ed \equiv 1 \pmod \phi$ 的私钥 $d$，再求 $m = c^d \bmod n$。

存在某些指数 $e$ 与明文 $m$，使得 $m^e \bmod n = m$ 成立。
我们称满足 $m^e \bmod n = m$ 的明文 $m$ 为**未隐藏消息**（unconcealed messages）。

在选取公钥指数 $e$ 时，未隐藏消息的数目应当尽可能少。
例如设 $p = 19, q = 37$，则 $n = 703, \phi = 648$。
若选取 $e = 181$，尽管满足 $\gcd(181, 648) = 1$，却会使得所有明文 $m \in [0, n - 1]$ 在加密后全部原样保持不变！
对于任何合法的 $e$，都必然存在若干未隐藏消息；因此关键是要让未隐藏消息的数目达到**最小值**。

设 $p = 1009$ 且 $q = 3643$。
求所有满足 $1 < e < \phi$、$\gcd(e, \phi) = 1$ 且使未隐藏消息数目达到最小值的指数 $e$ 的总和。
