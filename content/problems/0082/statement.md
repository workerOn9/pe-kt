# 路径和：三种走法

> 中文意译。英文原文见 [Project Euler Problem 82](https://projecteuler.net/problem=82)；抓取底稿见 `statement.en.md`。

**注意**：本题是第 81 题的高难度版本。

在下面这个 $5\times5$ 的矩阵中，从最左列的**任意一格**出发、到最右列的**任意一格**结束，只允许向上、向下、向右移动，最小路径和为 $994$（下表中加粗的格子构成这条路径）：

| | | | | |
|---|---|---|---|---|
| 131 | 673 | **234** | **103** | **18** |
| **201** | **96** | **342** | 965 | 150 |
| 630 | 803 | 746 | 422 | 111 |
| 537 | 699 | 497 | 121 | 956 |
| 805 | 732 | 524 | 37 | 331 |

请对 `matrix.txt`（一个约 31K 的文本文件，内含一个 $80\times80$ 的矩阵）求出从最左列到最右列的最小路径和。
