# 082 · 路径和：三种走法 — 解析

## 思路推导

与 81 题相比多了「向上」这一自由度：一旦允许上下移动，路径在同一列内可以折返，单行的前缀最优就不再成立。但**列与列之间依然只能向右**，这仍然是一条单向前进的结构，因此可以逐列推进。

设 $f_c(r)$ 为「从最左列任意格出发、终止于 $(r,c)$」的最小路径和。进入第 $c$ 列时有两条路：

1. 从 $(r,c-1)$ 向右走进来：代价 $f_{c-1}(r)+a_{r,c}$；
2. 从同列的另一行 $(p,c)$ 上下走到 $(r,c)$：代价为 $f_{c-1}(p)+a_{p,c}$ 再加上两行之间同列所有格子的值（列内路径唯一，必然逐格经过）。

于是

$$f_c(r)=\min_{p}\Bigl(f_{c-1}(p)+a_{p,c}+\sum_{k\text{ 在 }p,r\text{ 之间}} a_{k,c}\Bigr).$$

直接枚举 $p$ 是 $O(n)$ 每格、$O(n^2)$ 每列，总计 $O(n^3)$；但「列内上下走」本身是**路径图上的最短路**（每条边权为相邻格的值），可以用两次线性扫描精确求解：先向下松弛一遍

$$f_c(r)\leftarrow\min\bigl(f_{c-1}(r)+a_{r,c},\ f_c(r-1)+a_{r,c}\bigr),$$

再向上松弛一遍

$$f_c(r)\leftarrow\min\bigl(f_c(r),\ f_c(r+1)+a_{r,c}\bigr).$$

两次扫描合起来等于对所有 $p$ 取了 $\min$，因为任何从 $p$ 到 $r$ 的列内路径都单调（先单向走到底再折返不会更优，代价非负）。

**答案**：对 $5\times5$ 样例跑出 $994$（与题面一致），对 $80\times80$ 矩阵得 **260324**。

## 复杂度对比

| 方案 | 时间 | 实测（JIT 预热后） |
|------|------|------|
| 优化解：逐列 DP + 列内双向扫描 | $O(n^2)$（每列 $3n$ 次松弛，共 $n$ 列） | ~5.728 ms |
| 暴力解：多源 Bellman–Ford 全图松弛，跑满 $n^2-1$ 轮 | $O(n^4)$——每轮 $3n^2$ 次松弛，共 $n^2$ 轮 | ~337.860 ms |

约 59 倍差距来自「利用列间单向 + 列内路径结构」这两层信息：DP 每格只被处理常数次，Bellman–Ford 则是把整张图反复扫描几千轮。

## 实现要点

- 初始列 $f_0(r)=a_{r,0}$：起点可以是左列任意格，格子自身值计入
- 列内松弛的先后顺序：必须先向下、再向上，且第二遍要基于第一遍的结果；反序同样可行，但两遍缺一不可
- 新列数组用 `LongArray(n) { cur[it] + g[it][c] }` 一次性初始化，再原地松弛，避免额外的中间数组
- 暴力解将左列全部格子作为多源起点，最后取末列最小值
- 输入解析与 81 题共用同一份 `matrix.txt`，本题目录内已放置副本，运行基准时需 `cd content/problems/0082`
