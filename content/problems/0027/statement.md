# 二次素数

> 中文意译。英文原文见 [Project Euler Problem 27](https://projecteuler.net/problem=27)；抓取底稿见 `statement.en.md`。

欧拉发现了这样一个非凡的二次式：

$$n^2 + n + 41$$

可以验证，当 $n$ 取 $0 \le n \le 39$ 这 40 个连续整数时，它生成的值全都是素数。然而当 $n = 40$ 时，

$$40^2 + 40 + 41 = 40 \times (40 + 1) + 41$$

能被 $41$ 整除；而当 $n = 41$ 时，$41^2 + 41 + 41$ 显然也能被 $41$ 整除。

后来人们又发现了另一个惊人的二次式 $n^2 - 79n + 1601$，它在 $0 \le n \le 79$ 这 80 个连续取值下都生成素数，其两个系数的乘积为 $-79 \times 1601 = -126479$。

现在考虑所有形如

$$n^2 + an + b$$

的二次式，其中 $|a| < 1000$ 且 $|b| \le 1000$（$|n|$ 表示 $n$ 的绝对值，例如 $|11| = 11$、$|-4| = 4$）。

求：从 $n = 0$ 开始连续生成素数、且生成素数个数最多的那个二次式，其系数 $a$ 与 $b$ 的乘积。
