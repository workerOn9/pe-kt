# 027 · 二次素数 — 解析

## 思路推导

设 $f(n) = n^2 + an + b$，要求从 $n = 0$ 起 $f(0), f(1), \dots$ 连续为素数的最长长度。

**先砍掉绝大多数候选。** $f(0) = b$ 必须为素数，而素数都是 $\ge 2$ 的正整数，所以 $b$ 直接限定为不超过 1000 的素数——共 168 个，而不是 2001 个整数。又由

$$f(b) = b^2 + ab + b = b\,(b + a + 1)$$

知 $n = b$ 时 $f(b)$ 必被 $b$ 整除且大于 $b$，必为合数。因此任何二次式的素数链长度至多为 $b$，最优解的 $b$ 必然大于最终链长。进一步，$f(1) = 1 + a + b$ 是奇素数时 $a$ 必为奇数（$b$ 为奇素数），可以把 $a$ 的枚举量再减半——本题规模小，留作练习，不强求。

**素性判定：筛法一次预生成，全场 $O(1)$ 查表。** 由于链长 $< b \le 1000$，中途所有 $f(n) = n^2 + an + b$ 的值不超过约 $10^6$ 量级（保守起见筛到 $2 \times 10^6$），用埃氏筛一次生成布尔表，内层枚举只做数组下标查询。每个 $(a, b)$ 对的链长用一次 `while` 连续计数即可，无需为每个 $n$ 单独判断「链是否中断」。

**枚举与记录**：$a$ 遍历 $-999 \dots 999$，$b$ 遍历 2 到 1000 的素数，逐对计数链长，维护最大值与对应的 $(a, b)$。最终最长链出现在 $a = -61,\ b = 971$，连续生成 71 个素数，乘积

$$a \times b = -61 \times 971 = -59231$$

答案：**-59231**。

## 复杂度对比

| 方案 | 时间 | 实测（JIT 预热后） |
|------|------|------|
| 优化解：埃氏筛预生成 + 素数 $b$ 剪枝 + 查表计数 | $O(N \log \log N + 2000 \times \pi(1000) \times L)$，查表 $O(1)$ | ~5.78 ms |
| 暴力解：试除法现场判素，不预筛 | 每次判定 $O(\sqrt{v})$，且同一数值被重复判定 | ~13.74 ms |

约 2.4 倍差距来自素性判定的成本结构：暴力解对每个 $f(n)$ 都重新做试除到 $\sqrt{v}$，而优化解把全部判定摊销成一次筛法 + $O(1)$ 查表。本题值域仅 $2 \times 10^6$，试除的常数尚可忍受；值域再大一个数量级，试除法就会因 $\sqrt{v}$ 因子被进一步拉开。

## 实现要点

- $b$ 必须是素数：内层只遍历 2..1000 的素数（168 个），候选组合从 200 万级降到约 34 万
- 链长上界 $n < b$ 由 $f(b) = b(b+a+1)$ 保证，天然限制了内层循环深度
- 埃氏筛到 $2 \times 10^6$ 覆盖所有可能取值，循环内零次素性计算、只做布尔数组查询
- 计数用 `while` 连续自增，一次遍历即得链长；更新最优时同步记录 $a, b$
- 返回值注意转 `Long`：乘积为负且绝对值超 `Int` 安全区时需避免溢出（本题 $-59231$ 在 Int 范围内，仍统一按规范转出）
