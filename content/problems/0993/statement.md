# 993 · 香蕉海狸

> 中文意译。英文原文见 [Project Euler Problem 993](https://projecteuler.net/problem=993)；抓取底稿见 `statement.en.md`。

一只海狸在一条无限长的数轴上玩游戏。
游戏开始时，海狸位于位置 $0$，身上携带着 $N$ 根香蕉，数轴上没有任何其他香蕉。
在每一步中，海狸根据其当前位置 $x$ 以及在位置 $x$ 和 $x + 1$ 处观察到的香蕉情况执行以下规则：

- 如果位置 $x$ 和位置 $x + 1$ 处各有一根香蕉，则海狸拾起位置 $x+1$ 处的一根香蕉，并移动到位置 $x-1$；
- 如果位置 $x$ 处有一根香蕉但位置 $x+1$ 处没有香蕉，则海狸拾起位置 $x$ 处的一根香蕉，并移动到位置 $x+2$；
- 如果位置 $x$ 处没有香蕉但位置 $x+1$ 处有一根香蕉，则海狸将位置 $x+1$ 处的一根香蕉移到位置 $x$，并移动到位置 $x+2$；
- 如果位置 $x$ 和位置 $x + 1$ 处均没有香蕉，则海狸检查身上是否仍携带至少 3 根香蕉。若是，则它在三个位置 $x - 1, x, x + 1$ 各放下一根香蕉，并移动到位置 $x-2$；若携带不足 3 根香蕉，游戏结束。

例如，当 $N \ge 3$ 时，起始位置适用最后一条规则，因此经过 1 步后，数轴上的位置 $-1, 0, 1$ 处各有一根香蕉，海狸位于位置 $-2$。
类似地，当 $N \ge 5$ 时，经过 5 步后，数轴上的位置 $-2, -1, 0, 1, 2$ 处各有一根香蕉，海狸位于位置 $-1$。

设 $\operatorname{BB}(N)$ 为游戏结束时海狸所在的位置（可以证明游戏总是会结束）。
已知 $\operatorname{BB}(1000) = 1499$。

求 $\operatorname{BB}(10^{18})$。
