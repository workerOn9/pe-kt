# Ulam 序列

对两个正整数 $a$、$b$，Ulam 序列 $U(a,b)$ 定义为：$U(a,b)_1 = a$，$U(a,b)_2 = b$，且当 $k > 2$ 时，$U(a,b)_k$ 是大于 $U(a,b)_{k-1}$ 的最小的、能够**恰好以一种方式**表示为序列中两个**不同**先前项之和的数。

例如序列 $U(1,2)$ 以如下方式开始：

$$1,\; 2,\; 3 = 1+2,\; 4 = 1+3,\; 6 = 2+4,\; 8 = 2+6,\; 11 = 3+8$$

$5$ 不在其中，因为 $5 = 1+4 = 2+3$ 有两种表示；$7 = 1+6 = 3+4$ 同理。

求 $\sum\limits_{n=2}^{10} U(2,2n+1)_k$，其中 $k = 10^{11}$。
