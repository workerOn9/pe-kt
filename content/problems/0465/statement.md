# 465 · 极性多边形

> 中文意译。英文原文见 [Project Euler Problem 465](https://projecteuler.net/problem=465)；抓取底稿见 `statement.en.md`。

多边形的**核**定义为这样一组点的集合：从其中任一点出发都能看到该多边形的整条边界。若一个多边形的核严格包含原点，则称该多边形为**极性多边形**。

在本题中，一个多边形可以有连续共线的顶点，但仍然不能自交，也不能面积为零。

例如，下面五个多边形中只有第一个是极性多边形（第二、第三、第四个的核不严格包含原点，第五个则根本没有核）：

![五个多边形的示意图：只有第一个是极性多边形](0465_polygons.png)

注意第一个多边形有三个连续共线的顶点。

记 $P(n)$ 为所有顶点 $(x, y)$ 坐标均为整数且绝对值不超过 $n$ 的极性多边形的个数。

注意：只要边的集合不同，即使围出的区域相同，多边形也要分别计数。例如，顶点为 $[(0,0),(0,3),(1,1),(3,0)]$ 的多边形与顶点为 $[(0,0),(0,3),(1,1),(3,0),(1,0)]$ 的多边形是不同的。

例如 $P(1) = 131$，$P(2) = 1648531$，$P(3) = 1099461296175$，$P(343) \bmod 1\,000\,000\,007 = 937293740$。

求 $P(7^{13}) \bmod 1\,000\,000\,007$。
