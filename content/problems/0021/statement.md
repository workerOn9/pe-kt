# 亲和数

> 中文意译。英文原文见 [Project Euler Problem 21](https://projecteuler.net/problem=21)；抓取底稿见 `statement.en.md`。

记 d(n) 为 n 的真因子之和（真因子指小于 n 且能整除 n 的数）。
若 d(a) = b 且 d(b) = a，其中 a ≠ b，则称 a 与 b 为一对亲和数对，a 和 b 都称为亲和数。

例如，220 的真因子为 1, 2, 4, 5, 10, 11, 20, 22, 44, 55 和 110，因此 d(220) = 284；而 284 的真因子为 1, 2, 4, 71 和 142，故 d(284) = 220。

求所有小于 10000 的亲和数之和。
