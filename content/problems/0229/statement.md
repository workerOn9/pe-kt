考虑数字 $3600$。它非常特殊，因为

$$
\begin{aligned}
3600 &= 48^2 + &&36^2\\
3600 &= 20^2 + 2 \times &&40^2\\
3600 &= 30^2 + 3 \times &&30^2\\
3600 &= 45^2 + 7 \times &&15^2
\end{aligned}
$$

类似地，可以验证 $88201 = 99^2 + 280^2 = 287^2 + 2 \times 54^2 = 283^2 + 3 \times 52^2 = 197^2 + 7 \times 84^2$。

1747 年，欧拉证明了哪些数字可以表示成两个平方数之和。我们感兴趣的是那些同时具有下列四种表示的 $n$：

$$
\begin{aligned}
n &= a_1^2 + && b_1^2\\
n &= a_2^2 + 2 && b_2^2\\
n &= a_3^2 + 3 && b_3^2\\
n &= a_7^2 + 7 && b_7^2,
\end{aligned}
$$

其中 $a_k$ 与 $b_k$ 都是正整数。

已知不超过 $10^7$ 的这类数字有 $75373$ 个。
