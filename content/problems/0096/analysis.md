# 096 · 数独 — 解析

## 思路推导

数独是典型的**约束满足问题**（CSP）：变量是 $81$ 个格子，每个变量取值 $\{1,\dots,9\}$，约束是「同行、同列、同宫互不相同」。对每个变量，三个约束各自对应一个已用数字集合，候选集合就是三者补集的交集。

**位掩码表示约束。** 用 $9$ 位整数（bit $1$ 到 bit $9$）表示「已用过哪些数字」：

$$\text{used}(i) = R_{r(i)} \mid C_{c(i)} \mid B_{b(i)},\qquad \text{cand}(i) = \sim\text{used}(i) \cap \{1,\dots,9\}.$$

一次按位或就把「行 + 列 + 宫」三条约束合并，判定一个数字是否可用只需一次位与——比逐格扫描 $27$ 个位置快一个数量级。放置/撤销数字同样是两次异或（或与补码与）。

**MRV 启发式。** 朴素的填格顺序是「从左到右、从上到下」，但搜索树的规模对顺序极其敏感。**最小剩余值优先**（Minimum Remaining Values）每次选择候选数最少的空格展开：

$$i^{*} = \arg\min_{g(i)=0} |\text{cand}(i)|.$$

理由是：候选只有 $1$ 个的格子一旦存在，就是被迫赋值，先填它不会引入任何分支；而候选数为 $0$ 则说明当前分支已死，可以立刻回溯。这两类剪枝都不改搜索的完备性，却能把分支因子压得很小。加上五十个盘面都只有唯一解，实际探索的节点数远小于 $9^{81}$。

**答案汇集。** 每个解盘面左上角三位数为 $100g_0 + 10g_1 + g_2$，五十盘累加。

答案：**24702**。

## 复杂度对比

| 方案 | 时间 | 实测（JIT 预热后） |
|------|------|------|
| 优化解：位掩码约束 + MRV 启发式 | $O(9^{\text{空位数}})$ 最坏，实际观测节点数很少 | ~2.732 ms |
| 暴力解：按编号顺序填格，线性合法性校验 | 同一搜索树，但无启发式、单次判合法 $O(27)$ | ~74.292 ms |

两者的搜索空间上界相同，$27$ 倍的差距全部来自「常数」与「顺序」：位掩码把每次判合法从 $27$ 次比较降到 $1$ 次位与，MRV 则让搜索树本身变小。这也说明 CSP 求解器的两个主要工程方向——**更好的约束表示**与**更好的变量排序**。

## 实现要点

- 掩码用 `1 shl d` 表示数字 $d$，bit 0 空闲不用，避免与「数字 0」混淆
- `search` 在扫描候选时若发现 `cnt == 0` 立即返回 false，这是最有效的失败检测
- 找到候选数为 $1$ 的格子即可提前终止扫描（`if (cnt == 1) break`），它是当前最紧的变量
- 回溯时必须把 `rows/cols/boxes` 恢复到之前状态，否则搜索会「污染」兄弟分支
- 输入用 `startsWith("Grid")` 跳过每个盘面的标题行，按每 9 行切分盘面
