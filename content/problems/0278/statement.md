给定整数 $1 < a_1 < a_2 < \dots < a_n$，考虑只用非负整数系数的线性组合

$$
q_1a_1 + q_2a_2 + \dots + q_na_n = b,\qquad q_k \ge 0 .
$$

注意对给定的一组 $a_k$，并不是所有 $b$ 都能被表示。例如 $a_1 = 5$、$a_2 = 7$ 时，$b$ 取 $1,2,3,4,6,8,9,11,13,16,18,23$ 这些值都无法表示；而 $23$ 正是 $a_1=5$、$a_2=7$ 时不能表示的最大值，于是我们记 $f(5,7) = 23$。

同样可以算出 $f(6,10,15) = 29$、$f(14,22,77) = 195$。

求 $\displaystyle\sum f(pq,\,pr,\,qr)$，其中 $p,q,r$ 都是素数且 $p < q < r < 5000$。
