# 278 — Linear Combinations of Semiprimes（半素数的线性组合）

## 建模

题目要的是**三生成元 Frobenius 数**：对两两互素的 $a,b,c \ge 2$，

$$
S = \sum_{p<q<r<5000} g(pq,\,pr,\,qr),\qquad g = \text{不能表示为非负整数组合的最大整数}.
$$

### 关键公式

$$
\boxed{\,g(ab,\,ac,\,bc) = 2abc - ab - ac - bc\,}
$$

**证明.** 写 $N = ab\,x + ac\,y + bc\,z$（$x,y,z \ge 0$）。令 $z_0 \in [0,a)$ 是满足 $z_0 \equiv N(bc)^{-1} \pmod a$ 的规范余数——它是必要的：$N - bc\,z \equiv 0 \pmod a$ 逼出 $z \equiv N(bc)^{-1} \pmod a$。于是 $z = z_0 + at$（$t \ge 0$），代入得

$$
N = bc\,z_0 + a\,M,\qquad M := bx + cy + bc\,t \ \ge 0 .
$$

这说明 $N$ 可表示 $\iff$ 存在 $z_0 \in [0,a)$（由 $N$ 唯一决定）与 $s \equiv M \pmod{bc}$、$0 \le s \le M$、$s \in \langle b,c\rangle$。记 $w(\rho)$ 为 $\langle b,c\rangle$ 中 $\equiv \rho \pmod{bc}$ 的最小元素（Apéry 元素），则

$$
N \text{ 可表示} \iff M \ge w(M \bmod bc). \qquad(\ast)
$$

这里要用到两点：可表示的 $N$ 一定落在参数化像里（$M \ge 0$）；而不在像里的 $N$ 满足 $M = (N - bc\,z_0)/a < 0$，即 $N < bc\,z_0 \le bc(a-1)$，比下面得到的上界更小，不影响最大值。而 $M \ge 0$ 时 $(z_0, M) \mapsto N = bc\,z_0 + aM$ 与 $N$ 一一对应（$N$ 的 $z_0$ 由 $N \bmod a$ 唯一决定）。

**两数情形的两个事实**（古典结论）：$\rho$ 可被 $\langle b,c \rangle$ 表示时 $w(\rho) = \rho$；$\rho$ 是间隙时 $w(\rho) = \rho + bc$——因为 $\rho + bc > g(b,c) = bc-b-c$ 必可表示，而 $\rho$ 与 $\rho - bc$ 是同类中仅有的两个 $< \rho + bc$ 的候选，$\rho$ 又不可表示。

于是由 $(\ast)$，**不可表示**的 $N$ 恰是 $M < w(\rho)$、$\rho = M \bmod bc$ 的情形；由前一事实 $M < \rho + bc$ 且 $M \equiv \rho$，只能 $M = \rho$ 且 $\rho$ 是间隙。所以不可表示的 $N$ 恰为

$$
N = bc\,z_0 + a\,\rho,\qquad z_0 \in [0,a),\ \rho\ \text{是}\ \langle b,c\rangle\ \text{的间隙},
$$

其最大值为

$$
bc(a-1) + a\cdot g(b,c) = bc(a-1) + a(bc-b-c) = 2abc - ab - ac - bc,
$$

在 $z_0 = a-1$、$\rho = g(b,c)$ 处取到，且该值确实不可表示。无可再大者，故它就是 Frobenius 数。∎

验证一下三个锚点：$g(6,10,15) = 2\cdot2\cdot3\cdot5 - (6+10+15) = 60-31 = 29$；$g(14,22,77) = 2\cdot2\cdot7\cdot11 - (14+22+77) = 308 - 113 = 195$；两生成元的退化版 $g(a,b) = ab-a-b$ 给出 $g(5,7) = 23$。

### 求和

记 $\pi(5000) = 669$ 个素数 $p_1 < \dots < p_n$（$n = 669$），

$$
e_2 = \sum_{i<j} p_ip_j,\qquad e_3 = \sum_{i<j<k} p_ip_jp_k,
$$

则

$$
S = \sum_{i<j<k}\bigl(2p_ip_jp_k - p_ip_j - p_ip_k - p_jp_k\bigr) = 2e_3 - (n-2)\,e_2,
$$

第二项用的是「每个无序对 $\{p_i,p_j\}$ 恰好出现在 $n-2$ 个三元组中，而每个三元组的三个乘积项各对应一个无序对」。数值上 $e_2 = 1195837592176$、$e_3 = 614506685473944922$、$S = 1228215747273908452 < 2^{63}$；中间量 $s_1^3 = 3710456369929939456$ 也未溢出（$s_1 = 1548136$）。

## 独立复核

1. **公式 vs 精确 DP**：`solution.kt` 用「前推可达性 DP」直接求 Frobenius 数（外加上界充分性检查：区间尾部必须有 $\min$ 生成元个连续可达位置），对
   - 所有素数三元组 $p<q<r\le31$（165 个），
   - 所有两两互素三元组 $2 \le a<b<c \le 25$（619 个，**不限于素数**），
   逐个与公式对拍，全部一致；三个题面锚点也由 DP 直接复现。
2. **两条求和路径**：方法 A 用 Newton 恒等式 $e_2 = (s_1^2-s_2)/2$、$e_3 = (s_1^3-3s_1s_2+2s_3)/6$（$s_k = \sum p_i^k$）；方法 B 用滚动前缀和逐项累加 $e_2,e_3$（不含任何对称多项式恒等式）。两者在完整规模上给出同一个 $S$。
3. **朴素三重循环**：直接枚举全部 $C(669,3) = 49679494$ 个三元组累加公式值，得到同一个 $S$。

## 直接暴力对照

`brute-force.kt` 三条路（反向 DP：`can[i] = can[i-a] ∨ can[i-b] ∨ can[i-c]`，与 solution.kt 的前推写法相反）：

1. 题面锚点：反向 DP 直算出 $23, 29, 195$。
2. **小规模整段对拍**：对所有素数三元组 $p<q<r\le47$（455 个），逐个跑 DP 求**真实** Frobenius 数并求和，得 $7955105$，与公式求和一致；用时 $111.6$ ms。
3. **完整规模朴素循环**（meta 的 `bruteForceBaselineMs` 口径）：$49679494$ 个三元组逐个累加公式值，用时 $30.8$ ms。

不可行的路线：对 $r<5000$ 的全部三元组逐个跑 Frobenius DP——DP 上界正比于 $pqr$，而 $\sum pqr$ 从 $r\le47$ 的 $4.29\times10^6$ 涨到全体的 $6.15\times10^{17}$（约 $1.4\times10^{11}$ 倍），按实测单三元组耗时外推需要约 $5\times10^2$ 年；按操作数 $\sim10^{18}$ 次、每秒 $10^9$ 量级估计也要十年以上。所以必须先证出闭式公式，暴力只负责把它钉死到小规模。

## 旁证

1. **题面锚点**：$f(5,7)=23$、$f(6,10,15)=29$、$f(14,22,77)=195$ 三条全部由独立实现的 DP 复现，且与公式吻合。
2. **公式的普遍性**：$165 + 619$ 个小规模三元组（含非素数的两两互素三元组）上公式与精确 DP 全部一致——说明公式只依赖「两两互素」而不是「素数」，与证明中的推导一致。
3. **双路径 + 三循环**：Newton 恒等式、滚动前缀和、朴素三重循环三条独立求和路径给出同一个 $S$。
4. **公开答案表**：公开的 PE 答案汇总页列出 $1228215747273908452$（仅作旁证；`meta.answer` 取自本机实跑输出）。

## 答案

实跑输出（方法 A、方法 B、朴素三重循环一致）：

$$
\boxed{\sum_{p<q<r<5000} f(pq,pr,qr) = 1228215747273908452}
$$

## 复杂度对比

| 方法 | 复杂度 | 本机实测（3 轮最优，JIT 预热后） |
|:--|:--|:--|
| 逐个三元组跑 Frobenius DP（$r<5000$，外推） | $\sum pqr \approx 6.15\times10^{17}$ 次 DP 推进 | 约 $5\times10^2$ 年 |
| 小规模 DP 对拍 $r \le 47$（455 个三元组） | $\sum O(6pqr)$ | $111.6$ ms |
| 朴素三重循环（meta 的 `bruteForceBaselineMs`，$49679494$ 个三元组） | $O(n^3)$ | $30.8$ ms |
| 方法 A：筛 + Newton 恒等式（meta 的 `optimizedBaselineMs`） | $O(n\log\log n + n)$ | $0.465$ ms |
| 方法 B：筛 + 滚动前缀和 | $O(n\log\log n + n)$ | $0.409$ ms |
| 对照：筛 $5000$ 内素数 | $O(5000\log\log 5000)$ | $0.117$ ms |

方法 B 略快是因为它只走一遍数组（方法 A 要三次 `sumOf`）。$n = 669$ 时两条路径的差别都在缓存友好度上，绝对耗时远小于 JVM 启动开销。

## 关键教训

- **先证公式再求和**：三生成元的 Frobenius 数一般没有简单闭式（$n$ 固定时有多项式算法，但公式复杂），可本题的「对称半素数」结构 $ab, ac, bc$ 恰好有一条干净的证明路径——把 $N$ 分解成 $bc\cdot z_0 + aM$，问题就退化成两生成元的间隙计数（$w(\rho) = \rho + bc$ 这一步只用到「$\rho + bc$ 超过两数 Frobenius 数必可表示」）。**换个坐标系（按 $a$ 的余数分组）就能看到简单结构**，这是本题最值得记住的一步。
- **公式的适用范围要靠 DP 打出来**：证明里只用到「两两互素」，所以对拍就故意包含非素数三元组（$619$ 个）——如果公式只在素数上有巧合式成立，这组对拍会立刻暴露。
- **DP 求 Frobenius 数必须自带「上界充分」判据**：只要区间末尾出现 $\min(a_k)$ 个连续可达位置，之后就不可能再有不可表示的数（平移即可），这样就不必先知道 Frobenius 数再定 DP 上界，避免循环论证。
- **求和结构值值得化简**：$\sum(2pqr-pq-pr-qr)$ 直接三重循环 $5\times10^7$ 次也能跑（$32.8$ ms），但用 $2e_3-(n-2)e_2$ 只需 $O(n)$，且给出 $O(n)$ 与 $O(n^3)$ 两条可互证的路径——「每个无序对出现在 $n-2$ 个三元组里」这句话是把第二项从 $O(n^3)$ 拉回 $O(n)$ 的关键。
- **溢出边界要算清**：$s_1^3 \approx 3.71\times10^{18} < 2^{63}-1 \approx 9.22\times10^{18}$，Newton 恒等式的中间量刚好放得下；如果 $r$ 的界再大一点（比如 $10^4$），这条路径就必须换顺序先除后乘或上 BigInteger。
