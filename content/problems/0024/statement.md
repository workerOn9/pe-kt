# 字典序排列

> 中文意译。英文原文见 [Project Euler Problem 24](https://projecteuler.net/problem=24)；抓取底稿见 `statement.en.md`。

排列指一组对象的有序安排。例如 3124 就是数字 1、2、3、4 的一种排列。如果把所有排列按数值或字母顺序列出，称为字典序。数字 0、1、2 的字典序排列为：

<p align="center">012 &nbsp; 021 &nbsp; 102 &nbsp; 120 &nbsp; 201 &nbsp; 210</p>
