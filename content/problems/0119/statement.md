# 119 · 数字幂和

> 中文意译。英文原文见 [Project Euler Problem 119](https://projecteuler.net/problem=119)；抓取底稿见 `statement.en.md`。

$512$ 这个数很有意思：它恰好等于自身各位数字之和的某个幂——$5 + 1 + 2 = 8$，而 $8^3 = 512$。另一个具有同样性质的例子是 $614656 = 28^4$。

把这类数按升序排成数列，记第 $n$ 项为 $a_n$；同时约定：一个数至少要含有两位数字，才谈得上「各位数字之和」（一位数不计入数列）。

已知 $a_2 = 512$，$a_{10} = 614656$。

求 $a_{30}$。
