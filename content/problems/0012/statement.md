# 高度可整除的三角数

> 中文意译。英文原文见 [Project Euler Problem 12](https://projecteuler.net/problem=12)；抓取底稿见 `statement.en.md`。

三角数序列由自然数不断累加生成，因此第 7 个三角数是 1 + 2 + 3 + 4 + 5 + 6 + 7 = 28。前十项为：

$$1,\ 3,\ 6,\ 10,\ 15,\ 21,\ 28,\ 36,\ 45,\ 55,\ \dots$$

列出前七个三角数的因子：

| 三角数 | 因子 |
|--------|------|
| **1** | 1 |
| **3** | 1, 3 |
| **6** | 1, 2, 3, 6 |
| **10** | 1, 2, 5, 10 |
| **15** | 1, 3, 5, 15 |
| **21** | 1, 3, 7, 21 |
| **28** | 1, 2, 4, 7, 14, 28 |

可以看出，28 是第一个因子数超过 5 的三角数。

求第一个因子数超过 500 的三角数的值。
