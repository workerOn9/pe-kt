# 991 · 水果沙拉

> 中文意译。英文原文见 [Project Euler Problem 991](https://projecteuler.net/problem=991)；抓取底稿见 `statement.en.md`。

对于所有满足方程

$$
\frac{x}{y + z} + \frac{y}{z + x} + \frac{z}{x + z} = 4
$$

且满足 $x + y + z \le 10^7$ 的正整数三元组 $(x, y, z)$，求 $x + y + z$ 的总和。

注：在原题面中，$x, y, z$ 分别以苹果（🍎）、香蕉（🍌）和菠萝（🍍）三种水果表情符号表示，第三项分母原题为 $x + z$。
