# 456 · 包含原点的三角形 II

> 中文意译。英文原文见 [Project Euler Problem 456](https://projecteuler.net/problem=456)；抓取底稿见 `statement.en.md`。

定义：
$x_n = (1248^n \bmod 32323) - 16161$
$y_n = (8421^n \bmod 30103) - 15051$
$P_n = \{(x_1, y_1), (x_2, y_2), \dots, (x_n, y_n)\}$

例如，
$$
P_8 = \{(-14913, -6630), (-10161, 5625), (5226, 11896), (8340, -10778), (15852, -5203), (-15165, 11295), (-1427, -14495), (12407, 1060)\}.
$$

记 $C(n)$ 为以 $P_n$ 中的点为顶点、且内部包含原点的三角形个数。

样例：
$C(8) = 20$
$C(600) = 8950634$
$C(40\,000) = 2666610948988$

求 $C(2\,000\,000)$。
