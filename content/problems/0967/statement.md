# 967 · B-可三整除数

> 中文意译。英文原文见 [Project Euler Problem 967](https://projecteuler.net/problem=967)；抓取底稿见 `statement.en.md`。

若正整数 $n$ 的所有不超过 $B$ 的互异质因子之和能被 $3$ 整除，则称 $n$ 为 **$B$-可三整除数**（$B$-trivisible）。

例如，$175 = 5^2 \cdot 7$ 是 $10$-可三整除数，因为 $5 + 7 = 12$ 能被 $3$ 整除。类似地，$175$ 是 $4$-可三整除数，因为整除 $175$ 的所有质数都大于 $4$，空和 $0$ 能被 $3$ 整除。
另一方面，$175$ 不是 $6$-可三整除数，因为相关质因子之和为 $5$，不能被 $3$ 整除。

设 $F(N, B)$ 为不超过 $N$ 的 $B$-可三整除数的个数。

例如 $F(10, 4) = 5$，对应的 $4$-可三整除数为 $1, 3, 5, 7, 9$。
已知 $F(10, 10) = 3$ 以及 $F(100, 10) = 41$。

求 $F(10^{18}, 120)$。
