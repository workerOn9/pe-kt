# 603 · 素数拼接的子串和

> 中文意译。英文原文见 [Project Euler Problem 603](https://projecteuler.net/problem=603)；抓取底稿见 `statement.en.md`。

设 $S(n)$ 为整数 $n$ 的所有连续整数子串之和（子串允许重复）。

例如 $S(2024) = 2 + 0 + 2 + 4 + 20 + 02 + 24 + 202 + 024 + 2024 = 2304$。

设 $P(n)$ 为把前 $n$ 个素数依次拼接而成的整数。例如 $P(7) = 2357111317$。

设 $C(n, k)$ 为把 $k$ 份 $P(n)$ 依次拼接而成的整数。例如 $C(7, 3) = 235711131723571113172357111317$。

求 $S(C(10^6, 10^{12})) \bmod (10^9 + 7)$。
