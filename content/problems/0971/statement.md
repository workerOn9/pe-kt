# 971 · 模多项式复合

> 中文意译。英文原文见 [Project Euler Problem 971](https://projecteuler.net/problem=971)；抓取底稿见 `statement.en.md`。

设 $p$ 为形如 $5k-4$ 的质数，定义函数 $f_p(x) = \left(x^k+x\right) \bmod p$。

设 $C(p)$ 为使得对于某个正整数 $m$ 满足 $f_p^{(m)}(x) = x$ 的 $0 \le x < p$ 的值的个数；也就是说，从 $x$ 出发，通过对自身反复迭代应用 $f_p$ 可以回到 $x$。

例如，由于 $x = 0, 1, 2, 3, 8, 9, 10$ 满足条件，故 $C(11) = 7$。

设 $S(N)$ 为所有不超过 $N$ 且形如 $5k-4$ 的质数 $p$ 的 $C(p)$ 之和。已知 $S(100) = 127$。

求 $S(10^8)$。
