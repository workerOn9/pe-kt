# 386 · 反链的最大长度

> 中文意译。英文原文见 [Project Euler Problem 386](https://projecteuler.net/problem=386)；抓取底稿见 `statement.en.md`。

设 $n$ 为整数，$S(n)$ 为 $n$ 的所有因数构成的集合。

若 $S(n)$ 的一个子集 $A$ 只含一个元素，或者 $A$ 中没有任何元素整除 $A$ 中的其他元素，则称 $A$ 是 $S(n)$ 的一个**反链**（antichain）。

例如 $S(30) = \{1, 2, 3, 5, 6, 10, 15, 30\}$：

- $\{2, 5, 6\}$ 不是 $S(30)$ 的反链；
- $\{2, 3, 5\}$ 是 $S(30)$ 的反链。

记 $N(n)$ 为 $S(n)$ 的反链的最大长度。

求 $\displaystyle\sum_{n=1}^{10^{8}} N(n)$。
