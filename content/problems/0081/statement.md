# 路径和：两种走法

> 中文意译。英文原文见 [Project Euler Problem 81](https://projecteuler.net/problem=81)；抓取底稿见 `statement.en.md`。

在下面这个 $5\times5$ 的矩阵中，从左上角走到右下角、只允许向**右**和向**下**移动时，最小路径和为 $2427$（下表中加粗的格子构成这条路径）：

| | | | | |
|---|---|---|---|---|
| **131** | 673 | 234 | 103 | 18 |
| **201** | **96** | **342** | 965 | 150 |
| 630 | 803 | **746** | **422** | 111 |
| 537 | 699 | 497 | **121** | 956 |
| 805 | 732 | 524 | **37** | **331** |

请对 `matrix.txt`（一个约 31K 的文本文件，内含一个 $80\times80$ 的矩阵）求出从左上角到右下角、只向右和向下移动的最小路径和。
