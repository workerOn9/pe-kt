# 包含 0、1、A 的十六进制数

## 容斥原理

设 $U$ 为所有 $\leq 16$ 位的十六进制正整数集合（首位非零），则：

$$|U| = \sum_{k=1}^{16} 15 \cdot 16^{k-1}$$

目标：$|U| - |\text{missing } 0| - |\text{missing } 1| - |\text{missing } A|$
$+ |\text{missing } 0,1| + |\text{missing } 0,A| + |\text{missing } 1,A|$
$- |\text{missing } 0,1,A|$

## 子问题

给定禁止数字集合 $F$，长度为 $k$ 的 hex 数（首位非零）且不含 $F$ 中任何数字的个数：

$$\text{count}(F, k) = n_1 \cdot n_2^{k-1}$$

其中 $n_1$ 是首位允许的非零数字个数，$n_2$ 是总允许数字个数。

## 答案

$$4\,420\,408\,745\,587\,516\,162 = 0x3D58725572C62302$$
