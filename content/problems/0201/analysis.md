# PE 201 解析——Subsets with a Unique Sum

## 思路推导

题意：对 $V=\{1,\dots,100\}$，问所有 $50$ 元子集的和中，哪些**恰好只出现一次**，把这些和全部加起来。

### 第一步：问题变换为子集和计数

直接枚举 $\binom{100}{50}\approx 1\times 10^{29}$ 个子集显然不可行。问题的核心状态是：

$$
d_k(s) = \bigl|\{T\subseteq V : |T|=k,\ \sigma(T)=s\bigr\}|
$$

即「从 $V$ 中取 $k$ 个元素、和恰好为 $s$」的子集个数。答案就是

$$
\sigma(U_{50}(V)) = \sum_{s:\,d_{50}(s)=1} s
$$

### 第二步：0/1 背包式 DP 转移

逐个把元素 $v=1,\dots,100$ 加入，按 $k$ **倒序**推进（保证每个元素至多选一次）：

$$
d_k(s) \mathrel{+}= d_{k-1}(s-v)
$$

与经典 0/1 背包完全同构，只是把「最大值」换成「可数方案数」。

### 第三步：规模测算

- $s$ 的取值范围是 $[0,\ \sigma(V)] = [0, 5050]$；
- 共 $100\times 50\times 5050 \approx 2.5\times 10^{7}$ 次状态转移。

关键问题：计数值本身就是 $\binom{100}{50}$ 级别的大数（$\approx 10^{29}$），**远超 64 位整数**。这里有一个关键观察可以绕开大数运算：

### 第四步：饱和计数（64 位安全化）

答案只关心 $d_{50}(s)$ 是否**恰为 1**。而一旦 $d_{50}(s)\ge 2$，就永远不可能再回到 1——计数单调不减。因此把转移改成带饱和的 64 位整数即可：

- 饱和阈值取 $T\ge 2$：$d(s) \leftarrow \min(d(s)+c,\ T)$；
- 推理：若 $d(s)$ 已饱和到 $T$，则 $d(s)+c$ 仍 $\ge T$，不丢「$=1$ 与否」这个全部所需的信息。

这一步避免了大数膨胀，让 $2.5\times 10^{7}$ 次转移全在 `Long` 上进行，总耗时降到毫秒级。

（本仓库沉淀的 `solution.kt` 为忠实展示算法原貌仍写大数版，独立验证脚本先跑通大数版，
再验证饱和版与它逐项一致，最终答案两版相同。）

## 旁证

1. 题面样例：$V=\{1..6\}$、$k=3$ 时程序输出 $42$，与题面给出的 $\sigma(U_3(V))=42$ 一致。
2. 交叉验证：对 $V=\{1..12\}$、$k=5$，「组合枚举逐个计数」与「DP 计数」两条路径输出相同。
3. 全量答案由 Kotlin 求解器独立复跑，输出 10100。

以下独立 Python 脚本（大数精确计数）得到与 Kotlin 版相同结果：10100。

```python
from collections import defaultdict
N, K = 100, 50
dp = [defaultdict(int) for _ in range(K+1)]
dp[0][0] = 1
for v in range(1, N+1):
    for k in range(min(K, v), 0, -1):
        for s, c in list(dp[k-1].items()):
            dp[k][s+v] += c
uniq = [s for s, c in dp[K].items() if c == 1]
print(sum(uniq))    # -> 10100
```

值得玩味的结构：unique 的和恰好只有 **4 个**——

$$
\{1275,\ 1276,\ 3774,\ 3775\}
$$

其中 $1275=\sigma(\{1,\dots,50\})$、$3774=\sigma(\{51,\dots,100\})$，而 $1276$ 与 $3775$
是两个「位移一格」的次极值构造 $\{1,\dots,49,51\}$ 与 $\{52,53,\dots,100\}$。直觉：把一个
数从最小可行值替换成相邻的值，代价是整个和区间出现「链式补位」效应，破坏了唯一性；
只有贴着极值的两个方向各能维持一条「唯一走廊」。这解释了为何唯一和几乎总聚在
$[\sigma_{\min},\sigma_{\max}]$ 区间的两端。

## 答案

**10100**

## 复杂度对比

| 方法 | 时间 | 空间 | 实测 |
|------|------|------|------|
| 组合枚举 $\binom{100}{50}$ 个子集 | $\Theta\!\bigl(\binom{100}{50}\bigr)$ | — | 均不可行 |
| 大数 DP 计数 | $O(n\cdot k\cdot S)$，$\approx 2.5\times 10^{7}$ 次大数加法 | $O(k\cdot S)$ | ~2100 ms(Python) |
| 饱和 Long DP | 同上但每步为一条 Long 加法 | 同上 | ~140 ms(Kotlin) |

## 关键教训

1. **「恰好一次」单调不可逆**：频次大于等于 2 就再也不可能降回 1，饱和截断完全无损；
   这是本题把大数运算化归为 64 位运算的关键。
2. **规模 ahead of time**：$\binom{100}{50}$ 直接告诉这条路走不通，动手前先把规模算出来。
3. **样例检查**：题面的 $V=\{1..6\}$、$k=3$ 例子本身完全可作为第一个单元测试用例，
   保留一条「样例小规模 sanity check」可以快速兜住 off-by-one。
