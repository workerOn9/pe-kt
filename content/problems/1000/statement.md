# 1000 · 第 1000 题

> 中文意译。英文原文见 [Project Euler Problem 1000](https://projecteuler.net/problem=1000)；抓取底稿见 `statement.en.md`。

本题包含三个子问题和一个元问题。请输入元问题的答案作为最终答案。

### 子问题：最大按位与

将数字 $1$ 到 $n$ 分成两个集合 $A$ 和 $B$。设 $I(n)$ 为

$$
\sum_{a\in A}\sum_{b\in B}a\wedge b
$$

的最大可能值，其中 $\wedge$ 表示按位与运算符（bitwise AND）。

可以验证 $I(10)=50$（例如当 $A=\{1,4,7,10\}$ 且 $B=\{2,3,5,6,8,9\}$ 时即可达到，但还有其他取法）。

求 $I(1000)$。

### 子问题：最大异或和

对于两个整数 $x, y$，用 $[x, y]$ 表示 $x^2$ 与 $y^2$ 的按位异或（bitwise XOR）。

一个有限整数序列 $a_0, a_1, \dots, a_r$ 满足以下性质：

- 对所有 $0 \le i \le r$，均有 $1 \le a_i \le N$；
- 对所有 $0 < i < r$，均有 $[a_{i - 1}, a_i] < [a_i, a_{i + 1}]$。

设 $X(N)$ 为和式 $\sum_{i = 1}^r [a_{i - 1}, a_i]$ 的最大可能值。

例如，对于序列 $2,1,3,2,4,3$，可以达到 $X(4) = 71$。已知 $X(10) = 702$。

求 $X(1000)$。

### 子问题：不可达尼姆堆

两名玩家正在玩三堆尼姆博弈（Nim）。游戏状态是一个有序三元组 $(a, b, c)$，分别表示三堆各自的石子数。

如果存在必胜走法，玩家一定会选择必胜走法；否则可以进行任意合法移动，直到没有合法移动时游戏结束。

如果一个游戏状态在游戏进行过程中永远不会出现（除非它就是初始状态），则称其为**不可达状态**。例如，游戏状态 $(1, 1, 1)$ 是不可达的。

设 $C(N)$ 为满足 $0 \le a, b, c < N$ 的不可达状态的数量。已知 $C(10) = 123$。

求 $C(1000)$。

### 元问题

序列 $M$ 定义如下：

- $M(0) = I(1000)$；
- $M(1) = X(1000)$；
- $M(2) = C(1000)$；
- 当 $k \ge 3$ 时，$M(k) = M(k - 1)M(k - 2)M(k - 3)$。

已知 $M(4) \equiv 457587170 \pmod{10^9 + 7}$。

求 $M(1000) \bmod (10^9 + 7)$。

提示：可以假定给出的 $M(4)$ 值是正确的。
