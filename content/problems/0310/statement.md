# 310 · 平方尼姆

> 中文意译。英文原文见 [Project Euler Problem 310](https://projecteuler.net/problem=310)；抓取底稿见 `statement.en.md`。

Alice 和 Bob 在玩「平方尼姆」（Nim Square）：规则与普通的三堆尼姆相同，但每次只能从某一堆里取走**平方数**个石子。

三堆石子的数量用有序三元组 $(a,b,c)$ 表示。若 $0 \le a \le b \le c \le 29$，则对轮到行动的一方来说必败的局面有 $1160$ 个。

若 $0 \le a \le b \le c \le 100\,000$，必败局面有多少个？
