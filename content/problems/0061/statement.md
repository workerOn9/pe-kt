# 循环多边形数

> 中文意译。英文原文见 [Project Euler Problem 61](https://projecteuler.net/problem=61)；抓取底稿见 `statement.en.md`。

三角形数、正方形数、五边形数、六边形数、七边形数、八边形数统称多边形数，分别由下列公式生成：

| 名称 | 公式 | 前几项 |
|------|------|--------|
| 三角形数 | $P_{3,n}=\dfrac{n(n+1)}{2}$ | $1, 3, 6, 10, 15, \dots$ |
| 正方形数 | $P_{4,n}=n^2$ | $1, 4, 9, 16, 25, \dots$ |
| 五边形数 | $P_{5,n}=\dfrac{n(3n-1)}{2}$ | $1, 5, 12, 22, 35, \dots$ |
| 六边形数 | $P_{6,n}=n(2n-1)$ | $1, 6, 15, 28, 45, \dots$ |
| 七边形数 | $P_{7,n}=\dfrac{n(5n-3)}{2}$ | $1, 7, 18, 34, 55, \dots$ |
| 八边形数 | $P_{8,n}=n(3n-2)$ | $1, 8, 21, 40, 65, \dots$ |

有序三元组 $8128,\ 2882,\ 8281$ 有三个有趣的性质：

1. **循环性**：每个数的末两位恰好是下一个数的前两位（包括最后一个数与第一个数之间）；
2. **阶数互异**：三角形数 $P_{3,127}=8128$、正方形数 $P_{4,91}=8281$、五边形数 $P_{5,44}=2882$ 各由组中不同的数表示；
3. 具有该性质的四位数三元组**只有这一组**。

求唯一一组满足下述条件的六个循环四位数之和：这六个数构成循环序列，且三角形、正方形、五边形、六边形、七边形、八边形这六种多边形数各由组内不同的一个数表示。
