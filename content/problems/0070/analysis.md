# 070 · 欧拉函数与数字排列 — 解析

## 思路推导

分母 $n$ 与 $\phi(n)$ 的比值同样由素数分解的乘积公式给出：

$$\frac{n}{\phi(n)} = \prod_{p \mid n}\frac{p}{p-1} = \prod_{p\mid n}\left(1 + \frac{1}{p-1}\right).$$

要让这个比值尽量接近 1，就要让 $n$ 的**不同素因子尽量少**、每个素因子尽量大。用这一条把候选集分层压缩：

**第一步：排除 $\ge 3$ 个不同素因子的 $n$。** 设 $p < q < r$ 是 $n$ 的三个最小素因子，则

$$p^3 < pqr \le n < 10^7 \quad\Longrightarrow\quad p < 215.44 \quad\Longrightarrow\quad p \le 211 .$$

于是

$$\frac{n}{\phi(n)} \ge \frac{p}{p-1} \ge \frac{211}{210} \approx 1.004762 .$$

而下面在「两个素因子」的候选里能找到比 $1.001$ 还小的解（$\frac{8319823}{8313928} \approx 1.0007096$），所以含三个以上不同素因子的 $n$ 全部出局。

**第二步：主搜索只需枚举半素数 $n = pq$（$p < q$ 为素数）。** 此时

$$\phi(n) = (p-1)(q-1),$$

只需 $n < 10^7$，对所有满足 $p < \sqrt{10^7} \approx 3162.3$ 的素数 $p$，向后取素数 $q$，一旦 $pq \ge 10^7$ 就截断。筛素数表只需到 $10^7/2 = 5\times10^6$，因为 $p \ge 2$ 时必有 $q < 10^7/2$。配对总数约为 $\sum_{p<3162}\pi(10^7/p) \approx 2\times10^6$ 组，完全可枚举。

**第三步：单素因子情形单独扫描。** $n = p^a$ 时 $n/\phi(n) = p/(p-1)$，$a$ 越大比值不变却消耗额度，所以真正可能的只有 $a \ge 2$ 的素数幂，而 $p \ge 3163$ 时 $p^2 \ge 10^7$，只有 $p \le 3162$ 的几百个素数需要看。（$a = 1$ 一定不是解：$n$ 与 $n-1$ 的数位和不可能相等。）

**第四步：排列判定与比较。** 用长度 10 的计数数组做数位多重集比较（$n$ 的各位加一、$\phi(n)$ 的各位减一，最后全零即互为排列），比字符串排序更快且不分配内存。比值比较用 `Long` 交叉相乘 $n_1\phi_2 < n_2\phi_1$，避免浮点误差。

结果 $n = 8319823 = 2339 \times 3557$，$\phi(n) = 2338 \times 3556 = 8313928$，二者互为数字排列，比值约 $1.0007096$，为最小值。答案 **8319823**。

## 复杂度对比

| 方案 | 时间 | 实测（JIT 预热后） |
|------|------|------|
| 优化解：筛 $10^7/2$ 以内素数，枚举半素数对 + 素数幂，数位计数判排列 | 筛 $O(N\log\log N)$，配对约 $2\times10^6$ 组 | ~129.8 ms |
| 暴力解：筛出 $1..10^7$ 全部 $\phi(n)$，对每个 $n$ 判排列并比较比值 | $O(N\log\log N)$ + $O(N)$ 逐项判定，$N = 10^7$ | ~938.8 ms |

暴力解把 $10^7$ 个 $\phi$ 值全部算出来再做 $10^7$ 次数位判定；优化解先用「不同素因子为 2」这一结构性结论把候选从 $10^7$ 砍到 $2\times10^6$ 组，再用计数法做 $O(1)$ 判定。倍数不大（约 7 倍），因为两者都要筛素数/筛 $\phi$，且暴力解的筛法本身相当高效——但优化解的候选集小了将近一个数量级，且不含任何对全部 $n$ 的逐项判定。

## 实现要点

- 「$\ge 3$ 个不同素因子不可能最优」是严格不等式，不是猜测；单素因子情形另行扫描，构成完整覆盖
- 素数表只需到 $5\times10^6$（$p \ge 2 \Rightarrow q < 10^7/2$），省一半内存
- 内层循环用 `if (n >= limit) break` 截断，倚赖素数表升序排列
- 判排列用 0–9 计数数组，避免为每个候选分配字符串与排序
- 本机计时受负载影响较大，同一实现在多次基准中落在 $130 \sim 220$ ms 区间，表中取最近一次
