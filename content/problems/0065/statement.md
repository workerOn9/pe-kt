# $e$ 的渐近分数

> 中文意译。英文原文见 [Project Euler Problem 65](https://projecteuler.net/problem=65)；抓取底稿见 `statement.en.md`。

$\sqrt{2}$ 可以写成无限连分数：

$$\sqrt{2} = 1 + \dfrac{1}{2 + \dfrac{1}{2 + \dfrac{1}{2 + \dots}}}$$

记作 $\sqrt{2} = [1;(2)]$，其中 $(2)$ 表示数字 $2$ 无限重复。类似地有 $\sqrt{23} = [4;(1,3,1,8)]$。

平方根连分数的部分值给出的正是一类最佳有理逼近。考虑 $\sqrt{2}$ 的渐近分数：

$$
1 + \dfrac{1}{2} = \dfrac{3}{2},\qquad
1 + \dfrac{1}{2 + \dfrac{1}{2}} = \dfrac{7}{5},\qquad
1 + \dfrac{1}{2 + \dfrac{1}{2 + \dfrac{1}{2}}} = \dfrac{17}{12},\qquad
1 + \dfrac{1}{2 + \dfrac{1}{2 + \dfrac{1}{2 + \dfrac{1}{2}}}} = \dfrac{41}{29}
$$

因此 $\sqrt{2}$ 的前十个渐近分数是

$$1,\ \dfrac{3}{2},\ \dfrac{7}{5},\ \dfrac{17}{12},\ \dfrac{41}{29},\ \dfrac{99}{70},\ \dfrac{239}{169},\ \dfrac{577}{408},\ \dfrac{1393}{985},\ \dfrac{3363}{2378},\ \dots$$

最令人惊讶的是重要的数学常数

$$e = [2;\ 1, 2, 1,\ 1, 4, 1,\ 1, 6, 1,\ \dots,\ 1, 2k, 1, \dots]$$

$e$ 的渐近分数序列的前十项为

$$2,\ 3,\ \dfrac{8}{3},\ \dfrac{11}{4},\ \dfrac{19}{7},\ \dfrac{87}{32},\ \dfrac{106}{39},\ \dfrac{193}{71},\ \dfrac{1264}{465},\ \dfrac{1457}{536},\ \dots$$

第 10 个渐近分数的分子的数位之和为 $1+4+5+7=17$。

求 $e$ 的连分数的第 100 个渐近分数的分子的数位之和。
