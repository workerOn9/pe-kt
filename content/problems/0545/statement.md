# 545 · 法尔哈伯公式

> 中文意译。英文原文见 [Project Euler Problem 545](https://projecteuler.net/problem=545)；抓取底稿见 `statement.en.md`。

前 $n$ 个正整数的 $k$ 次幂之和可以表示成一个 $k+1$ 次的、有理系数的多项式，即法尔哈伯公式：

$$
1^k + 2^k + \ldots + n^k = \sum_{i=1}^n i^k = \sum_{i=1}^{k+1} a_{i} n^i = a_{1} n + a_{2} n^2 + \ldots + a_{k} n^k + a_{k+1} n^{k + 1},
$$

其中 $a_i$ 是有理系数，可以写成既约分数 $p_i/q_i$（若 $a_i = 0$，则约定 $q_i = 1$）。

例如 $1^4 + 2^4 + \ldots + n^4 = -\frac 1 {30} n + \frac 1 3 n^3 + \frac 1 2 n^4 + \frac 1 5 n^5$。

定义 $D(k)$ 为 $k$ 次幂之和中 $q_1$ 的值（也就是既约分数 $a_1$ 的分母）。
定义 $F(m)$ 为所有满足 $D(k) = 20010$ 的 $k \ge 1$ 中的第 $m$ 个。
已知 $D(4) = 30$（因为 $a_1 = -1/30$），$D(308) = 20010$，$F(1) = 308$，$F(10) = 96404$。

求 $F(10^5)$。
