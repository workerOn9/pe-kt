# 228 — Minkowski Sums（闵可夫斯基和）

## 思路：多边形和的边数 = 法向方向的并集大小

**定理（凸多边形 Minkowski 和）**：设 $P_1, \dots, P_r$ 是凸多边形，则 $P_1 + \cdots + P_r$ 的边向量集合恰是各 $P_i$ 边向量的**并集**（按方向排序后首尾相接）。换句话说，$P_1 + \cdots + P_r$ 的边数等于所有 $P_i$ 的**边法向方向在模 $180^\circ$ 意义下的去重个数**。

推论证明思路：把每个 $P_i$ 的边向量写成 $l_i \cdot u_i$（$u_i$ 为单位方向，$l_i > 0$）。两凸多边形相加时，沿任一方向 $u$，支撑线位置相加；而 $u$ 是和的边法向当且仅当它是某个 $P_i$ 的边法向（若不是，$u$ 方向上没有任何 $P_i$ 的边，该方向上支撑函数不可微，和也无边）。法向相同的边会合并成一条更长的边，方向数不变。

正 $n$ 边形 $S_n$ 的顶点角为 $(2k-1)\pi/n$，其**边法向**方向（模 $180^\circ$）均匀分布：把 $2k/n$（$k = 0, \dots, n-1$）约分成既约分数 $p/q$，则对应的不同方向数是 $\varphi(q)$。

因此对集合 $n \in [1864, 1909]$：

$$
\text{答案} = \sum_{q \in D} \varphi(q),\qquad D = \left\{ q : \exists n \in [1864,1909],\ q \mid n \text{ 或 } n/q \mid n \right\}
$$

即 $D$ 是这些 $n$ 的**全体因子**（含 $1$ 与自身）的集合 —— 因为 $2k/n$ 约分后的分母 $q$ 必整除 $n$；反之每个 $q \mid n$ 都能取 $k = q/2 \cdot$（可逆元）构造出分母恰为 $q$ 的方向。

## 计算

区间 46 个数，枚举 $\sqrt{n}$ 内的因子收集去重，得 $|D| = 239$；对每个 $q$ 用欧拉函数公式 $\varphi(q) = q \prod_{p \mid q}(1 - 1/p)$ 求值累加，得

$$
\sum_{q \in D} \varphi(q) = 86226.
$$

注意这个数**小于** $\sum_{n=1864}^{1909} n = 86779$：如果每个 $n$ 的方向完全不相交，答案会是 86779；实际有 553 个方向因分母相同而合并，这正是「取并集而非求和」的效果。

## 旁证：小规模直接算凸包

用定义暴力验证：$S_3 + S_4$ 得 **6** 条边（与题面图片描述一致），$S_4 + S_4$ 得 **4** 条边，$S_3 + S_3$ 得 3 条边，$S_3$ 自身 3 条。这些都用「枚举所有顶点对相加 → 求凸包边数」直接算出，与方向并集公式吻合。另外用精确有理数（`Fraction`）统计区间内既约方向 $2k/n$ 的并集大小，同样得 86226。

## 答案

$$
\boxed{86226}
$$

## 复杂度对比

| 方法 | 复杂度 | 实测（JIT 预热后） |
|------|--------|-------------------|
| 暴力：逐方向枚举塞入 HashSet（86779 次插入） | $O\!\left(\sum n\right)$ | 约 16 ms |
| 暴力（小规模凸包验证） | $O(n_1 n_2 \log)$ | 仅用于 n ≤ 10 |
| 因子去重 + Σφ(q) | $O(\sum \sqrt{n} + |D|\sqrt{\max D})$ | < 1 ms |

## 关键教训

- **Minkowski 和不需要坐标运算**：一旦接受「边数 = 法向并集大小」，$O(n)$ 的几何计算塌缩成 $O(\sqrt n)$ 的因子枚举。这种「先找不变量、再做算术」的思路在几何题里回报极高。
- **并集 vs 求和**：$\sum n = 86779$ 与答案 86226 接近纯属巧合，真正要警惕的是把「重叠方向」当独立方向数。区间内 $\gcd$ 结构使得重叠不可忽略，必须显式去重。
- **既约分数表示方向**：用 `(num/gcd, den/gcd)` 作 key 是去重的正确粒度；直接用浮点角度比较会因 $\pi$ 的近似把本应相同的方向判为不等，是本题最容易翻车的实现细节。
- **欧拉函数的角色**：$\varphi(q)$ 恰好是「分母为 $q$ 的既约分数在 $[0,1)$ 内的个数」，把计数问题直接转成数论函数求和，不必逐个枚举 $k$。
