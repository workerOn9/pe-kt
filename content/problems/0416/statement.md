# 416 · 青蛙的旅程

> 中文意译。英文原文见 [Project Euler Problem 416](https://projecteuler.net/problem=416)；抓取底稿见 `statement.en.md`。

一排 $n$ 个方格，最左边一格中有一只青蛙。青蛙经过连续跳跃到达最右边一格，然后返回最左边一格。去程时它向右跳 $1$、$2$ 或 $3$ 格，回程时它以类似的方式向左跳。它不能跳出这排方格。它把这样的往返旅行重复 $m$ 次。

记 $F(m, n)$ 为青蛙出行时最多只有一个方格从未被经过的走法数。
例如 $F(1, 3) = 4$，$F(1, 4) = 15$，$F(1, 5) = 46$，$F(2, 3) = 16$，$F(2, 100) \bmod 10^9 = 429619151$。

求 $F(10, 10^{12})$ 的最后 $9$ 位。
