# 素数对连接

> 中文意译。英文原文见 [Project Euler Problem 134](https://projecteuler.net/problem=134)；抓取底稿见 `statement.en.md`。

考察相邻的两个素数 $p_1 = 19$ 与 $p_2 = 23$。可以验证 $1219$ 是满足下述条件的最小正整数：它的末几位数字恰好构成 $p_1$，同时它又能被 $p_2$ 整除。

事实上，除了 $p_1 = 3$、$p_2 = 5$ 这一对之外，对任意一对相邻素数 $p_2 \gt p_1$，都存在这样的 $n$：末位数字构成 $p_1$，且 $n$ 能被 $p_2$ 整除。记 $S$ 为这批 $n$ 中最小的那个。

求所有满足 $5 \le p_1 \le 1000000$ 的相邻素数对所对应的 $S$ 之和。
