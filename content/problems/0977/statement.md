# 977 · 迭代函数

> 中文意译。英文原文见 [Project Euler Problem 977](https://projecteuler.net/problem=977)；抓取底稿见 `statement.en.md`。

对于正整数 $n$，设 $F(n)$ 为满足对集合 $S_n=\{1,2,\dots,n\}$ 中的任意 $x, y$ 均有 $f^{(x)}(y)=f^{(y)}(x)$ 的从集合 $S_n$ 到自身的函数 $f$ 的数量。此处 $f^{(k)}$ 表示函数 $f$ 的 $k$ 次复合，例如 $f^{(2)}(x)=f(f(x))$。

已知 $F(3)=8$，$F(7)=174$ 以及 $F(100)=570271270297640131$。

求 $F(10^6) \bmod (10^9+7)$。
