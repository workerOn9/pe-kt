# PE 210 解析——Obtuse Angled Triangles

## 思路推导

记 $c = \dfrac{r}{4}$，$O = (0,0)$，$C = (c,c)$，$B = (x,y) \in S(r)$，即 $|x| + |y| \le r$。

### 第一步：把「钝角」写成点积不等式

三角形共三个内角，三处余弦的符号由点积给出：

$$
\cos\angle O = \frac{(B-O)\cdot(C-O)}{|B-O|\,|C-O|},\quad
\cos\angle B = \frac{(O-B)\cdot(C-B)}{|O-B|\,|C-B|},\quad
\cos\angle C = \frac{(O-C)\cdot(B-C)}{|O-C|\,|B-C|}
$$

逐一展开（$c > 0$）：

$$
(B-O)\cdot(C-O) = c(x+y) < 0 \iff x + y < 0
$$

$$
(O-B)\cdot(C-B) = x^2 + y^2 - c(x+y) < 0 \iff x^2 + y^2 < c(x+y)
$$

$$
(O-C)\cdot(B-C) = c(2c - x - y) < 0 \iff x + y > \frac{r}{2}
$$

**三个条件天然互斥**：非退化三角形至多有一个钝角（内角和为 $180^\circ$）。因此

$$
N(r) = A + B + C
$$

分别对应钝角在 $O$、$C$、$B$ 处，但要额外扣掉**退化点**：当 $B$ 落在直线 $y = x$ 上时 $O$、$B$、$C$ 共线，无内角可言，而三条判据此时仍可能给出负点积（例如 $B = (2,2)$、$c = 1$ 时 $x^2+y^2 - c(x+y) = 8 - 4 > 0$ 无碍，但 $B = (-1,-1)$ 时序会给出负值），故必须显式扣除。

### 第二步：区域 A——$\angle O$ 钝

$S(r)$ 的整点总数

$$
T = \#S(r) = 1 + 2r(r+1) = 2r^2 + 2r + 1
$$

直线 $x + y = 0$ 与菱形的交点满足 $2|x| \le r$，共 $2\lfloor r/2 \rfloor + 1$ 个；由 $(x,y) \mapsto (-x,-y)$ 的双射，$x+y<0$ 与 $x+y>0$ 的点数相等，于是

$$
\#\{x+y<0\} = \frac{T - \left(2\lfloor r/2\rfloor + 1\right)}{2}
$$

其中与 $OC$ 共线的是 $x = y < 0$ 的 $\lfloor r/2 \rfloor$ 个点，减去：

$$
A = \frac{T - \left(2\lfloor r/2\rfloor + 1\right)}{2} - \left\lfloor \frac{r}{2}\right\rfloor
$$

$r = 4c$ 时为 $r^2$，即 $A = 10^{18}$。

### 第三步：区域 B——$\angle C$ 钝

按 $x + y = k$ 分层。当 $0 \le k \le r$ 时，满足 $|x|+|y| \le r$ 的第 $k$ 层点数为

$$
k + 1 + 2\left\lfloor \frac{r-k}{2}\right\rfloor
$$

于是

$$
\#\left\{x+y > \frac{r}{2}\right\} = \sum_{k=r/2+1}^{r}\left(k+1+2\left\lfloor\frac{r-k}{2}\right\rfloor\right)
$$

代入 $j = r - k$（$j = 0 \dots 2c-1$，$r = 4c$）并化简：

$$
= 2c(4c+1) - \frac{(2c-1)(2c)}{2} + 2c(c-1) = 8c^2 + c
$$

再扣去共线的 $x = y > c$ 的 $c$ 个点：

$$
B = 8c^2 + c - c = 8c^2 = 5 \times 10^{17}
$$

### 第四步：区域 C——$\angle B$ 钝（圆盘点数）

配方：

$$
x^2 + y^2 < c(x+y) \iff \left(x - \frac{c}{2}\right)^2 + \left(y - \frac{c}{2}\right)^2 < \frac{c^2}{2}
$$

半径 $\rho = \dfrac{c}{\sqrt 2} \approx 1.7678 \times 10^8$。先确认圆盘完全落在菱形内：盘内点满足

$$
|x| + |y| \le \left|x - \frac{c}{2}\right| + \left|y - \frac{c}{2}\right| + c \le \rho\sqrt 2 + c = 2c = \frac{r}{2} < r
$$

故无需截断。$c$ 为偶数（本题 $c = 2.5 \times 10^8$）时，$U = x - c/2$、$V = y - c/2$ 遍历全部整数，条件化为

$$
U^2 + V^2 < R^2,\qquad R^2 = \frac{c^2}{2}
$$

精确圆盘点数按列求和：满足 $V^2 < R^2 - U^2$ 的整数 $V$ 有 $2\lfloor\sqrt{R^2-U^2-1}\rfloor + 1$ 个，故

$$
\#\{(U,V) : U^2+V^2<R^2\} = (2m_0+1) + 2\sum_{U=1}^{\lfloor\sqrt{R^2-1}\rfloor}\left(2\left\lfloor\sqrt{R^2-U^2-1}\right\rfloor+1\right)
$$

按此式算得 $\# = 98174770424689457$，最后减去共线的 $0 < x = y < c$ 的 $c - 1$ 个点：

$$
C = 98174770424689457 - 249999999 = 98174770174689458
$$

## 旁证

1. **与题面样例一致**：闭式 + 圆盘点数公式对 $r = 4, 8, \dots, 400$（含 $c$ 奇偶两种情形）与直接枚举 $S(r)$ 的暴力解逐点比对全部相等；$N(4) = 24$、$N(8) = 100$ 与题面相符。
2. **圆盘点数用双实现互验**：numpy 分块向量化版本与纯 Python 逐列版本对 $c = 2, 4, \dots, 5000$ 输出相同；本题 $c = 2.5\times10^8$ 时两者同值。
3. **Gauss 圆问题误差自检**：$\# = 98174770424689457$ 与 $\pi R^2 = 98174770424681040$ 的差仅 $8417$，远小于 $O(\rho) \approx 1.8\times 10^8$，量级合理，可作为实现的健康检查。
4. **三区域互斥且覆盖完全**：暴力枚举中每个钝角三角形恰落入 A、B、C 之一（互不相交），且 $A + B + C$ 与暴力总数逐个 $r$ 吻合。
5. Kotlin 独立编译运行输出 $1598174770174689458$，与 Python 独立实现的同值结果一致。

## 答案

$$\mathbf{1598174770174689458}$$

## 教训

- **钝角判据的三条不等式天然互斥，但退化点必须单独扣**：$B$ 与 $O$、$C$ 共线时三点积判据仍可能出负值，直接相加会把非三角形算进去——三个区域各扣一次共线点（$\lfloor r/2 \rfloor$、$c$、$c-1$ 个）才对得上样例。
- **先证圆盘在菱形内再谈计数**：$|x|+|y| \le \rho\sqrt2 + c = r/2 < r$ 这一步省掉后，代码里就得多写一层截断判据，既慢又易错。
- **半径平方到 $3\times10^{16}$ 时 double 已不能精确表示整数**：$\lfloor\sqrt{\cdot}\rfloor$ 必须用 double 估算 + 整数校正（$O(1)$ 次修正即可），否则个别列会差 $1$，答案整体偏移几百。
- **对称性是免费的降维**：$\#\{x+y<0\}$ 与 $\#\{x+y>0\}$ 的对应、圆盘点数的 $u \leftrightarrow -u$ 配对，各把工作量砍半。
- **用解析误差项当自检**：Gauss 圆问题的 $|{\#}-\pi R^2|$ 应在 $O(\rho)$ 以内（实测 $8417$），若算出来偏了 $10^{10}$ 量级，一定是公式或整数开方错了，不必等最终答案对不上才发现。
