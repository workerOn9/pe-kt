# 数位平方和为完全平方数

## 思路推导

$n$ 的数字平方和只与「各数字出现了几次」有关，上界是一百六十级的量：最多 20 位、每位最大贡献 $9^2=81$，故 $0 \le s \le 1620$。

直接用数位 DP 逐位推进，状态为当前的平方和 $s$，同时维护两个量：

- $C[s]$：能得到平方和 $s$ 的前缀个数（$\bmod 10^9$）
- $V[s]$：这些前缀所代表的数值之和（$\bmod 10^9$）

追加一位数字 $d$ 时，旧值 $v$ 变成 $10v+d$，因此

$$C'[s+d^2] \mathrel{+}= C[s], \qquad V'[s+d^2] \mathrel{+}= 10V[s] + d\,C[s]$$

用 20 位定长表示（允许前导零）覆盖 $1 \le n < 10^{20}$ 的每个整数恰好一次。答案即

$$\sum_{k=1}^{40} V[k^2] \bmod 10^9$$

（$40^2 = 1600 \le 1620 < 41^2$；$k=0$ 对应全零串即 $n=0$，按 $n>0$ 排除。）

## 旁证

- 题面三例：$f(3)=9$、$f(25)=29$、$f(442)=36$ 均为完全平方数，逐位计算一致。
- 数位 DP 与暴力枚举在 $n < 10^6$ 上给出的和一致（暴力逐数求平方和并判完全平方）。
- 只保留模 $10^9$ 的计数与和值是安全的：递推里计数只以 $d\cdot C$（$d\le 9$）的形式参与加法，模意义下封闭。

## 答案

**142989277**

## 复杂度对比

| 方法 | 复杂度 | 实测耗时 |
|---|---|---|
| 逐数枚举 | $O(10^{20})$ | 不可行 |
| 暴力到 $10^6$（对拍用） | $O(10^6\cdot 20)$ | $0.9$ s（Python） |
| 数位 DP | $O(20 \times 1620 \times 10)$ | $< 10$ ms |

## 关键教训

1. 需要「求和」而不是「计数」时，DP 状态要同时携带和值，并注意进位形式 $10v+d$。
2. 定长前导零表示能把「不定长整数」变成「定长串」，避免按位数分段讨论。
3. 完全平方数只需枚举到 $\lfloor\sqrt{1620}\rfloor = 40$，不要遍历整个和值域做开方判定。
