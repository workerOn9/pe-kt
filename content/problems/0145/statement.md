# 可逆数

> 中文意译。英文原文见 [Project Euler Problem 145](https://projecteuler.net/problem=145)；抓取底稿见 `statement.en.md`。

有些正整数 $n$ 具有这样的性质：和式 $n + \operatorname{reverse}(n)$ 的十进制表示完全由奇数数字组成。例如 $36 + 63 = 99$，$409 + 904 = 1313$。我们称这样的数为**可逆数**，于是 $36$、$63$、$409$、$904$ 都是可逆数。$n$ 与 $\operatorname{reverse}(n)$ 都不允许有前导零。

一千以内共有 $120$ 个可逆数。

求十亿（$10^9$）以内有多少个可逆数？
