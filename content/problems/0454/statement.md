# 454 · 丢番图倒数方程 III

> 中文意译。英文原文见 [Project Euler Problem 454](https://projecteuler.net/problem=454)；抓取底稿见 `statement.en.md`。

在下列方程中，$x$、$y$、$n$ 都是正整数。

$$
\dfrac{1}{x} + \dfrac{1}{y} = \dfrac{1}{n}
$$

对上限 $L$，定义 $F(L)$ 为满足 $x \lt y \le L$ 的解的个数。

可以验证 $F(15) = 4$ 与 $F(1000) = 1069$。
求 $F(10^{12})$。
