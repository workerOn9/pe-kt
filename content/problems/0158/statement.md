# 探索左三字符按字典序排列的字符串

> 中文意译。原文见 [Project Euler Problem 158](https://projecteuler.net/problem=158)。

取一串仅含字符 `p`、`q`、`r` 的字符串（可重复）。若串长 3 且恰含 3 个不同字符，
则要求这三个字符按字典序升序出现（即必须形如 `pqr`、`pqr` 的某排列...wait — 题目要求**按字典序**，因此串必须是 `pqr`、`prs`、... 形如「3 个字符严格按字典序」）。

题面更准确表述（PE 158）：考察长度为 $n$、只含前 $L$ 个小写字母的字符串。若该串**最左侧的 3 个不同字符**按字典序排列（即左起第 $1, 2, 3$ 个新字符 $\alpha_1 \lt \alpha_2 \lt \alpha_3$），
则称串「valid」。求 $L=26$, $n=18$ 时 valid 字符串总数。

闭式：$p(n) = \binom{26}{n}(2^n - n - 1)$。
