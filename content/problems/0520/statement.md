# 520 · Simber 数

> 中文意译。英文原文见 [Project Euler Problem 520](https://projecteuler.net/problem=520)；抓取底稿见 `statement.en.md`。

我们称一个正整数为 simber 数，如果其中任何奇数位数字（只要出现）都出现奇数次，而任何偶数位数字（只要出现）都出现偶数次。

例如 $141221242$ 是一个 $9$ 位 simber 数，因为它含有三个 $1$、四个 $2$ 和两个 $4$。

记 $Q(n)$ 为位数不超过 $n$ 的 simber 数的个数。

已知 $Q(7) = 287975$，$Q(100) \bmod 1\,000\,000\,123 = 123864868$。

求 $(\sum_{1 \le u \le 39} Q(2^u)) \bmod 1\,000\,000\,123$。
