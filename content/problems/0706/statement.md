# 706 · 3-相似数

> 中文意译。英文原文见 [Project Euler Problem 706](https://projecteuler.net/problem=706)；抓取底稿见 `statement.en.md`。

对正整数 $n$，定义 $f(n)$ 为 $n$ 的能被 $3$ 整除的非空子串的个数。例如，字符串 "2573" 有 $10$ 个非空子串，其中三个表示能被 $3$ 整除的数，即 $57$、$573$ 和 $3$。因此 $f(2573) = 3$。

如果 $f(n)$ 能被 $3$ 整除，则称 $n$ 是 3-相似的。

定义 $F(d)$ 为有多少个 $d$ 位数是 3-相似的。例如 $F(2) = 30$，$F(6) = 290898$。

求 $F(10^5)$，答案对 $1\,000\,000\,007$ 取模。
