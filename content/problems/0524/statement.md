# 524 · 首次排序 II

> 中文意译。英文原文见 [Project Euler Problem 524](https://projecteuler.net/problem=524)；抓取底稿见 `statement.en.md`。

考虑下面这个给列表排序的算法：

1. 从列表开头开始，依次检查每一对相邻元素。
2. 如果这对元素顺序颠倒：
a. 把这对元素中较小的那个移到列表开头。
b. 从第 1 步重新开始。
3. 如果所有相邻对都已有序，停止。

例如，列表 $\{\,4\,1\,3\,2\,\}$ 的排序过程如下：

$\underline{4\,1}\,3\,2$（$4$ 与 $1$ 顺序颠倒，把 $1$ 移到列表开头）
$1\,\underline{4\,3}\,2$（$4$ 与 $3$ 顺序颠倒，把 $3$ 移到列表开头）
$\underline{3\,1}\,4\,2$（$3$ 与 $1$ 顺序颠倒，把 $1$ 移到列表开头）
$1\,3\,\underline{4\,2}$（$4$ 与 $2$ 顺序颠倒，把 $2$ 移到列表开头）
$\underline{2\,1}\,3\,4$（$2$ 与 $1$ 顺序颠倒，把 $1$ 移到列表开头）
$1\,2\,3\,4$（列表现在已有序）

记 $F(L)$ 为把列表 $L$ 排好序时第 2a 步被执行的次数。例如 $F(\{\,4\,1\,3\,2\,\}) = 5$。

我们可以把整数 $\{1, 2, \dots, n\}$ 的所有排列 $P$ 按字典序列出，并给每个排列赋一个从 $1$ 到 $n!$ 的序号 $I_n(P)$，表示它在表中的位置。

记 $Q(n, k) = \min(I_n(P))$，其中 $F(P) = k$，也就是用「首次排序」排序恰好需要 $k$ 步的第一个排列的序号。若不存在满足 $F(P) = k$ 的排列，则 $Q(n, k)$ 无定义。

记 $R(k) = \min(Q(n, k))$，其中 $n$ 取遍所有使 $Q(n, k)$ 有定义的值。

求 $R(12^{12})$。
