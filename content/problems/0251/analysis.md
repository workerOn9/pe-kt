# 251 — 卡尔达诺三元组（Cardano Triplets）

## 建模：把三次根式方程变成整数方程

设 $x = \sqrt[3]{a+b\sqrt c}$、$y = \sqrt[3]{a-b\sqrt c}$（都取实三次根）。由

$$
x^3 + y^3 = 2a, \qquad xy = \sqrt[3]{(a+b\sqrt c)(a-b\sqrt c)} = \sqrt[3]{a^2-b^2c},
$$

以及恒等式 $(x+y)^3 = x^3+y^3+3xy(x+y)$，条件 $x+y=1$ 等价于

$$
1 = 2a + 3\sqrt[3]{a^2-b^2c}
\quad\Longleftrightarrow\quad
a^2-b^2c = \left(\frac{1-2a}{3}\right)^3 .
$$

展开 $27a^2+(2a-1)^3 = 8a^3+15a^2+6a-1$，并注意 $(a+1)^2(8a-1) = 8a^3+15a^2+6a-1$，就得到整数的等式

$$
27b^2c = 27a^2 + (2a-1)^3 = (a+1)^2(8a-1) .
$$

反过来也成立：只要这个整式成立，就有 $\sqrt[3]{a^2-b^2c} = (1-2a)/3$，于是 $(x+y)^3 = 2a + (1-2a) = 1$，即 $x+y=1$。所以这是一个**与原方程完全等价的整数判据**，计数过程不需要任何开方。

模 $3$ 分析：左端 $27b^2c \equiv 0$。右端 $(a+1)^2(8a-1) \equiv 0 \pmod 3$ 要求 $a \equiv 2 \pmod 3$（$a\equiv 2$ 时 $a+1\equiv 0$；若 $8a-1\equiv 0$ 则 $2a\equiv 1$，同样给出 $a\equiv 2$）。记 $a = 3m-1$（$m \ge 1$），则 $a+1 = 3m$、$8a-1 = 3(8m-3)$，等式化为

$$
27b^2c = 9m^2 \cdot 3(8m-3) \quad\Longleftrightarrow\quad b^2c = m^2(8m-3) .
$$

代回去验证：$a^2-b^2c = (3m-1)^2 - m^2(8m-3) = -(2m-1)^3$，而 $(1-2a)/3 = -(2m-1)$，两边吻合。于是问题变成：

$$
\text{统计 } (m,b,c):\quad m,b,c \ge 1,\quad b^2c = m^2(8m-3),\quad 3m-1+b+c \le N .
$$

## 双射参数化

对每个解取 $p = \gcd(b,m)$，写 $b = pr$、$m = pq$，则 $\gcd(q,r)=1$。代入 $b^2c = m^2(8m-3)$ 得 $r^2c = q^2(8m-3)$；由 $\gcd(q,r)=1$ 推出 $r^2 \mid 8m-3$。记 $s = (8m-3)/r^2$，则 $c = sq^2$，且

$$
a = 3pq-1, \qquad b = pr, \qquad c = sq^2, \qquad 8pq = sr^2+3,
$$

其中 $r$ 必为奇数（$8m-3$ 是奇数），约束为

$$
a+b+c \le N \quad\Longleftrightarrow\quad p(3q+r) + sq^2 \le N+1 =: L .
$$

反向：任给满足 $8pq = sr^2+3$（$r$ 奇、$\gcd(q,r)=1$）的正整数 $(p,q,r,s)$，令 $m = pq$、$b = pr$、$c = sq^2$，则 $b^2c = m^2sr^2 = m^2(8m-3)$，是一个合法三元组；且此时 $\gcd(b,m) = \gcd(pr,pq) = p\gcd(r,q) = p$ 由三元组唯一确定。所以这是 $(p,q,r,s) \leftrightarrow (a,b,c)$ 的**一一对应**。

关键观察：固定 $(q,r)$ 后，$p$ 的可行性只差一个模条件——$8pq \equiv 3 \pmod{r^2}$。因为 $r$ 奇、$\gcd(q,r)=1$ 时 $\gcd(8q,r^2)=1$，$p$ 在模 $r^2$ 下唯一。

## 方法 A：按 $(q,r)$ 分类，等差数列计数（主路径）

- **$q$ 的界**：$a \ge 3q-1$、$b \ge 1$、$c \ge q^2$，故 $q^2+3q \le N$，$q \le 10488$。
- **$r$ 的界**：$p = (3+sr^2)/(8q) \ge r^2/(8q)$，由 $s \ge 1$ 与 $p(3q+r) \le L$ 得必要界
  $r^3+3qr^2+8q^3 \le 8qL$（循环用它，命中后再按精确条件过滤）。
- **$r = 1$ 整列处理**：此时 $s = 8pq-3$，约束化成
  $p(8q^3+3q+1) \le L+3q^2$，于是这一列有
  $\lfloor (L+3q^2)/(8q^3+3q+1) \rfloor$ 个解——**一次除法顶掉一整列**。
- **$r \ge 3$**：$p$ 落在等差数列 $p \equiv p_0 \pmod{r^2}$ 上，$p_0 = 3\cdot(8q)^{-1} \bmod r^2$（取 $[1,r^2]$ 内的代表）。最小解 $p_0$ 对应 $s_0 = (8p_0q-3)/r^2$；$p$ 每增加 $r^2$，$s$ 增加 $8q$，总和增加

$$
step = r^2(3q+r) + 8q^3 ,
$$

  所以若 $base = p_0(3q+r)+s_0q^2 \le L$，这一对 $(q,r)$ 贡献 $\lfloor (L-base)/step \rfloor + 1$。（等价判据：$9q+3r+s_0\cdot step \le 8qL$。）

每对 $(q,r)$ 都要算 $s_0 = (-3/r^2) \bmod 8q$。直接逐对扩展欧几里得是 $4.9\times10^7$ 次；实现改为**同一模数下的批量求逆**：把该 $q$ 的全部 $x_i = r_i^2 \bmod 8q$ 收集起来，算前缀积后做**一次**模逆，再回代分发——每对只需常数次乘法，扩展欧几里得次数从 $4.9\times10^7$ 降到约 $10^4$。

实测枚举了 $49\,058\,710$ 个 $(q,r)$ 对，其中 $84\,151$ 对命中，合计给出全部 $18\,946\,051$ 个三元组。

## 方法 B：按 $(r,s)$ 枚举 + 约数分解（独立复核）

这条路径不引进 $p$ 的等差结构，而是利用 $(r,s)$ 唯一确定 $m$ 这一点：

- $s \equiv 5 \pmod 8$ 是 $8 \mid sr^2+3$（$r^2 \equiv 1 \bmod 8$）的直接推论；
- $r$ 为奇数、$s = 5+8j$ 时 $m = (sr^2+3)/8$ 唯一确定；
- 用最小质因子筛分解 $m$，枚举 $m$ 的**全部约数** $p$，检查 $\gcd(m/p, r) = 1$ 与 $3m-1+pr+s(m/p)^2 \le N$。

$m$ 的范围由 AM-GM 收紧：$b+c \ge 3\sqrt[3]{b^2c/4} = 3\sqrt[3]{m^2(8m-3)/4} \ge 3\sqrt[3]{5m^3/4} = 3.2317\,m$，于是 $6.2317m - 1 \le N$，$m < (N+1)\cdot 5/31 \approx 1.774\times10^7$。

两条路径的枚举空间（$4.9\times10^7$ 对 $(q,r)$ vs $2.19\times10^7$ 对 $(r,s)$）、循环次序、数据结构与全部算术都不同，只在 $b^2c = m^2(8m-3)$ 这个起点上重合。

## 答案

两条路径的完整规模输出一致：

$$
\boxed{18946051}
$$

## 关键教训

- **静默的 Long 溢出只能靠双方法互证抓出来。** 方法 B 第一版在 Kotlin 里写成 `s * q * q`，而 $sq^2$ 在过滤前可以到 $10^{22}$ 量级：结果静默回绕，完整规模数出 $53\,257\,933$（真值的 $2.8$ 倍），但 $N \le 10^6$ 之前两条路径全部一致——因为那时中间量还没溢出，而 Python 原型用大整数更不会暴露。**乘式先估上界、必要时用除法预检（`s > n/(q*q)` 就直接跳过）**，是这类题的基本纪律；两组结构不同的实现则是最便宜的保险。
- **参数化的双射要两头都证。** $a\equiv2\pmod 3$ 是必要条件（模 $3$ 分析），$p=\gcd(b,m)$ 与 $\gcd(q,r)=1$ 是构造的必要条件，而反向「任给 $(p,q,r,s)$ 都能拼出合法三元组」也必须显式验证——少证一头就会多算或漏算。
- **必要界要靠不等式挤。** $p \ge r^2/(8q)$ 加 $s \ge 1$ 把 $r$ 的枚举上界从「$r^3 \le 8qL$」压到「$r^3+3qr^2+8q^3 \le 8qL$」，枚举空间从约 $8.2\times10^7$ 对降到 $4.9\times10^7$ 对；AM-GM 则把方法 B 的 $m$ 上界从 $N/3$ 压到 $1.774\times10^7$。
- **定点小数的牛顿迭代会在末位振荡。** 用 `BigDecimal` 求立方根时不能拿「相邻两步完全相等」当停机条件（实测大量输入永不相等、循环打转）；改成「步长小于容差」即可，收敛判据 50 位精度下 3～5 步就够。
- **整列解法比逐个枚举便宜得多。** $r = 1$ 对应 $s = 8pq-3$ 的整列解，闭式一次除法就数完；批量求逆同理，把 $4.9\times10^7$ 次模逆压成 $10^4$ 次。
- **$b = 1$ 时 $c$ 可以很大。** 最大的一族解里 $p = r = 1$、$q$ 很大（$c = 8q^3-3q^2$ 达 $10^8$ 量级），任何「$b$ 接近最优值 $2.5m$」的近似裁剪都必须先证明、再使用；本题的裁剪全部来自严格不等式。
