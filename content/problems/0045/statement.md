# 三角形数、五边形数与六边形数

> 中文意译。英文原文见 [Project Euler Problem 45](https://projecteuler.net/problem=45)；抓取底稿见 `statement.en.md`。

三类多边形数由如下公式生成：

| 名称 | 公式 | 前几项 |
|------|------|--------|
| 三角形数 | $T_n = n(n+1)/2$ | 1, 3, 6, 10, 15, … |
| 五边形数 | $P_n = n(3n-1)/2$ | 1, 5, 12, 22, 35, … |
| 六边形数 | $H_n = n(2n-1)$ | 1, 6, 15, 28, 45, … |

可以验证 $T_{285} = P_{165} = H_{143} = 40755$。
