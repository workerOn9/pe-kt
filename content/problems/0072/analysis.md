# 072 · 既约真分数计数 — 解析

## 思路推导

**把「按大小排序」这个信息扔掉。** 题目问的是集合的元素个数，而排序只是描述集合的方式，与计数无关。真正决定一个分数是否入集的，只有两条约束：$0 < n < d$ 与 $\gcd(n,d)=1$。

于是按分母分层统计：固定 $d$，满足 $1 \le n < d$ 且 $\gcd(n,d)=1$ 的 $n$ 的个数，正是 Euler 函数

$$\varphi(d) = \#\{1 \le n \le d : \gcd(n,d)=1\}$$

（$n=d$ 被 $n<d$ 排除，但 $\gcd(d,d)=d \ne 1$，本来就不算）。所以

$$S(N) = \sum_{d=2}^{N} \varphi(d).$$

下界从 $d=2$ 开始：$d=1$ 时唯一的候选是 $0/1$，$n$ 必须是正整数，故不入集。用题面的样例校验：

$$S(8) = \varphi(2)+\varphi(3)+\cdots+\varphi(8) = 1+2+2+4+2+6+4 = 21,$$

与题面给出的 $21$ 个元素吻合。

**线性筛一次算出所有 $\varphi$。** 设 $i$ 的最小素因子为 $p_j$，商 $i = p_j \cdot t$，则

$$\varphi(i p_j) = \begin{cases} \varphi(i)\cdot p_j, & p_j \mid i \quad(\text{指数的幂次抬高，新增素因子为零})\\ \varphi(i)\cdot (p_j - 1), & p_j \nmid i \quad(\text{新增一个素因子})\end{cases}$$

前者来自 $\varphi(p^{a+1}) = p^{a+1}-p^{a} = p\,(p^{a}-p^{a-1})$，后者来自 $\varphi$ 的乘性。每个合数只在「被它的最小素因子筛掉」时被写一次，总代价 $O(N)$。

**量级旁证。** 素数分布给出 $\sum_{d \le N}\varphi(d) \sim \dfrac{3N^2}{\pi^2}$：代入 $N = 10^6$ 得 $3\times10^{12}/9.8696 \approx 3.0396\times10^{11}$，与实跑结果 $303\,963\,552\,391$ 的前四位完全一致——这条渐近式只做交叉校验，真正的答案仍来自筛法逐项累加。

**溢出提醒。** 数据规模 $10^6$，但求和量级 $3\times10^{11}$ 远超 `Int` 上限 $2^{31}-1 \approx 2.1\times10^9$：累加器必须用 `Long`，而 $\varphi$ 本身不超过 $10^6$，用 `Int` 存放即可。

答案：**303963552391**。

## 复杂度对比

| 方案 | 时间 | 实测（JIT 预热后） |
|------|------|------|
| 优化解：线性筛求 $\varphi$ 后累加 | $O(N)$，$O(N)$ 空间 | ~5.557 ms |
| 暴力解：每个 $d$ 单独试除分解再算 $\varphi$ | $O\!\left(\sum_{d\le N}\sqrt d\right) = O(N\sqrt N)$ | ~219.339 ms |
| （反面参照）直接枚举所有 $(n,d)$ 数最大公约数 | $O(N^2)\approx 10^{12}$ 次 gcd | 不可行 |

约 $39$ 倍差距来自「信息复用」：暴力解对每个 $d$ 从零开始试除，同一个素因子的判定被重复做了 $N/p$ 次；线性筛让每个合数只在唯一一次写入中被确定，等于把重复劳动整片删掉。值得注意的是暴力解本身也远好于双重循环数 gcd——$O(N^2)$ 的那条路即使在本机也要走上几十分钟，说明「先按分母归并，再逐分母求 $\varphi$」这一步结构上的降维比常数优化重要得多。

## 实现要点

- `phi[1] = 1` 但不参与求和；`d` 从 2 开始
- 线性筛内层用裸数组 `primes` + 计数器，避免 `ArrayList` 装箱带来的常数开销
- 判断 `i * p > n` 时先把乘数升为 `Long`，否则 $10^6 \times 10^6$ 会溢出 `Int` 变成负数而误判
- 累加器与返回值都是 `Long`；`phi[i] * p ≤ 10^6` 不会溢出 `Int`，可以放心用 `Int` 存
- 筛完后一次 `for` 求和，与筛法分离，便于对照暴力解
