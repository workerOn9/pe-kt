# 410 · 圆与切线

> 中文意译。英文原文见 [Project Euler Problem 410](https://projecteuler.net/problem=410)；抓取底稿见 `statement.en.md`。

设 $C$ 是半径为 $r$ 的圆 $x^2 + y^2 = r^2$。选取两点 $P(a, b)$ 与 $Q(-a, c)$，使得过 $P$ 与 $Q$ 的直线与 $C$ 相切。

例如，四元组 $(r, a, b, c) = (2, 6, 2, -7)$ 满足这一性质。

记 $F(R, X)$ 为具有这一性质、且 $0 \lt r \leq R$、$0 \lt a \leq X$ 的整数四元组 $(r, a, b, c)$ 的个数。

可以验证 $F(1, 5) = 10$，$F(2, 10) = 52$，$F(10, 100) = 3384$。
求 $F(10^8, 10^9) + F(10^9, 10^8)$。
