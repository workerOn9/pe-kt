# 980 · 四元数群 I

> 中文意译。英文原文见 [Project Euler Problem 980](https://projecteuler.net/problem=980)；抓取底稿见 `statement.en.md`。

从空字符串开始，我们要构造一个由字母“x”、“y”、“z”组成的字符串。在每一步中，可以执行以下操作之一：

- 在字符串的任意位置插入两个连续的相同字母“xx”、“yy”或“zz”；
- 按照规则将字符串中的一个字母替换为两个连续字母：“x” $\to$ “yz”，“y” $\to$ “zx”，“z” $\to$ “xy”；
- 交换字符串中两个相邻的不同字母，例如“xy” $\to$ “yx”，“zx” $\to$ “xz”等。

如果一个字符串可以从空字符串出发经过偶数步操作得到，则称该字符串为**中性字符串**（neutral）。

定义序列 $(a_n)_{n \ge 0}$：$a_0=88\,888\,888$，且当 $n \gt 0$ 时，$a_n=(8888\cdot a_{n-1})\bmod 888\,888\,883$。

设 $b_n = a_n \bmod 3$。对每个 $i \ge 0$，通过规则 $0 \to$ “x”，$1 \to$ “y”，$2 \to$ “z”将有限序列 $b_{50i},b_{50i+1},\dots,b_{50i+49}$ 转化为长度为 $50$ 的字符串 $c(i)$。

设 $F(N)$ 为使得拼接后的字符串 $c(i)c(j)$ 为中性字符串的有序对 $(i, j)$（满足 $0 \le i, j < N$）的数量。
已知 $F(10) = 13$ 以及 $F(100) = 1224$。

求 $F(10^6)$。
