# 立方体数字对

> 中文意译。英文原文见 [Project Euler Problem 90](https://projecteuler.net/problem=90)；抓取底稿见 `statement.en.md`。

两个立方体，各自六个面上分别写着一个互不相同的数字（$0$ 到 $9$）。把两个立方体并排摆成不同位置，就能拼出各种两位数。

例如平方数 $64$ 可以这样拼出来。

事实上，只要精心挑选两个立方体上的数字，就能拼出所有小于一百的平方数：$01$、$04$、$09$、$16$、$25$、$36$、$49$、$64$、$81$。

例如把 $\{0,5,6,7,8,9\}$ 放在一个立方体上、$\{1,2,3,4,8,9\}$ 放在另一个上，就能做到这一点。

不过本题允许把 $6$ 或 $9$ 上下倒过来使用，于是像 $\{0,5,6,7,8,9\}$ 与 $\{1,2,3,4,6,7\}$ 这样的搭配也能拼出全部九个平方数——否则就无法得到 $09$。

判断两种摆放是否相同，我们只看每个立方体上写了哪些数字，而不看顺序：

- $\{1,2,3,4,5,6\}$ 与 $\{3,6,4,1,2,5\}$ 视为同一种；
- $\{1,2,3,4,5,6\}$ 与 $\{1,2,3,4,5,9\}$ 视为不同。

但因为允许 $6$ 与 $9$ 互换，上例中这两个不同的集合在「拼两位数」这件事上代表同一个扩展集合 $\{1,2,3,4,5,6,9\}$。

问：有多少种不同的立方体摆放方式，能够拼出全部九个平方数？
