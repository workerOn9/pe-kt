# 388 · 互不相同的直线

> 中文意译。英文原文见 [Project Euler Problem 388](https://projecteuler.net/problem=388)；抓取底稿见 `statement.en.md`。

考虑所有满足 $0 \\le a, b, c \\le N$ 的格点 $(a,b,c)$。

从原点 $O(0,0,0)$ 向其余每个格点都画一条直线。

记 $D(N)$ 为这些互不相同的直线的条数。

已知 $D(1\\,000\\,000)=831909254469114121$。

求 $D(10^{10})$。答案以前 $9$ 位紧接后 $9$ 位给出。
