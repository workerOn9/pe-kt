# 正方形薄片的拼法计数

## 思路推导

沿用上一题的结构：边长 $n$ 的外框配 $m$ 边长的孔（$m<n$、$m\equiv n \bmod 2$）用砖

$$t = n^2 - m^2$$

对每个 $t \le 10^6$ 统计它被多少组 $(n,m)$ 表示，记作 $L(t)$；则

$$N(k) = \#\{t \le 10^6 : L(t) = k\}, \qquad \text{答案}=\sum_{k=1}^{10} N(k)$$

枚举所有 $(n,m)$ 对的代价可控：$n \le 250001$，但每组 $n$ 只需走到 $m \ge \sqrt{n^2-10^6}$，总对数约 $3.3\times 10^6$。

## 旁证

- 题面给出 $N(15)=832$，实算 832。
- 题面两例：$t=8$ 只有 $3^2-1^2$ 一种表示（$L(8)=1$）；$t=32$ 有 $(9,7)$ 与 $(6,2)$ 两种（$L(32)=2$），实算一致。
- 实算得到的 $N(1..15)$：
  $22139, 55858, 12675, 56035, 2378, 24111, 670, 29015, 2749, 3936, 53, 16144, 90, 859, 832$。

## 答案

**209566**

## 复杂度对比

| 方法 | 复杂度 | 实测耗时（Python） |
|---|---|---|
| 逐对枚举全部 $(n,m)$ 后排序统计 | $O(3.3\times 10^6)$ | $0.4$ s |
| 桶计数 + 前缀统计 | $O(3.3\times 10^6 + 10^6)$ | $0.4$ s |

## 关键教训

1. 同一几何结构（平方差）上的两个不同问题可以共用一次枚举：先算「每个 $t$ 的表示数」，再按表示数分桶，就能回答「恰有 $k$ 种拼法」的任意统计。
2. 表示数分布极不均匀（$N(1)$ 与 $N(4)$ 都是万级，$N(11)$ 只有几十），统计时先分桶再取前缀，避免对每个 $k$ 重扫一遍。
3. 判断表示数上界时要给桶留余量：本题出现过的最大表示数远大于 10，桶数组开小了会越界。
4. **整型溢出**：外边长 $n$ 最大到 $2.5\times10^5$，$n^2$ 达 $6.25\times10^{10}$，远超 32 位 `Int` 上限（约 $2.1\times10^9$）。循环变量与面积一律用 64 位，只在写回数组下标时才转回 `Int`。首版用 `Int` 计算 $n^2$ 直接越界崩溃。
