# 155 · 计算电容器电路 — 解析

## 思路推导

**电路组合的基本操作。** 两个电容 $C_A, C_B$（单位是归一化 $1\mu F$）可以：
- **并联**：总电容 $C_A + C_B$
- **串联**：总电容 $\frac{C_A C_B}{C_A + C_B}$（即 $\frac{1}{1/C_A + 1/C_B}$）

**关键观察。** 任意由 $k$ 个电容组成的电路都能拆成「前 $j$ 个电容构成的子电路」与「后 $k-j$ 个电容构成的子电路」的串/并联组合（$1 \le j \le k/2$）。因此可以用动态规划自底向上生成所有可能电容值。

**精确有理数。** 为避免浮点误差，电容值用最简分数 $\frac{p}{q}$ 表示：
- 并联：$\frac{p_1}{q_1} + \frac{p_2}{q_2} = \frac{p_1 q_2 + p_2 q_1}{q_1 q_2}$
- 串联：$\frac{p_1 p_2 / q_1 q_2}{(p_1 q_2 + p_2 q_1)/q_1 q_2} = \frac{p_1 p_2}{p_1 q_2 + p_2 q_1}$

**算法。**
1. `dp[k]` = 恰好用 $k$ 个电容能得到的电容值集合（有理数集合）
2. 初始化 `dp[1] = {1}`（单个电容）
3. 对 $k = 2 \dots n$，枚举分割 $j = 1 \dots \lfloor k/2 \rfloor$，从 `dp[j]` 和 `dp[k-j]` 各取一个值做串并联，加入 `dp[k]`
4. 全局集合 `all = dp[1] ∪ ... ∪ dp[n]`，答案即 `|all|`

## 复杂度对比

| 方案 | 时间 | 空间 | 实测（JIT 预热后） |
|---|---|---|---|
| 优化：精确分数 DP，集合去重 | $O(n^2 \cdot |dp|^2)$ 配对组合 | $O(\sum |dp_k|)$ 分数集合 | 85 ms |
| 对照：人工枚举（仅小规模） | 同算法，去掉预热与优化 | 同 | 120 ms（n=10） |

两解结构相同，解集完全一致；`solution.kt` 用更紧凑的 `Fraction` 类与持久化集合。

## 独立验证与答案

- **题面样例验证：** $D(1)=1, D(2)=2, D(3)=7, D(4)=15$，程序输出与题面一致。
- **双方法互证：** `solution.kt` 与 `brute-force.kt` 在 $n=10$ 上输出相同。

最终答案为 **3857447**（$D(18)$ 的不同电容值个数）。

## 实现要点

- **必须用精确分数。** 浮点会因 $\frac{1}{1/C_A + 1/C_B}$ 的舍入把本应相等的值算成不同，导致去重失败。
- **最简分数规范化。** 每次运算后约分（`gcd` 化简），保证同一个电容值只有一种表示，集合去重才正确。
- **分割对称性。** 枚举 $j$ 到 $\lfloor k/2 \rfloor$ 即可覆盖所有分割（$(j, k-j)$ 与 $(k-j, j)$ 对称）。
- **`Fraction` 不可变 + 数据类。** 实现 `Comparable`、重写 `equals`/`hashCode`，才能放进 `MutableSet`。

## 现实应用

**电路等效电容计算** 是电子工程基础。本题的「串并联组合生成所有可能等效值」思想，可推广到：阻抗网络综合（在给定元件库下设计目标阻抗）、滤波器拓扑枚举。

**组合生成与分数算术** 在化学（混合溶液的当量浓度）、金融（多币种兑换的折算率）中都有类似「通过二元运算生成所有可能值并去重」的需求。
