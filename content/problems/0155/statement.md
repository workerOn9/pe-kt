# 计算电容器电路

> 中文意译。英文原文见 [Project Euler Problem 155](https://projecteuler.net/problem=155)；抓取底稿见 `statement.en.md`。

一个电路使用全部等值的电容 $C$。

这些电容可以串联或并联形成子单元，然后这些子单元可以继续与其他电容或子单元串联/并联，构建更大的子单元，直到最终完成整个电路。

用这种简单方法，最多使用 $n$ 个相同电容，可以获得一系列不同的总电容值。例如，用不超过 $n=3$ 个 $60\,\mu F$ 的电容，可以得到以下 7 种不同总电容值：

$$60\mu F, 90\mu F, 120\mu F, 180\mu F, 40\mu F, 45\mu F, 135\mu F$$

若用 $D(n)$ 表示用最多 $n$ 个相同电容和上述简单方法能获得的不同总电容值个数，则：

$$D(1) = 1, D(2) = 2, D(3) = 7, D(4) = 15$$

求 $D(18)$。

提示：电容 $C_1, C_2, \dots$ 并联时，总电容为 $C_{total} = C_1 + C_2 + \dots$；串联时，总电容满足 $\frac{1}{C_{total}} = \frac{1}{C_1} + \frac{1}{C_2} + \dots$。
