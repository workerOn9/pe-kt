# 155 · 计算电容器电路 — 现实应用

**电路等效电容** 是电子工程的基础问题。现代电路综合（circuit synthesis）正是从「给定元件库，能否实现目标阻抗」出发，枚举所有可能的串并联组合——本解的 DP 框架是该问题的离散化原型。

**分数算术的稳健性** 在科学计算中极其重要：阻抗、浓度、汇率换算等都用有理数表达，而浮点舍入会导致「同一物理量出现多个近似表示」从而破坏去重与等价判断。用最简分数（gcd 规范化）是标准解法，也出现在计算机代数系统（CAS）的底层。

**组合生成 + 集合去重** 的模式，在生物信息学（de Bruijn 图组装）、编译器优化（指令组合等价类）中都有应用。
