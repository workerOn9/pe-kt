# 960 · 石子堆单人纸牌

> 中文意译。英文原文见 [Project Euler Problem 960](https://projecteuler.net/problem=960)；抓取底稿见 `statement.en.md`。

有 $n$ 堆各不相同的石子，每堆的大小均为 $n - 1$。从初始得分 $0$ 开始，重复执行以下操作：
1. 选择任意两堆石子，并从这两堆中总共移走恰好 $n$ 颗石子。
2. 若从这两堆中分别移走的石子数为 $a$ 和 $b$（满足 $a + b = n$ 且 $a, b \ge 0$），则将 $\min(a, b)$ 累加到得分中。

如果最终所有石子堆都被清空，则当前得分被确认作为最终得分。然而，如果陷入“僵局”（stuck）导致无法清空所有石子堆，则当前得分作废，最终得分计为 $0$。

下图展示了 $n = 4$ 时的三种回合序列示例，每个元组表示进行过程中的石子堆大小，箭头上方的数字表示累加的分数：

$$
\begin{aligned}
&(3,3,3,3) \xrightarrow{+1} (0,3,2,3) \xrightarrow{+1} (0,3,1,0) \xrightarrow{+1} (0,0,0,0) &: \quad \text{最终得分 } = 3 \\
&(3,3,3,3) \xrightarrow{+1} (3,0,3,2) \xrightarrow{+2} (1,0,3,0) \xrightarrow{+1} (0,0,0,0) &: \quad \text{最终得分 } = 4 \\
&(3,3,3,3) \xrightarrow{+2} (1,3,1,3) \xrightarrow{+1} (1,2,1,0) \rightarrow \text{僵局!} &: \quad \text{最终得分 } = 0
\end{aligned}
$$

定义 $F(n)$ 为成功清空所有石子堆的每一种合法回合序列所获得的最终得分之和。

已知 $F(3) = 12$，$F(4) = 360$，且 $F(8) = 16785941760$。

求 $F(100) \bmod (10^9 + 7)$。
