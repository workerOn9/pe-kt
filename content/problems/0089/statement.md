# 罗马数字

> 中文意译。英文原文见 [Project Euler Problem 89](https://projecteuler.net/problem=89)；抓取底稿见 `statement.en.md`。

一个用罗马数字写成的数要被认作**合法**，必须满足若干基本规则。虽然规则允许同一个数有多种写法，但每个数总有唯一一种「最好」的写法。

例如十六似乎至少可以写成六种形式：

```
IIIIIIIIIIIIIIII
VIIIIIIIIIII
VVIIIIII
XIIIIII
VVVI
XVI
```

但按规则只有 `XIIIIII` 与 `XVI` 合法，而后者用到的数字字符最少，因此被认为是最高效的写法。

文本文件 `roman.txt`（约 11K）中包含一千个数，都写成合法但未必最小的罗马数字；题中「关于……罗马数字」页面给出了本题采用的权威规则。

请计算：把这一千个数全部改写成它们的最小形式后，**一共能省下多少个字符**。

注：可以假定文件中所有罗马数字里不会出现超过四个连续的相同符号。
