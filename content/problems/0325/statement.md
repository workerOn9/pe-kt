# 325 · 取石游戏 II

> 中文意译。英文原文见 [Project Euler Problem 325](https://projecteuler.net/problem=325)；抓取底稿见 `statement.en.md`。

两堆石子，两名玩家轮流行动。每回合，玩家从**较大的那堆**中取走石子，取走的数量必须是较小那堆石子数的正整数倍。

例如有序对 $(6,14)$ 表示小堆有 $6$ 个、大堆有 $14$ 个石子，先手可以从大堆中取走 $6$ 或 $12$ 个。

取光某一堆石子的玩家获胜。

若先手能强制获胜，则称该局面为**必胜局面**。例如 $(1,5)$、$(2,6)$、$(3,12)$ 都是必胜局面——先手可以直接取光大堆。

若无论先手怎么走，后手都能强制获胜，则称该局面为**必败局面**。例如 $(2,3)$ 与 $(3,4)$ 都是必败局面：任何合法走法都会给后手留下一个必胜局面。

记 $S(N)$ 为所有必败局面 $(x_i,y_i)$（$0 < x_i < y_i \le N$）的 $(x_i+y_i)$ 之和。可以验证 $S(10)=211$，$S(10^4)=230312207313$。

求 $S(10^{16}) \bmod 7^{10}$。
