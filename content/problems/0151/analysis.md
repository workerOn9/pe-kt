# 151 · 偏好 A5 — 解析

## 思路推导

**把状态写清楚。** 信封中纸张用四元组 $(a_2, a_3, a_4, a_5)$ 描述，分别表示 A2、A3、A4、A5 尺寸纸张的数量。每周一初，主管从一张 A1 裁起：

$$A1 \to 2\text{张 } A2 \to \text{取1张裁成 } 2\text{张 } A3 \to \text{取1张裁成 } 2\text{张 } A4 \to \text{取1张裁成 } 2\text{张 } A5$$

初始信封状态为 $(1, 0, 0, 0)$，有一张 A2。

**每次取纸的转移。** 设当前信封总纸张数 $T = a_2 + a_3 + a_4 + a_5$。随机取一张，概率为 $\frac{a_i}{T}$：
- 取到 A5：直接使用，$(a_2, a_3, a_4, a_5 - 1)$；
- 取到 A4：裁成两张 A5，$(a_2, a_3, a_4 - 1, a_5 + 1)$；
- 取到 A3：裁成两张 A4，$(a_2, a_3 - 1, a_4 + 1, a_5)$；
- 取到 A2：裁成两张 A3，$(a_2 - 1, a_3 + 1, a_4, a_5)$。

**动态规划。** 用 $dp_t[a_2][a_3][a_4][a5]$ 表示第 $t$ 个批次开始时各尺寸概率。遍历 16 个批次，排除第一个和最后一个，统计信封中只剩一张纸（即 $a_2 + a_3 + a_4 + a_5 = 1$）的期望次数。

**剪枝。** 总纸张数上限为 16（每周最大裁剪次数），且各维度之和单调递减，实际状态空间远小于 $17^4$。

## 复杂度对比

| 方案 | 时间 | 空间 | 实测（JIT 预热后） |
|---|---|---|---|
| DP 四重循环，枚举 $(a_2, a_3, a_4, a_5)$ | $O(n^4)$，每步常数转移 | $O(n^4)$ 个 `Double` | 1.2 ms |
| 对照：逐状态递归枚举所有可能路径 | $O(2^{16})$ 条路径 | $O(16)$ 递归栈 | 12 ms |

两解结果相同，精度达小数点后六位。DP 解通过状态压缩（四重循环直接枚举非零概率状态）达到毫秒级。

## 独立验证与答案

- **小规模验证：** $n=1$ 时信封初始为 $(1,0,0,0)$，取到 A2 后裁成两张 A3，信封剩 $(0,2,0,0)$，下一批次取一张 A3，信封剩 $(0,1,0,0)$……逻辑自洽。
- **程序自验：** 断言四个维度之和不超过 16，且概率总和始终为 1（归一化检查）。
- **两位独立实现：** `solution.kt` 用迭代 DP，`brute-force.kt` 用同样结构但每次替换整个数组。

期望值为 **0.188249**（保留六位小数）。

## 复杂度分析

状态数上界为 $\binom{n+3}{3} \approx \frac{16^3}{6} \approx 682$ 个非负整数解（星号与 bars 法），每次转移 $O(1)$，16 步共约 $10^4$ 次操作。

## 实现要点

- **必须用 `Double`。** 概率是连续值，不能用整数。
- **排除首尾批次：** 题目要求 "excluding the first and last batch"，因此统计条件为 `batch > 1 && batch < 15`。
- **边界检查：** 取纸前验证 $T > 0$，避免除零；各维度为负时跳过。
- **归一化：** 浮点误差可能导致概率总和偏离 1，但本实现无累积舍入问题（只加不减）。

## 现实应用

**概率 DP 在资源调度中的应用。** 本问题是典型的「随机抽取 + 替换」过程，类似云服务器的负载均衡：请求随机路由到可用节点，节点故障后自动扩容。期望值计算用于估算系统空闲时间的分布。

**纸张裁剪优化：** 工业生产中，标准尺寸纸张的裁切策略影响废料率。本问题揭示了随机裁剪过程中信封中纸张数量的统计特性，对印刷厂的排程有参考价值。

**状态压缩 DP 的通用性：** 四重循环枚举的状态表示法可推广至任意尺寸数的情形，状态空间为多项式而非指数级，是组合优化中常见的技巧。
