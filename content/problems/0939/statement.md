# 939 · 党派尼姆

> 中文意译。英文原文见 [Project Euler Problem 939](https://projecteuler.net/problem=939)；抓取底稿见 `statement.en.md`。

两名玩家 A 和 B 正在进行一种尼姆博弈（Nim）的变体游戏。
初始时有若干堆石子。每堆石子要么属于 A 这一侧，要么属于 B 这一侧。各堆石子之间是无序的。

两人轮流行动。轮到某位玩家时，该玩家可以：
- 选择对手侧的一堆石子，并从中移走恰好一颗石子；
- 或者选择自己侧的一堆石子，将该堆石子整堆全部移走。

移走最后一颗石子的玩家获胜。

设 $E(N)$ 为总石子数不超过 $N$、且无论谁先手 A 都拥有必胜策略的初始布局数。

例如 $E(4) = 9$，这 9 种初始布局分别为：

| 编号 | A 侧的石子堆 | B 侧的石子堆 |
| :---: | :---: | :---: |
| 1 | $4$ | 无 |
| 2 | $1, 3$ | 无 |
| 3 | $2, 2$ | 无 |
| 4 | $1, 1, 2$ | 无 |
| 5 | $3$ | $1$ |
| 6 | $1, 2$ | $1$ |
| 7 | $2$ | $1, 1$ |
| 8 | $3$ | 无 |
| 9 | $2$ | 无 |

求 $E(5000) \bmod 1234567891$。
