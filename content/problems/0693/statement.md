# 693 · 有限序列生成器

> 中文意译。英文原文见 [Project Euler Problem 693](https://projecteuler.net/problem=693)；抓取底稿见 `statement.en.md`。

两个正整数 $x$ 和 $y$（$x > y$）可按如下方式生成一个序列：

$a_x = y$ 是首项，
对 $z = x, x+1,x+2,\ldots$ 有 $a_{z+1} = a_z^2 \bmod z$，且
当某项变成 $0$ 或 $1$ 时生成停止。

该序列的项数记为 $l(x,y)$。

例如，当 $x = 5$、$y = 3$ 时，得到 $a_5 = 3$，$a_6 = 3^2 \bmod 5 = 4$，$a_7 = 4^2\bmod 6 = 4$，等等。得到 29 项的序列：
$ 3,4,4,2,4,7,9,4,4,3,9,6,4,16,4,16,16,4,16,3,9,6,10,19,25,16,16,8,0 $
因此 $l(5,3) = 29$。

$g(x)$ 定义为对所有 $y \lt x$ 的 $l(x,y)$ 的最大值。例如，$g(5) = 29$。

再定义 $f(n)$ 为对所有 $x \le n$ 的 $g(x)$ 的最大值。例如，$f(100) = 145$，$f(10\,000) = 8824$。

求 $f(3\,000\,000)$。
