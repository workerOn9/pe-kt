# 772 · 可平衡的 k 有界分拆

> 中文意译。英文原文见 [Project Euler Problem 772](https://projecteuler.net/problem=772)；抓取底稿见 `statement.en.md`。

正整数 $N$ 的一个 $k$ 有界分拆，是把 $N$ 写成不超过 $k$ 的正整数之和的方式。

可平衡分拆是指能进一步分成两部分、使两部分之和相等的分拆。

例如，$3 + 2 + 2 + 2 + 2 + 1$ 是 $12$ 的一个可平衡的 $3$ 有界分拆，因为 $3 + 2 + 1 = 2 + 2 + 2$。反之，$3 + 3 + 3 + 1$ 是 $10$ 的一个 $3$ 有界分拆，但它不可平衡。

记 $f(k)$ 为最小的正整数 $N$，使得它的所有 $k$ 有界分拆都可平衡。例如 $f(3) = 12$，$f(30) \equiv 179092994 \pmod {1\,000\,000\,007}$。

求 $f(10^8)$，答案对 $1\,000\,000\,007$ 取模。
