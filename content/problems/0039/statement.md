# 整数直角三角形

> 中文意译。英文原文见 [Project Euler Problem 39](https://projecteuler.net/problem=39)；抓取底稿见 `statement.en.md`。

设直角三角形三边长均为整数，记为 $\{a, b, c\}$，其周长为 $p$。例如当 $p = 120$ 时，恰好存在三个解：

| 三边 $\{a, b, c\}$ | 验证 |
|------|------|
| $\{20, 48, 52\}$ | $20^2 + 48^2 = 400 + 2304 = 2704 = 52^2$ |
| $\{24, 45, 51\}$ | $24^2 + 45^2 = 576 + 2025 = 2601 = 51^2$ |
| $\{30, 40, 50\}$ | $30^2 + 40^2 = 900 + 1600 = 2500 = 50^2$ |

在 $p \le 1000$ 中，哪个周长对应的解的个数最多？
