# 039 · 整数直角三角形 — 解析

## 思路推导

**暴力思路**：对每个 $p \le 1000$，枚举直角边 $a \le b$，令 $c = p - a - b$，验证 $a^2 + b^2 = c^2$ 并计数。由 $a \le b \le c$ 且 $a + b + c = p$ 可推出 $a \le p/3$、$b \le (p-a)/2$，内层规模约 $p^2/12$，对 $p$ 累加后总量约 $10^7$ 量级——能跑（约 28.75 ms），但没有利用任何结构。

**优化思路：欧几里得公式。** 所有本原勾股数（三边互素的整数直角三角形）都可由

$$a = m^2 - n^2, \qquad b = 2mn, \qquad c = m^2 + n^2$$

参数化生成，其中 $m > n \ge 1$、$\gcd(m,n) = 1$ 且 $m - n$ 为奇数；每个本原三元组在上述条件下被**恰好生成一次**。非本原的三角形都是某个本原三角形的 $k$ 倍。

代入周长立即得到漂亮的化简：

$$p_0 = a + b + c = (m^2 - n^2) + 2mn + (m^2 + n^2) = 2m(m + n)$$

于是算法变成：枚举合法的 $(m, n)$ 对，算出本原周长 $p_0$，再把 $p_0$ 的所有倍数 $k \cdot p_0 \le 1000$ 在计数数组里各加一。最后扫描数组取计数最大的 $p$。

**上界估计**：取最小的 $n = 1$ 时 $p_0 = 2m(m+1) \le 1000$ 给出 $m \le 21$（实现里用宽松的 $m \le 31$，超出的组合 $p_0 > 1000$ 会被内层 $k$ 循环自然跳过，无副作用）。

一个值得注意的细节：$a^2 + b^2 = c^2$ 与 $a + b + c = p$ 联立可推出计数本质上在统计「$p$ 能被哪些本原周长整除」——周长 $840$ 拥有最多的本原周长因子，因此解数最多。

答案：**840**。

## 复杂度对比

| 方案 | 时间 | 实测（JIT 预热后） |
|------|------|------|
| 优化解：欧几里得公式生成本原勾股数 + 倍数平移计数 | $O(\#\text{生成对} \cdot 1000/p_0)$，实际仅数千次操作 | ~0.0013 ms |
| 暴力解：逐 $p$ 枚举 $a \le b$ 验证 $a^2+b^2=c^2$ | $\sum_{p \le 1000} \Theta(p^2) = \Theta(P^3)$，约 $3 \times 10^7$ 次内层检查 | ~28.75 ms |

约 2 万倍的差距来自枚举空间的本质缩小：暴力解在「无序的边长组合」里大海捞针，而欧几里得公式直接给出**不重不漏**的解空间参数化，只需枚举 $\Theta(m^2)$ 个 $(m,n)$ 对（实际不到 400 个合法对），每个对的后续工作只是少量整除与计数。

## 实现要点

- 本原性三条件缺一不可且合起来恰好「每三元组一次」：$m > n \ge 1$、$\gcd(m,n) = 1$、$m - n$ 为奇数；漏掉奇偶条件会重复计数，漏掉互素会漏掉缩放来源
- 周长直接化简为 $p_0 = 2m(m+n)$，避免边长公式逐项相加
- 用 `IntArray(1001)` 做直方图计数，$k \cdot p_0$ 平移即把本原解传播到所有缩放倍数
- 取最大用严格大于 `>` 比较，平局时保留较小的 $p$（本题 $840$ 为唯一最大值）
- 全程 `Int` 足够：边长 $\le 1000$ 时 $a^2 + b^2 \le 2 \times 10^6$，无溢出风险
