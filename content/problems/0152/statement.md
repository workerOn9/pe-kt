# 平方倒数之和

> 中文意译。英文原文见 [Project Euler Problem 152](https://projecteuler.net/problem=152)；抓取底稿见 `statement.en.md`。

把分数 $\frac{1}{2}$ 写成若干个**不同整数**的平方倒数之和，有多种方式。

例如，集合 $\{2,3,4,5,7,12,15,20,28,35\}$ 可以这样用：

$$\frac{1}{2} = \frac{1}{2^2} + \frac{1}{3^2} + \frac{1}{4^2} + \frac{1}{5^2} + \frac{1}{7^2} + \frac{1}{12^2} + \frac{1}{15^2} + \frac{1}{20^2} + \frac{1}{28^2} + \frac{1}{35^2}$$

事实上，只用 $2$ 到 $80$ 之间的整数（含端点），恰好有三种方式，另外两种是：

$\{2,3,4,6,7,9,10,20,28,35,36,45\}$ 和 $\{2,3,4,6,7,9,12,15,28,30,35,45\}$。

问：只用 $2$ 到 $80$ 之间的不同整数，共有多少种方式把 $\frac{1}{2}$ 写成平方倒数之和？
