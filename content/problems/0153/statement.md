# 探究高斯整数

> 中文意译。英文原文见 [Project Euler Problem 153](https://projecteuler.net/problem=153)；抓取底稿见 `statement.en.md`。

众所周知，方程 $x^2 = -1$ 在实数范围内无解。

但如果引入虚数 $i$，该方程有两个解：$x = i$ 和 $x = -i$。

更进一步，方程 $(x + iy)^2 = -1$ 有两个复数解……

高斯整数是指形如 $a + bi$ 的复数，其中 $a$ 和 $b$ 都是整数。

普通整数也是高斯整数（此时 $b = 0$）。

为区分 $b \neq 0$ 的高斯整数，我们称其为「有理整数」。

若 $\frac{n}{a + bi}$ 仍是高斯整数，则称高斯整数 $a + bi$ 是有理整数 $n$ 的一个**因数**。

例如，用 $2 + i$ 除 $10$：将分子分母同乘 $2 + i$ 的共轭 $2 - i$：

$$\frac{10}{2 + i} = \frac{10(2 - i)}{(2 + i)(2 - i)} = \frac{20 - 10i}{4 + 1} = \frac{20 - 10i}{5} = 4 - 2i$$

所以 $2 + i$ 是 $10$ 的一个因数。

注意 $3 + 2i$ 不是 $7$ 的因数，因为 $\frac{7}{3 + 2i} = \frac{7(3 - 2i)}{9 + 4} = \frac{21 - 14i}{13}$ 不是高斯整数。

另外注意：若 $a + bi$ 是 $n$ 的因数，则其共轭 $a - bi$ 也是 $n$ 的因数。

事实上，$10$ 有六个实部为正的高斯整数因数：$1+i, 1-i, 2+2i, 2-2i, 5, 1$ 及其共轭，再加上 $10$ 本身。

对每个正整数 $n$，令 $s(n)$ 为 $n$ 的所有实部为正的因数的和（按复数加法计算实部和与虚部和）。

求 $\sum_{n=1}^{10^8} s(n)$。
