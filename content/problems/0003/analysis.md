# 003 · 最大质因数 — 解析

## 思路推导

目标：求 $n = 600851475143$ 的最大质因数。

**关键观察：试除法的上界会随整除动态缩小。**

从小到大试除候选因子 $d$：能整除就把 $n$ 里的 $d$ 全部剥离（`while (n % d == 0) n /= d`）。剥离是彻底的，所以之后遇到的每个能整除的 $d$ 必然是新质因子——合数因子早已被它的质因子提前剥光。

终止条件不是 $d \le n_0$，而是 $d^2 \le n_{\text{剩余}}$。每次剥离都让剩余值急剧变小，循环提前结束。循环退出时若 $n_{\text{剩余}} > 1$，它本身就是最大质因数（一个数至多有一个大于 $\sqrt{n}$ 的质因子）。

本题的分解过程：

$$600851475143 = 71 \times 839 \times 1471 \times 6857$$

候选因子只需扫到 1471（发现它之后剩余 6857，而 $1473^2 > 6857$ 直接退出），总共约 740 次迭代——而不是 $\sqrt{600851475143} \approx 77.5$ 万次。

**为什么不做暴力**：从 $\sqrt{n}$ 往下找因子再判质，或先筛出 77.5 万以内所有素数，都是可行的但完全没必要；试除法在本题规模下微秒级完成。

## 复杂度

- 时间：最坏 $O(\sqrt{n})$（n 本身是质数时退化为全扫描）；本题实际约 740 次迭代
- 空间：$O(1)$
- 实测（JIT 预热后）：~1.85 µs

## 实现要点

- 候选步进：2 单独处理，之后只试奇数（`candidate += if (candidate == 2) 1 else 2`）
- 返回逻辑：`if (n > 1) n else largest`——剩余值优先，它就是最大质因子
- 输入用 `Long` 字面量 `600_851_475_143L`，注意下划线分组可读性
