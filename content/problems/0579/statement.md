# 579 · 格立方体中的格点

> 中文意译。英文原文见 [Project Euler Problem 579](https://projecteuler.net/problem=579)；抓取底稿见 `statement.en.md`。

格立方体是指所有顶点都具有整数坐标的立方体。设 $C(n)$ 为所有顶点坐标都落在 $0$ 到 $n$（含两端）之间的不同格立方体的数量。此处，如果两个立方体的任何顶点坐标不同，则视为不同的立方体。
例如，$C(1)=1$，$C(2)=9$，$C(4)=100$，$C(5)=229$，$C(10)=4469$，$C(50)=8154671$。

不同的立方体可能包含不同数量的格点。

例如，顶点为
$(0, 0, 0)$、$(3, 0, 0)$、$(0, 3, 0)$、$(0, 0, 3)$、$(0, 3, 3)$、$(3, 0, 3)$、$(3, 3, 0)$、$(3, 3, 3)$ 的立方体包含 $64$ 个格点（$56$ 个格点在表面上，含 $8$ 个顶点，另有 $8$ 个点在立方体内部）。

相比之下，顶点为
$(0, 2, 2)$、$(1, 4, 4)$、$(2, 0, 3)$、$(2, 3, 0)$、$(3, 2, 5)$、$(3, 5, 2)$、$(4, 1, 1)$、$(5, 3, 3)$ 的立方体只包含 $40$ 个格点（$20$ 个点在表面上，$20$ 个点在立方体内部），尽管两个立方体的边长都是 $3$。

设 $S(n)$ 为所有顶点坐标都落在 $0$ 到 $n$（含两端）之间的不同格立方体所包含的格点总数。

例如，$S(1)=8$，$S(2)=91$，$S(4)=1878$，$S(5)=5832$，$S(10)=387003$，$S(50)=29948928129$。

求 $S(5000) \bmod 10^9$。
