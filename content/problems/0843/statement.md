# 843 · 周期圆环

> 中文意译。英文原文见 [Project Euler Problem 843](https://projecteuler.net/problem=843)；抓取底稿见 `statement.en.md`。

本题考虑一个迭代过程：起始时圆周上排列着 $n \ge 3$ 个整数。每一步迭代中，圆周上的每个数同时被替换为其两个相邻邻居的差的绝对值。

对于任意初始值，该过程最终都会进入周期循环。

设 $S(N)$ 为所有满足 $3 \le n \le N$ 的圆环上可能出现的所有不同周期长度之和。例如 $S(6) = 6$，因为在 $3 \le n \le 6$ 范围内的所有可能周期为 $1, 2, 3$。具体而言，$n=3$ 和 $n=4$ 的周期都只能是 $1$；$n=5$ 的周期可以是 $1$ 或 $3$；$n=6$ 的周期可以是 $1$ 或 $2$。

已知 $S(30) = 20381$。

求 $S(100)$。
