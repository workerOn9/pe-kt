# 617 · 镜像幂序列

> 中文意译。英文原文见 [Project Euler Problem 617](https://projecteuler.net/problem=617)；抓取底稿见 `statement.en.md`。

对两个整数 $n,e \gt 1$，定义 $(n,e)$-MPS（镜像幂序列）为一个整数无穷序列 $(a_i)_{i\ge 0}$，满足对一切 $i\ge 0$ 有 $a_{i+1} = \min(a_i^e,n-a_i^e)$，且 $a_i \gt 1$。

这样的序列的例子是由 $2$ 和 $4$ 交替构成的两条 $(18,2)$-MPS。

注意，虽然这样的序列由 $n,e$ 和 $a_0$ 唯一确定，但对大多数取值这样的序列并不存在。例如当 $n \lt 6$ 时不存在任何 $(n,e)$-MPS。

设 $C(n)$ 为对某些 $e$ 存在的 $(n,e)$-MPS 的个数，$\displaystyle D(N) = \sum_{n=2}^N C(n)$。

已知 $D(10) = 2$，$D(100) = 21$，$D(1000) = 69$，$D(10^6) = 1303$，$D(10^{12}) = 1014800$。

求 $D(10^{18})$。
