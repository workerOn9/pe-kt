# 319 · 有界数列

> 中文意译。英文原文见 [Project Euler Problem 319](https://projecteuler.net/problem=319)；抓取底稿见 `statement.en.md`。

设长度为 $n$ 的序列 $x_1, x_2, \dots, x_n$ 满足：

- $x_1 = 2$；
- 对一切 $1 < i \le n$：$x_{i-1} < x_i$；
- 对一切 $1 \le i, j \le n$：$(x_i)^j < (x_j+1)^i$。

长度为 $2$ 的这类序列只有五个：$\{2,4\}$、$\{2,5\}$、$\{2,6\}$、$\{2,7\}$、$\{2,8\}$。

长度为 $5$ 的这类序列有 $293$ 个，例如 $\{2,5,11,25,55\}$、$\{2,6,14,36,88\}$、$\{2,8,22,64,181\}$。

记 $t(n)$ 为长度为 $n$ 的这类序列的个数。已知 $t(10)=86195$，$t(20)=5227991891$。

求 $t(10^{10}) \bmod 10^9$。
