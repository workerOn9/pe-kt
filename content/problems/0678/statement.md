# 678 · 类费马方程

> 中文意译。英文原文见 [Project Euler Problem 678](https://projecteuler.net/problem=678)；抓取底稿见 `statement.en.md`。

若正整数三元组 $(a, b, c)$ 满足 $a^2+b^2=c^2$，则称它为毕达哥拉斯三元组。当 $e \ge 3$ 时，没有三元组 $(a, b, c)$ 满足 $a^e+b^e=c^e$（费马大定理）。然而，若左右两边的指数不同，这就不成立。例如 $3^3+6^3=3^5$。

设 $a, b, c, e, f$ 均为正整数，$0 \lt a \lt b$，$e \ge 2$，$f \ge 3$，且 $c^f \le N$。设 $F(N)$ 为满足 $a^e+b^e=c^f$ 的 $(a, b, c, e, f)$ 个数。已知 $F(10^3) = 7$，$F(10^5) = 53$，$F(10^7) = 287$。

求 $F(10^{18})$。
