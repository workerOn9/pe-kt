# 523 · 首次排序 I

> 中文意译。英文原文见 [Project Euler Problem 523](https://projecteuler.net/problem=523)；抓取底稿见 `statement.en.md`。

考虑下面这个给列表排序的算法：

1. 从列表开头开始，依次检查每一对相邻元素。
2. 如果这对元素顺序颠倒：
a. 把这对元素中较小的那个移到列表开头。
b. 从第 1 步重新开始。
3. 如果所有相邻对都已有序，停止。

例如，列表 $\{\,4\,1\,3\,2\,\}$ 的排序过程如下：

$\underline{4\,1}\,3\,2$（$4$ 与 $1$ 顺序颠倒，把 $1$ 移到列表开头）
$1\,\underline{4\,3}\,2$（$4$ 与 $3$ 顺序颠倒，把 $3$ 移到列表开头）
$\underline{3\,1}\,4\,2$（$3$ 与 $1$ 顺序颠倒，把 $1$ 移到列表开头）
$1\,3\,\underline{4\,2}$（$4$ 与 $2$ 顺序颠倒，把 $2$ 移到列表开头）
$\underline{2\,1}\,3\,4$（$2$ 与 $1$ 顺序颠倒，把 $1$ 移到列表开头）
$1\,2\,3\,4$（列表现在已有序）

记 $F(L)$ 为把列表 $L$ 排好序时第 2a 步被执行的次数。例如 $F(\{\,4\,1\,3\,2\,\}) = 5$。

记 $E(n)$ 为 $F(P)$ 在所有 $\{1, 2, \dots, n\}$ 的排列 $P$ 上的期望值。
已知 $E(4) = 3.25$，$E(10) = 115.725$。

求 $E(30)$，结果四舍五入到小数点后两位。
