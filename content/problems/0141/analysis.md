# 141 · 平方递进数 — 解析

## 思路推导

**把「顺序不限的等比三项」翻译成乘法等式。** 递进数的定义是

$$
n = d\,q + r,\qquad 0 < r < d,
$$

且 $d, q, r$ 是某个等比数列中连续的正整数项。三项成等比的等价说法是「中项的平方等于两侧之积」，这条判据与顺序无关，所以把三项排序成 $A < B < C$ 后就有

$$
A\cdot C = B^{2}.
$$

这一步是全部推导的支点：它把「顺序不限」这个麻烦条件变成了一个纯乘法的整除关系。

**三项的完整参数化。** 设公比的最简分数表示为 $p/q$（$p > q \ge 1$，$\gcd(p,q)=1$），则三个数必然是

$$
A = c\,q^{2},\qquad B = c\,p\,q,\qquad C = c\,p^{2}\qquad (c \ge 1);
$$

反过来，任意一组这样的 $(p,q,c)$ 都确定一个含三项的等比数列。

**筛出真正可行的排列。** 把 $(d,q,r)$ 的六种排列逐一对照约束 $0 < r < d$：

| $(d,q,r)$ | 余数条件 | 得到的 $n$ |
|---|---|---|
| $(A,B,C)$ | $r=C>A$，不成立 | — |
| $(A,C,B)$ | $r=B>A$，不成立 | — |
| $(B,A,C)$ | $r=C>B$，不成立 | — |
| $(B,C,A)$ | $r=A<B$，成立 | $C\cdot B + A$ |
| $(C,A,B)$ | $r=B<C$，成立 | $C\cdot A + B = B^{2} + B$ |
| $(C,B,A)$ | $r=A<C$，成立 | $C\cdot B + A$ |

第四、六两行算出的是同一个 $n$；第五行可以整支丢掉，因为

$$
B^{2} < B^{2} + B < (B+1)^{2},
$$

即它严格夹在两个相邻平方数之间，永远不可能是完全平方数（代码里对 $B\le 10^{5}$ 做了直接检查作为断言）。

于是**平方递进数恰好是**

$$
n = C\,B + A = c^{2}p^{3}q + c\,q^{2} = c\,q\left(c\,p^{3} + q\right),
$$

$$
p > q \ge 1,\qquad \gcd(p,q)=1,\qquad c \ge 1,\qquad n < 10^{12}.
$$

**搜索范围。** $q=1$、$c=1$ 时 $n = p^{3}+1$，故 $p \le 9999$。固定 $(p,q)$ 后 $n$ 关于 $c$ 严格递增，$c$ 的上界约为 $\sqrt{10^{12}/(q p^{3})}$；$n \ge q(p^{3}+q)$ 又关于 $q$ 递增，所以内层 $q$ 循环一旦越界即可 `break`。整轮实跑共评估 **7302731** 个候选，覆盖 **605232** 组互素 $(p,q)$ 对。

**$q=1$ 的那一支其实是佩尔方程。** 当 $q=1$ 时 $\gcd(c,\,cp^{3}+1)=1$，两者之积是平方数就迫使**两者各自都是平方数**：$c=s^{2}$ 且 $s^{2}p^{3}+1=t^{2}$，也就是

$$
t^{2} - p^{3}s^{2} = 1 .
$$

这解释了最先几个解的来历：$p=2,s=1$ 给出 $t=3$、$c=1$、$n=9$；$p=2,s=6$ 给出 $t=17$、$c=36$、$n=36\,(36\cdot 8+1)=10404=102^{2}$；$p=3,s=5$ 给出 $t=26$、$c=25$、$n=25\,(25\cdot 27+1)=16900=130^{2}$。这三个正是十万以内四个解中的前三个。

## 独立验证与答案

第二条路径从**因子结构**出发，方向与优化解相反：不碰比值参数 $p,q,c$，而是直接枚举等比三项的中项 $B$ 与小项 $A$，由 $C = B^{2}/A$ 补出大项。枚举 $A \mid B^{2}$ 依赖一个初等观察

$$
a \mid b^{2} \iff \beta(a) \mid b,\qquad \beta(a)=\prod_{f^{e}\parallel a} f^{\lceil e/2\rceil},
$$

先用最小质因子筛求全部 $\beta(a)$，再沿 $\beta(a)$ 的倍数走遍所有 $A \mid B^{2}$（$A<B$），每组算出 $n = B\cdot C + A$ 判平方。这条路径完全不用 $p,q,c$ 那套参数，也不做任何浮点运算。

两条路径在完整范围内给出**同样 23 个数**，并且都复现题面样例：十万以内恰好是 $9, 10404, 16900, 97344$，和是

$$
9 + 10404 + 16900 + 97344 = 124657,
$$

与题面给出的一字不差。这是来自题面本身的外部锚点，也正是对上面那段排列分类的直接检验——六种排列里少留一支或多留一支，这个和都会破坏。优化解还按**题面原始定义**逐项复核了这四个数：枚举除数 $d$，取出真实的商与余数，检查三项中项的平方是否等于两侧之积。

解的分布也自洽（同一份代码取不同上界）：

| 上界 | 解的个数 | 累计和 |
|---|---|---|
| $10^{5}$ | 4 | 124657 |
| $10^{6}$ | 5 | 700738 |
| $10^{9}$ | 13 | 623708737 |
| $10^{12}$ | 23 | **878454337159** |

实跑显示这 23 个数各有唯一的一组 $(p,q,c)$（去重前后个数相同），最终答案是 **878454337159**。

## 复杂度对比

设 $L = 10^{12}$。优化解对每组互素 $(p,q)$ 枚举 $c$，成本为 $\sqrt{L/(q p^{3})}$；固定 $q$ 对 $p$ 求和是 $\Theta(\sqrt{L}/q)$，再对 $q$ 求和得 $O(\sqrt{L}\log L)$，实测约 $7.3\times10^{6}$ 次「一次乘法 + 一次整数开方」。对照解要先建 $10^{6}$ 的筛表，再枚举全部满足 $A \mid B^{2}$、$A<B<10^{6}$ 的 $(A,B)$ 对，实测循环 $3.64\times10^{7}$ 次，其中 $7.3\times10^{6}$ 次走到平方判定；多出来的开销是筛法、$\beta$ 分解，以及每对一次 64 位除法。

| 方案 | 时间 | 空间 | 实测（JIT 预热后） |
|---|---|---|---|
| 优化：互素比值 $(p,q)$ + 倍数 $c$ 的闭式生成 | $O(\sqrt{L}\log L)$ | $O(H)$，$H$ 为解的个数 | 30.6385 ms |
| 对照：中项 $B$ + $\beta(a)$ 因子枚举 | $O\!\left(N\log\log N + N\sum_{a<N}1/\beta(a)\right)$，$N=\sqrt{L}$ | $O(N)$ | 43.2358 ms |

计时口径：两个解都在程序内 JIT 预热后自报耗时，由主 Agent 在空闲机器上各编译一次、独立进程重复 5 次取最小值；数字已同步进 `meta.json` 的两个 baseline 字段。计时覆盖完整的候选生成、集合分配与求和，不含样例断言与编译。

还有一处值得记录：优化解这 30.6385 ms 里约 **62.7%**（约合 19.2 ms）花在 $(p,q)$ 对循环本身（60.5 万次 `gcd` 与越界判断），候选评估只占约 11.4 ms。这个比例由同一进程内交替计时（线程 CPU 时间）测得，绝对毫秒按上面的权威基线折算。也就是说它已接近这个枚举结构的极限——任何只压缩候选数、不动 $(p,q)$ 枚举的剪枝，最多只能省下这约 37%。

## 实现要点

- **六种排列必须逐一看过。** 三组合法、一组恒非平方数（$B^{2}+B$）、两组违反 $r<d$。漏判任何一支，十万以内的样例和就不再是 124657。
- **$B(B+1)$ 不是平方数有纯算术证明**：$B^{2} < B^{2}+B < (B+1)^{2}$。不必逐项验证，但代码里仍对小范围做了直接断言。
- **整除与开方全部用整数完成。** 判等比用 $A\cdot C=B^{2}$ 而不是比值；判平方用「整数开方后回验」。浮点 `sqrt` 在 $10^{12}$ 范围内虽已足够精确，回验能把边界错误彻底排除。
- **去重是语义要求。** 求和累加的是数本身，同一个平方数即使有多组表示也只能算一次；本题实测无重复，仍用集合兜底。
- **一个看似优美、实则错误的剪枝（踩坑记录）。** 曾试图证明 $\gcd(cq,\,cp^{3}+q)=\gcd(c,q)$，据此要求 $\mathrm{lcm}(c,q)$ 是平方数，从而把 $c$ 的枚举压到 $\sqrt{c_{\max}}$ 量级。反例：$p=23,q=2,c=2$ 给出 $n=97344=312^{2}$，而 $\mathrm{lcm}(2,2)=2$ 不是平方数——这里 $v_2(c)=v_2(q)=1$，第三项 $cp^{3}+q=24336=2^{4}\cdot 39^{2}$ 额外携带了 $2$ 的幂，抵消了指数奇偶性。正确的结论是：对 $f \mid q$ 记 $i=v_f(c)$、$j=v_f(q)$，只有 $i \ne j$ 时才能推出约束（$i<j$ 要求 $j$ 为偶，$i>j$ 要求 $i$ 为偶），$i=j$ 时什么都推不出来。我第一次推导时在 $i=j$ 的情形上想当然地认为括号内两项互素（漏掉了 $f=2$ 时「奇 $+$ 奇 $=$ 偶」的可能），于是对奇指数的 $j$ 强制 $i \ge j+1$，直接剪掉了 $c=2$ 这类解。按该错误条件剪枝后，一百万以内的和从 700738 掉到 603394，样例立即报警——**推导里的每个「显然」都要有实跑兜底**。
- **量级与溢出。** $cp^{3}$ 最大约 $4\times10^{12}$，$n$ 只在越界那一步略微超过 $10^{12}$，`Long` 绰绰有余；但候选的中间乘法一律用 `Long`，避免 `Int` 溢出的隐蔽错误。
