# 861 · 双幺因数之积

> 中文意译。英文原文见 [Project Euler Problem 861](https://projecteuler.net/problem=861)；抓取底稿见 `statement.en.md`。

正整数 $n$ 的一个**幺因数**（unitary divisor）是指满足 $\gcd\left(d, \frac{n}{d}\right) = 1$ 的因数 $d$。

$n$ 的一个**双幺因数**（bi-unitary divisor）是指满足以下条件的因数 $d$：$1$ 是 $d$ 的幺因数与 $\frac{n}{d}$ 的幺因数中唯一的公共因数。

例如，$2$ 是 $8$ 的双幺因数，因为 $2$ 的幺因数集合为 $\{1, 2\}$，而 $8/2 = 4$ 的幺因数集合为 $\{1, 4\}$，两者的公共幺因数仅有 $1$。

$240$ 的所有双幺因数为 $\{1, 2, 3, 5, 6, 8, 10, 15, 16, 24, 30, 40, 48, 80, 120, 240\}$。

设 $P(n)$ 为 $n$ 的所有双幺因数之积。定义 $Q_k(N)$ 为满足 $1 < n \le N$ 且 $P(n) = n^k$ 的正整数 $n$ 的个数。例如，$Q_2(10^2) = 51$，$Q_6(10^6) = 6189$。

求

$$
\sum_{k=2}^{10} Q_k(10^{12})
$$
