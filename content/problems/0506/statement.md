# 506 · 时钟序列

> 中文意译。英文原文见 [Project Euler Problem 506](https://projecteuler.net/problem=506)；抓取底稿见 `statement.en.md`。

考虑下面这个无限循环的数字序列：

1234321234321234321...

令人惊讶的是，可以把这串数字切分成一串整数，使得第 $n$ 个整数的各位数字之和恰为 $n$。

这个序列如下：

$1, 2, 3, 4, 32, 123, 43, 2123, 432, 1234, 32123, \ldots$

记 $v_n$ 为该序列的第 $n$ 项。例如 $v_2 = 2$，$v_5 = 32$，$v_{11} = 32123$。

记 $S(n) = v_1 + v_2 + \cdots + v_n$。例如 $S(11) = 36120$，$S(1000) \bmod 123454321 = 18232686$。

求 $S(10^{14}) \bmod 123454321$。
