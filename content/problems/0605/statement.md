# 605 · 相邻配对抛硬币游戏

> 中文意译。英文原文见 [Project Euler Problem 605](https://projecteuler.net/problem=605)；抓取底稿见 `statement.en.md`。

考虑一个有 $n$ 位玩家的游戏，按相邻配对进行：第 $1$ 轮在玩家 $1$ 和 $2$ 之间进行，第 $2$ 轮在玩家 $2$ 和 $3$ 之间进行，依此类推，直到第 $n$ 轮在玩家 $n$ 和 $1$ 之间进行。然后第 $n+1$ 轮又回到玩家 $1$ 和 $2$ 之间，整个循环重新开始。

换句话说，在第 $r$ 轮中，玩家 $((r-1) \bmod n) + 1$ 与玩家 $(r \bmod n) + 1$ 对阵。

每一轮抛一枚公平硬币决定两名玩家中谁赢。如果某位玩家同时赢下第 $r$ 轮和第 $r+1$ 轮，则该玩家赢得整局游戏。

设 $P_n(k)$ 为 $n$ 人游戏中玩家 $k$ 获胜的概率，用最简分数表示。例如 $P_3(1) = 12/49$，$P_6(2) = 368/1323$。

设 $M_n(k)$ 为 $P_n(k)$ 最简分数的分子与分母之积。例如 $M_3(1) = 588$，$M_6(2) = 486864$。

求 $M_{10^8+7}(10^4+7)$ 的最后 $8$ 位数字。
