# 719 · 数的拆分

> 中文意译。英文原文见 [Project Euler Problem 719](https://projecteuler.net/problem=719)；抓取底稿见 `statement.en.md`。

我们定义 $S$-数为这样的自然数 $n$：它是一个完全平方数，且其平方根可以通过把 $n$ 的十进制表示拆分成 $2$ 个或更多个数再相加得到。

例如，$81$ 是 $S$-数，因为 $\sqrt{81} = 8+1$。
$6724$ 是 $S$-数：$\sqrt{6724} = 6+72+4$。
$8281$ 是 $S$-数：$\sqrt{8281} = 8+2+81 = 82+8+1$。
$9801$ 是 $S$-数：$\sqrt{9801}=98+0+1$。

再定义 $T(N)$ 为所有 $S$-数 $n\le N$ 之和。已知 $T(10^4) = 41333$。

求 $T(10^{12})$。
