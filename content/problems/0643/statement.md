# 643 · 2-友善

> 中文意译。英文原文见 [Project Euler Problem 643](https://projecteuler.net/problem=643)；抓取底稿见 `statement.en.md`。

两个正整数 $a$ 和 $b$ 称为 $2$-友善的，当 $\gcd(a,b) = 2^t$，$t \gt 0$。例如 $24$ 和 $40$ 是 $2$-友善的，因为 $\gcd(24,40) = 8 = 2^3$；而 $24$ 和 $36$ 不是，因为 $\gcd(24,36) = 12 = 2^2\cdot 3$ 不是 $2$ 的幂。

设 $f(n)$ 为满足 $1\le p\lt q\le n$ 且 $p$ 与 $q$ 是 $2$-友善的正整数对 $(p,q)$ 的个数。已知 $f(10^2) = 1031$，$f(10^6) = 321418433$（模 $1\,000\,000\,007$）。

求 $f(10^{11})$ 模 $1\,000\,000\,007$。
