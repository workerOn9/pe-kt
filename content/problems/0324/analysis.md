# 324 — Building a Tower（搭一座塔）

## 逐层轮廓 DP

把 $3\times 3\times n$ 的高塔沿 $z$ 方向切成 $n$ 个 $3\times 3$ 截面。用 9 位掩码 $\text{in}$ 表示「当前层已被上一层伸下来的骨牌占住的格子」。处理当前层时，剩下空格有两种填法：

* 用**层内**骨牌（$x$ 或 $y$ 方向）覆盖相邻两格；
* 放一块沿 $z$ **伸出**的骨牌：它占住本层该格，并在下一层同位置留下一个已填格，于是产生出射掩码 $\text{out}$。

枚举「层内骨牌 + 伸出骨牌」对 $3\times3$ 的精确覆盖，得到转移矩阵

$$
M[\text{in}][\text{out}] = \text{在入射掩码 }\text{in}\text{ 下恰好盖满本层、出射掩码为 }\text{out}\text{ 的方案数}.
$$

从空塔出发，$f(n) = (M^n)[0][0]$，且 $f(0)=1$。奇数 $n$ 时体积 $9n$ 为奇数、无法用 2-格骨牌铺满，故 $f(\text{奇数})=0$，可作自检。

## 大规模 $n$：线性递推 + Kitamasa

$n = 10^{10000}$ 极大，无法直接做矩阵幂。但 $f(n) \bmod q$（$q = 100000007$ 为素数）作为 $n$ 的序列满足**常系数线性递推**：

1. 用轮廓 DP 递推生成 $f(0), f(1), \dots, f(K)$（$K = 3000$）；
2. 对这段序列跑 **Berlekamp–Massey**，求出极小递推的阶数 $d$（本题 $d = 38$）；
3. 用 **Kitamasa**（多项式的快速幂：计算 $x^N \bmod$ 特征多项式，再与初值线性组合）在 $O(d^2\log N)$ 内求出 $f(N) \bmod q$。

## 验证

1. **暴力枚举真实铺法**：直接递归数 $3\times3\times n$ 盒子被 $2\times1\times1$ 方块铺满的方案数，得 $f(2)=229$、$f(4)=117805$，与题面一致。
2. **掩码 DP 对照题面样例**：$f(10) \bmod q = 96149360$、$f(10^3)\bmod q = 24806056$、$f(10^6)\bmod q = 30808124$，全部一致。
3. **递推自洽**：BM 得到的 38 阶递推在 $n=0,\dots,3000$ 上逐项复核通过。
4. **双方法互证**：Kitamasa 与 $38\times38$ 伴随矩阵快速幂对 $N=10^{10000}$ 给出同一结果。

$$
\boxed{96972774}
$$

与公开官方答案表一致。

## 复杂度对比

| 方法 | 规模 | 耗时（本机 JIT 预热后 3 轮最快） |
| --- | --- | --- |
| 暴力枚举真实铺法 | $n=4$ | 5.55 ms |
| 轮廓 DP + BM + Kitamasa（端到端，主求解路径） | $N=10^{10000}$ | 527.29 ms |

暴力枚举的规模随 $n$ 指数增长（$n=4$ 已是 117805 种铺法，$n=10$ 更不可数）；正式法把「生成序列（$O(9^2 K)$）+ BM（$O(K^2)$）+ Kitamasa（$O(d^2\log N)$）」都控制在可算范围，$N$ 的位数只影响 Kitamasa 的对数因子。

## 关键教训

* **轮廓 DP 是铺砖类问题的标准武器**：把「跨层伸出」编码成掩码的传播，指数级的平面铺法被压成 $2^9\times 2^9$ 的转移矩阵。
* $f(n) \bmod p$ 满足**常系数递推**，$n$ 再大也能用 BM + Kitamasa（或 Bostan–Mori）在 $O(d^2\log N)$ 内求解——这是「指数下标 + 小模数」组合的通用解法。
* 一定要做**独立互证**：Kitamasa 的多项式规约容易写错，用另一条完全不同的路径（伴随矩阵快速幂）算出同一值，才能排除实现层面的错误。
* 模数为素数 $q$ 时 BM 求逆元安全；若模数是合数则需先按素因子拆分，否则除法可能不合法。
