# PE 218 解析——Perfect Right-angled Triangles

## 思路推导

完美 = 本原直角三角形 + 斜边是完全平方数。本原三元组的经典参数化是
$$
a = m^2-n^2,\quad b = 2mn,\quad c = m^2+n^2 \qquad (m>n,\ \gcd(m,n)=1,\ m,n\ \text{一奇一偶}).
$$
要求 $c$ 是平方数，即 $m^2+n^2 = k^2$——这说明 $(m,n,k)$ 自己就是一个本原勾股三元组，于是可以对 $m,n$ 再做一次参数化：
$$
m = 2uv,\quad n = u^2-v^2,\quad k = u^2+v^2 \qquad (u>v,\ \gcd(u,v)=1,\ u,v\ \text{一奇一偶}).
$$
代入得 $c = k^2 = (u^2+v^2)^2$，于是
$$
c \le 10^{16} \iff u^2+v^2 \le 10^{8},
$$
只要枚举 $u \le 10^4$、$v<u$、互素且奇偶相异的 $(u,v)$，就恰好覆盖全部完美三角形：本机共 **15 915 492** 个。

面积 $A = \dfrac{ab}{2} = mn\,|m^2-n^2|$（$m$ 与 $n$ 互换给出同一个三角形，取绝对值），逐个检查 $84 \mid A$，统计不满足者即为答案。

## 结论：0 是可以证明的

计算给出 0 个非超完美的完美三角形，这不是「没搜到」，而是定理：

- $4 \mid A$：$u$、$v$ 一奇一偶 $\Rightarrow uv$ 为偶数 $\Rightarrow m = 2uv \equiv 0 \pmod 4$，而 $m^2-n^2$ 是奇数，故 $4 \mid mn(m^2-n^2)$。
- $3 \mid A$：若 $m$、$n$ 都不被 $3$ 整除，则 $m^2 \equiv n^2 \equiv 1 \pmod 3$，于是 $3 \mid m^2-n^2$。
- $7 \mid A$：反设 $7 \nmid mn(m^2-n^2)$，即 $m,n \not\equiv 0$ 且 $m^2 \not\equiv n^2 \pmod 7$。由于模 7 的二次剩余只有 $\{1,2,4\}$，两个**不同**的二次剩余之和只能是 $1+2=3$、$1+4=5$、$2+4=6$，都不是二次剩余；但 $m^2+n^2 = k^2$ 必须是二次剩余，矛盾。

于是 $84 = \operatorname{lcm}(3,4,7) = 2^2\cdot 3\cdot 7$ 恒整除面积，自然同时给出 $6 \mid A$ 与 $28 \mid A$：**每一个完美三角形都是超完美的**。

## 旁证

1. **两条独立枚举路径**：`solution.kt` 用 $(u,v)$ 二次参数化枚举 $c \le 10^{16}$ 的全部 15 915 492 个完美三角形；`brute-force.kt` 不走推导，直接在 $(m,n)$ 空间枚举 + 整数开方判 $c$ 是否平方，在 $c \le 10^6$（158 个）与 $c \le 10^8$（1593 个）两个区间上同样全部满足 $84 \mid A$。两组计数按区间比例自洽（$15915492 \times 10^{-4} \approx 1592$，与 1593 吻合）。
2. **溢出防护的实测**：面积最大约 $10^{32}$，超出 `Long` 范围，实现里只按模 $84$ 判定（$84 \mid A \iff 84 \mid |A|$），用 $m \bmod 84$、$n \bmod 84$ 分块相乘；若直接写 `area % 84` 会静默溢出并给出错误结果。
3. **题面锚点**：题面给出的 $7$-$24$-$25$ 例子满足「面积 $84$ 被 $6$ 与 $28$ 整除」，本实现的整除判据对 $u=2,v=1$（$m=4,n=3$，得 $7$-$24$-$25$）给出 $84 \mid A$。

**答案：0**。

## 关键教训

- **「斜边是平方数」等价于参数再嵌一层**：看到 $(m,n,\sqrt{c})$ 本身就是勾股三元组，$c$ 的平方结构就能用 $(u,v)$ 显式写出来，枚举规模从 $10^{16}$ 的候选点降到 $u^2+v^2 \le 10^8$ 的圆内格点。
- **答案是 0 的题必须给证明**：只报「count = 0」读者无法区分「不存在」与「没搜到」。三条整除性论证把 0 从计算结果升级成定理，其中模 7 那条需要穷举两个不同二次剩余之和，是本题唯一的实质数论内容。
- **先取模再相乘**：面积量级 $10^{32}$ 远超 `Long`，先把 $m$、$n$ 降到 $84$ 以内做乘法，可以完全避开溢出；这类错误不会抛异常，只会给出一个看似合理的数字。
