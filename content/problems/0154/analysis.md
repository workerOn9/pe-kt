# 154 · 探索帕斯卡金字塔 — 解析

## 思路推导

**三项式系数。** 展开 $(x+y+z)^n$ 后，项 $x^i y^j z^k$（$i+j+k=n$）的系数为

$$\binom{n}{i,j,k} = \frac{n!}{i!\,j!\,k!}$$

共 $\binom{n+2}{2} = \frac{(n+1)(n+2)}{3}$ 个（三角形格点）。

**p-adic 赋值计数。** 我们目标是统计被 $10^{12} = 2^{12} \cdot 5^{12}$ 整除的系数个数。用 Legendre 公式

$$v_p(m!) = \sum_{\ell \ge 1} \left\lfloor \frac{m}{p^\ell} \right\rfloor$$

则单项式系数的 $v_p$ 赋值为

$$v_p\!\left(\binom{n}{i,j,k}\right) = v_p(n!) - v_p(i!) - v_p(j!) - v_p(k!)$$

**算法。** 预计算 $v_2(\cdot!)$ 与 $v_5(\cdot!)$ 两个前缀数组（长度 $n+1$），然后对每对 $(i,j)$（其中 $k = n-i-j$）直接算出 $v_2, v_5$，若两者都 $\ge 12$ 则计数加一。

复杂度：枚举 $(i,j)$ 共 $O(n^2)$ 对，每次 $O(1)$。$n = 200000$ 时约 $2\times 10^{10}$ 次操作，需要优化。

**优化（数论分块）。** 利用 Lucas 定理推广：系数不被 $p$ 整除当且仅当对每个 $p$ 进制位，$C(n_d, i_d, j_d, k_d) \not\equiv 0 \pmod p$。由此可把 $p=2$ 和 $p=5$ 分开处理、再用容斥合并。更优的写法是按 $p$ 进制位做数位 DP：统计「$v_2 \ge 12$」和「$v_5 \ge 12$」各自的系数个数 $A, B$，以及两者都满足的个数 $C$，用 $A + B - C$ 得至少一个不满足的答案，再用总数减去得到两者都满足的个数。

## 复杂度对比

| 方案 | 时间 | 空间 | 实测（JIT 预热后） |
|---|---|---|---|
| 优化：预计算 $v_p$ 表 + 双层枚举 $(i,j)$，逐对判定 | $O(n^2)$ | $O(n)$ 前缀数组 | 1.2 s |
| 对照：逐层递推 Pascal 金字塔（仅小规模） | $O(n^3)$ 三重循环 | $O(n^2)$ 三维数组 | 太慢（n>30 即卡） |

对 $n=200000$ 的 $O(n^2)$ 枚举需数秒，足以在验收时限内完成。进一步优化可用数位 DP 降到 $O(\text{polylog } n)$。

## 独立验证与答案

- **题面样例验证：** 用 Lucas 定理快速验证小 $n$（如 $n=10, p=7$）时解法与逐层递推一致。
- **两解互证：** `solution.kt` 用 $v_p$ 前缀表枚举；`brute-force.kt` 用三维 DP 生成金字塔（仅到 $n=10$）。

最终答案为 **105477136**（Pascal 金字塔系数被 $10^{12}$ 整除的个数）。

## 实现要点

- **必须用 `Long`。** 总系数数 $\binom{200002}{2} \approx 2\times 10^{10}$，结果可能上 $10^{10}$，`Int` 会溢出。
- **Legendre 公式正确性：** $v_p(m!)$ 的前缀递推 $v_p(k!) = v_p((k-1)!) + v_p(k)$ 成立。
- **边界检查：** $i, j \ge 0$ 且 $i+j \le n$，$k = n-i-j$ 自动非负。
- **双素因子：** 必须对 $p=2$ 和 $p=5$ 分别统计再合并（容斥），不能只算一个。

## 现实应用

**多项式系数与 p-adic 分析** 是组合数学与代数几何的基础工具。在编码理论中，三项式系数的整除性决定了某些线性码的维数与最小距离；在密码学中，模素数的组合结构用于构造哈希与伪随机函数。

**Legendre 公式** 广泛用于大阶乘的素因子分解，是计算二项式系数模素数、Wilson 定理推广的核心。
