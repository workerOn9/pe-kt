# PE 221 — 亚历山大整数

## 思路推导

亚历山大整数定义为 $A = pqr$ 且 $\dfrac{1}{A} = \dfrac{1}{p} + \dfrac{1}{q} + \dfrac{1}{r}$（$p,q,r$ 为整数，允许负值）。

把 $p$ 取正、$q,r$ 取负（若全取正则任意 $a\cdot b\cdot c = a+b+c$ 型解会重复计入），设 $p = x > 0$，$q = -m$，$r = -n$（$m, n > x$），恒等式通分：

$$
\dfrac{1}{x} - \dfrac{1}{m} - \dfrac{1}{n} = \dfrac{mn - xm - xn}{xmn} = 0
\;\Longrightarrow\; mn - xm - xn = 0
$$

左移整理为 $(m-x)(n-x) = x^2 + 1$（注意不是配平 $x^2$：展开 $mn - xm - xn + x^2$ 与 $mn - xm - xn$ 恰好差一个 $x^2$，所以右侧补上是 $x^2 + 1$）。记 $s = m - x$、$t = n - x$：

$$
\boxed{\;A = x(x+s)(x+t), \quad s\cdot t = x^2 + 1, \quad 1 \le s < t, \quad x \ge 1\;}
$$

由于 $s < t$ 等价于 $s < \sqrt{x^2+1}$，生成元 $(x, s)$ 一一确定一个亚历山大整数（$x$ 固定时 $s\mapsto A$ 严格单调，故同一 $A$ 不会由两个 $(x,s)$ 生成）。按 $x$ 递增扫描因子对即可按序生成全部解。

例：$x=1$，$x^2+1=2$，$s=1,t=2$：$A = 1\cdot2\cdot3 = 6$；$x=2$，$5$，$s=1,t=5$：$A = 2\cdot3\cdot7 = 42$；$x=3$，$10$，$s=1,t=10$、$s=2,t=5$：$A = 3\cdot4\cdot13 = 156$、$3\cdot5\cdot8 = 120$（$156$ 先于 $120$ 出现——$x$ 内 $s$ 降序或排序后合并均不影响总数）。

## 程序验证

* 每个生成元 $(x,s,t)$ 用 Python `Fraction` 精确验证 $\dfrac{1}{A} = \dfrac{1}{x} - \dfrac{1}{x+s} - \dfrac{1}{x+t}$；
* 官方样例 $6, 42, 120, 156, 420, 630$ 按序重现在列表前 6 位；
* $x \le 310000$ 扫完（不动点：$A \ge 3x^3$，扫描末尾 $3X^3 \approx 8.9\times10^{17}$ 已覆盖答案 $1.88\times10^{15}$），201 万个生成元无一重复（去重数为 0，两两互不冲突的双射性成立）；
* 独立验证 Kotlin 程序输出：**第 150000 个亚历山大整数 = 1884161251122450**。

## 复杂度对比

| 方法 | 复杂度 | 实测 |
| --- | --- | --- |
| 暴力逐 x 试除 $\sqrt{x^2+1}$ | $O(X\sqrt{X})$ | Kotlin 8 s（JVM 预热后） |
| 素因子打标（$q\equiv1\bmod4$ 找 $x^2\equiv-1$ 根） | $O(X\log\log X)$ | Kotlin 5.2 s（JVM 预热后） |

打标筛实测加速约 1.54 倍——本题上限温和，试除常数其实不大，真正的差距在 $x$ 远超 $10^6$ 时才会拉开。

## 关键教训

* **「逐 x 试除」在小上限上其实够快**，优先做暴力版本跑出答案与数列，再去优化分解；
* **$A(s)$ 关于 $s$ 单调先减后不变**，从小因子扫到大因子（$s>\sqrt{}$ 时止）会先出极大值再缩小——溢出防护必须靠 `m1 > cap/(x+t)` 的预除来跳过，不能用「越界即 break」（会把中段全部合法值漏光，实测从 173202 掉到 34878 项）；
* $x=310000$ 时 $x(x+s)(x+t)$ 最大可达 $10^{22}$ 级别（Long 最大 $9.2\times10^{18}$），任何未经预除判断的乘法都会静默回绕——首次运行曾输出负数答案，是被 $x=330000$ 附近的溢出污染。
