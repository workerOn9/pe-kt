# 488 · 不平衡 Nim

> 中文意译。英文原文见 [Project Euler Problem 488](https://projecteuler.net/problem=488)；抓取底稿见 `statement.en.md`。

Alice 与 Bob 每天都很享受玩 Nim 游戏。然而他们终于玩腻了普通的三堆 Nim。

于是他们加了一条额外规则：

- 不允许出现两个大小相同的堆。

三元组 $(a, b, c)$ 表示三堆的大小。在这条额外规则下，$(2,4,5)$ 是留给下一位玩家的一个必败局面。

举例说明：

- Alice 走到 $(2,4,3)$
- Bob 走到 $(0,4,3)$
- Alice 走到 $(0,2,3)$
- Bob 走到 $(0,2,1)$

与普通三堆 Nim 不同，$(0,1,2)$ 及其各种排列是这个游戏的终局。

对整数 $N$，定义 $F(N)$ 为所有满足 $0 \lt a \lt b \lt c \lt N$ 的必败局面上 $a + b + c$ 的总和。

例如 $F(8) = 42$，因为留给下一位玩家的必败局面共有 $4$ 个，即 $(1,3,5)$、$(1,4,6)$、$(2,3,6)$ 和 $(2,4,5)$。

还可以验证 $F(128) = 496062$。

求 $F(10^{18})$ 的最后 $9$ 位。
