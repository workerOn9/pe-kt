# 057 · 平方根的渐近分数 — 解析

## 思路推导

把 $\sqrt 2$ 的连分数写成渐近分数序列 $x_k = p_k/q_k$，其中

$$x_1 = 1 + \frac{1}{2} = \frac{3}{2},\qquad x_{k+1} = 1 + \frac{1}{1 + x_k}.$$

代入 $x_k = p_k/q_k$：

$$x_{k+1} = 1 + \frac{1}{\dfrac{p_k+q_k}{q_k}} = 1 + \frac{q_k}{p_k+q_k} = \frac{p_k + 2q_k}{p_k + q_k},$$

即**只需加倍与加法**的整数递推

$$\boxed{p_{k+1} = p_k + 2q_k,\qquad q_{k+1} = p_k + q_k.}$$

用它复核题面：$(3,2)\to(7,5)\to(17,12)\to(41,29)\to(99,70)\to(239,169)\to(577,408)\to(1393,985)$，与题目给出的前八项完全一致。

**为什么分子会追上分母。** 该递推对应佩尔方程

$$p_k^2 - 2q_k^2 = (-1)^k,$$

即 $p_k/q_k$ 总在 $\sqrt 2$ 两侧交替逼近，$|p_k - \sqrt 2\,q_k| = 1/(p_k + \sqrt 2 q_k) \to 0$。于是

$$p_k = \sqrt2\,q_k + O(1/q_k),$$

分子与分母的**相对**差距按 $O(1/q_k^2)$ 缩小，但绝对比值恒为 $\sqrt 2$ 附近——所以位数只会在 $q_k$ 恰好跨过 $10^{m}$ 的整数次幂时短暂地满足 $\text{digits}(p) > \text{digits}(q)$。这类「位数差点」共出现

$$153 \text{ 次（前 } k \le 1000),$$

答案：**153**。

**数位数怎么算。** 题目限定「不许用 `toString()` 数字数」，因此实现改用十进制数位数组：递推里只有乘 2 和加法，数位数组的长度**就是**位数，一次比较 `num.size > den.size` 即可，连阈值表都不用。第 1000 项约有 $1000\log_{10}(1+\sqrt2) \approx 383$ 位，数组完全放得下。

## 复杂度对比

| 方案 | 时间 | 实测（JIT 预热后） |
|------|------|------|
| 优化解：十进制数位数组，位数即数组长度 | $O(1000 \cdot D)$，$D \approx 383$ | ~3.727 ms |
| 暴力解：`BigInteger` 递推 + 每次 `toString()` 比长度 | 同阶加法，外加 2000 次十进制格式化 | ~34.313 ms |

（两个基准均预热 5 轮、取 9 轮平均；暴力解在预热不足时会被 JIT 编译时间污染，故这里多预热了两轮。）

## 实现要点

- 递推 $(p,q)\to(p+2q,\ p+q)$ 必须用旧值同时更新分子分母，先算再赋值
- 数位数组低位在前的表示让进位处理最简单，构造结果时去掉高位 0 保证长度即位数
- 首项必须显式取 $k=1$ 的 $3/2$，否则循环次数会与题目的一千次展开错位
- $p_k - \sqrt2 q_k$ 的符号交替（$(-1)^k$）说明序列从两侧收敛，位数追上是短暂现象而非趋势
