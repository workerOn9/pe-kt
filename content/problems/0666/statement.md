# 666 · 多态细菌

> 中文意译。英文原文见 [Project Euler Problem 666](https://projecteuler.net/problem=666)；抓取底稿见 `statement.en.md`。

某物种的细菌有两种类型：$\alpha$ 和 $\beta$。单个细菌能按以下规则在两种类型之间繁殖和变异：
每一分钟，每个个体同时经历某种变换。
类型为 $\alpha$ 的每个个体 $A$ 独立地等概率随机执行以下之一：
自我克隆，产生一个新的 $\alpha$ 型细菌（$A$ 本身保留）；
分裂为 3 个 $\beta$ 型新细菌（$A$ 消失）。
类型为 $\beta$ 的每个个体 $B$ 独立地等概率随机执行以下之一：
产生一个新的 $\alpha$ 型细菌（$B$ 本身保留）；
死亡。

若种群从单个 $\alpha$ 型细菌开始，可以证明种群最终灭绝的概率为 0.07243802，永远存续的概率为 0.92756198。这些概率四舍五入到小数点后 8 位。

现在考虑另一物种的细菌 $S_{k,m}$（$k$ 和 $m$ 为正整数），它有 $k$ 种不同类型 $\alpha_i$（$0\le i< k$）。该物种的生命周期规则涉及如下定义的序列 $r_n$：

$r_0 = 306$
$r_{n+1} = r_n^2 \bmod 10\,007$

每一分钟，对每个 $i$，类型为 $\alpha_i$ 的每个细菌 $A$ 独立地在 $0\le j<m$ 范围内均匀随机选择一个整数 $j$。它随后的行为取决于 $q = r_{im+j} \bmod 5$：

若 $q=0$，$A$ 死亡。
若 $q=1$，$A$ 自我克隆，产生一个新的 $\alpha_i$ 型细菌（$A$ 本身保留）。
若 $q=2$，$A$ 变异，变为类型 $\alpha_{(2i) \bmod k}$。
若 $q=3$，$A$ 分裂为 3 个类型为 $\alpha_{(i^2+1) \bmod k}$ 的新细菌（$A$ 消失）。
若 $q=4$，$A$ 产生一个新的类型为 $\alpha_{(i+1) \bmod k}$ 的细菌（$A$ 本身保留）。

事实上，我们最初的物种正是 $S_{2,2}$，其中 $\alpha=\alpha_0$，$\beta=\alpha_1$。

设 $P_{k,m}$ 为物种 $S_{k,m}$ 从单个 $\alpha_0$ 型细菌开始、种群最终灭绝的概率。所以 $P_{2,2} = 0.07243802$。已知 $P_{4,3} = 0.18554021$，$P_{10,5} = 0.53466253$，均四舍五入到小数点后 8 位。

求 $P_{500,10}$，四舍五入到小数点后 8 位。
