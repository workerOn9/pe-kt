# 976 · XO 游戏

> 中文意译。英文原文见 [Project Euler Problem 976](https://projecteuler.net/problem=976)；抓取底稿见 `statement.en.md`。

两名玩家 X 和 O 在 $k$ 条由方格组成的长条纸带上玩游戏，各纸带长度分别为 $n_1,\dots,n_k$，初始时所有方格均为空白。

从 X 开始，双方轮流操作。轮到 X 时，X 画一个符号“X”；轮到 O 时，O 画一个符号“O”。
符号必须用红笔或蓝笔画在一个空白方格中，并遵守以下限制：

- 在同一条纸带的相邻两个方格中，两个符号必须不同，且颜色也必须不同；
- 如果存在至少一条全空的空白纸带，则玩家必须在一条空白纸带上落子。

无法进行合法操作的玩家输掉游戏。

设 $P(K, N)$ 为满足 $1 \leq k \leq K$、$1\leq n_1\leq\cdots\leq n_k\leq N$ 且使得 X 在对应游戏中拥有必胜策略的元组 $(n_1,\dots,n_k)$ 的数量。
已知 $P(2, 4)=7$ 以及 $P(5, 10) = 901$。

求 $P(10^7, 10^7) \bmod 1234567891$。
